آشنایی با JavaScript

در این درس با کاربرد JavaScript آشنا می‌شوی، چند دستور ساده را امتحان می‌کنی و با شکل‌های رایج نام‌گذاری و ESLint آشنا می‌شوی.

در این درس

    JavaScript چیست؟

    تا اینجا با HTML ساختار صفحه را ساختیم و با CSS ظاهر آن را تغییر دادیم. JavaScript زبانی است که به صفحه رفتار و تعامل اضافه می‌کند؛ مثلاً می‌تواند پیامی نشان دهد، محاسبه کند یا محتوای صفحه را تغییر دهد.

    هدف این درس

    این درس فقط یک آشنایی اولیه است. محاسبات، تغییر محتوای صفحه و دیگر قابلیت‌های JavaScript را در درس‌های بعدی جداگانه و عمیق‌تر یاد می‌گیریم.

    اولین دستور JavaScript

    دستور alert() یک پنجره‌ی کوچک در مرورگر باز می‌کند و پیام داخل آن را نشان می‌دهد. برای امتحان کردنش، این کد را در کادر زیر تغییر بده یا اجرا کن:

    نکته

    alert() پیام را در پنجره‌ی مرورگر نشان می‌دهد؛ نه در کنسول. پنجره‌ی پیام را ببند تا بتوانی دوباره با صفحه کار کنی.

    JavaScript و محاسبات ساده

    JavaScript می‌تواند عملیات ریاضی ساده انجام دهد. علامت‌های آشنای جمع، تفریق، ضرب و تقسیم در این مثال‌ها به کار رفته‌اند:

    چند عملگر رایج ریاضی در JavaScript:

    عملگر معنا مثال
    + جمع 10 + 5
    - تفریق 10 - 5
    * ضرب 10 * 5
    / تقسیم 10 / 5

    تغییر محتوای صفحه

    JavaScript می‌تواند یک عنصر HTML را پیدا کند و متن آن را تغییر دهد. در مثال زیر، querySelector() عنصر دارای شناسه‌ی message را پیدا می‌کند و textContent متنش را عوض می‌کند.

    یادت باشد

    در این درس فقط نمونه‌ای از تغییر متن می‌بینی. پیدا کردن عناصر صفحه و تغییر دادنشان را در درس‌های بعدی با جزئیات بیشتری تمرین می‌کنیم.

    سینتکس و شیوه‌های نام‌گذاری

    سینتکس یعنی قواعدی که باید هنگام نوشتن کد رعایت شوند. برای مثال، رشته‌ی متنی در JavaScript معمولاً داخل کوتیشن قرار می‌گیرد: 

    alert("سلام");

    برای نام‌گذاری در کد، شکل‌های مختلفی وجود دارد. این‌ها را فعلاً در حد تشخیص دادن یاد می‌گیریم:

    نام روش نمونه شکل نوشتن
    camelCase userName کلمه‌ی اول با حرف کوچک و کلمه‌های بعدی با حرف بزرگ شروع می‌شوند.
    snake_case user_name کلمه‌ها با زیرخط _ جدا می‌شوند.
    PascalCase UserName هر کلمه با حرف بزرگ شروع می‌شود.
    kebab-case user-name کلمه‌ها با خط تیره - جدا می‌شوند.

    نکته

    در JavaScript معمولاً برای نام متغیرها و تابع‌ها از camelCase استفاده می‌کنیم. در این مرحله مهم‌تر این است که بتوانی شکل‌های مختلف را تشخیص بدهی.

    ESLint چیست؟

    ESLint ابزاری برای بررسی کد JavaScript است. می‌تواند بعضی اشتباه‌های نوشتاری یا ناهماهنگی با قواعد کدنویسی پروژه را گزارش کند تا پیدا کردن و مرتب کردن مشکلات آسان‌تر شود.

    ESLint خودش برنامه را نمی‌نویسد و همه‌ی خطاهای منطقی را هم پیدا نمی‌کند؛ بیشتر مثل یک بررسی‌کننده‌ی کمکی برای کد عمل می‌کند.

    جمع‌بندی

    JavaScript به صفحه رفتار و تعامل اضافه می‌کند. در این درس دیدیم که می‌توان با alert() پیامی نمایش داد، محاسبه‌ای ساده انجام داد و متن یک عنصر صفحه را تغییر داد. همچنین با مفهوم سینتکس، روش‌های نام‌گذاری و ابزار ESLint آشنا شدیم. این‌ها مقدمه‌ای هستند برای درس‌های بعدی.

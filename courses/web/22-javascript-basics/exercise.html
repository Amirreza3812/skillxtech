تمرین: آشنایی با JavaScript

مثال‌ها را اجرا کن، کدها را تغییر بده و شکل‌های مختلف نام‌گذاری را تشخیص بده.

  1. نمایش یک پیام

    کد را طوری کامل کن که با اجرای آن، پیام دارم JavaScript یاد می‌گیرم! در پنجره‌ی مرورگر نمایش داده شود.

    راهنمایی

    از alert() استفاده کن و متن پیام را داخل کوتیشن قرار بده.

  2. انجام یک محاسبه

    عددهای کد را تغییر بده تا حاصل جمع دو عدد دلخواهت در صفحه نمایش داده شود.

    راهنمایی

    نتیجه‌ی جمع را در متغیر result قرار بده. سپس متن عنصر را با textContent تغییر بده.

  3. تغییر متن صفحه

    متن داخل پاراگراف را با JavaScript به «من متن را تغییر دادم» تبدیل کن.

    راهنمایی

    پاراگراف را با document.querySelector("#notice") پیدا کن و مقدار textContent آن را تغییر بده.

  4. تشخیص شیوه‌ی نام‌گذاری

    برای هر نام، در کامنت کنار آن بنویس که از کدام روش استفاده شده: camelCase، snake_case، PascalCase یا kebab-case.

    راهنمایی

    به حروف بزرگ و جداکننده‌ها توجه کن: زیرخط، خط تیره یا حرف بزرگ میان کلمه‌ها.

  5. نوشتن یک مثال کوتاه

    یک پاراگراف HTML با شناسه‌ی greeting بساز. بعد با JavaScript متن آن را به یک سلام دلخواه تغییر بده.

    راهنمایی

    اول پاراگراف را بنویس، بعد داخل تگ <script> آن را با querySelector() پیدا کن.

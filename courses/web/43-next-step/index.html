بازگشت به داشبورد تمرین پایانی

طراحی وب

قدم بعدی پس از این دوره

مسیر HTML، CSS و JavaScript را مرور می‌کنیم و برای ادامه، پروژه‌ها و موضوعاتی را انتخاب می‌کنیم که مهارت‌هایت را به تجربه‌ی واقعی تبدیل می‌کنند.

در این درس

    تا اینجا چه یاد گرفته‌ای؟

    در این دوره از ساختار صفحه با HTML شروع کردی، با CSS ظاهر و چیدمان ساختی و سپس با JavaScript به صفحه رفتار و تعامل دادی. همچنین با مفاهیمی مثل DOM، آرایه‌ها، توابع، ماژول‌ها، Promiseها و درخواست‌های شبکه آشنا شدی.

    این دوره یک نقطه‌ی شروع است، نه پایان یادگیری. حالا بهترین قدم این است که آموخته‌ها را در چند پروژه‌ی کامل ترکیب کنی، بازخورد بگیری و موضوعات بعدی را بر اساس نیاز همان پروژه‌ها یاد بگیری. مسیرهای آموزشی معتبر فرانت‌اند هم معمولاً مهارت‌های پایه را از موضوعات تکمیلی جدا می‌کنند و پیشنهاد می‌دهند ابتدا پایه‌ها را تقویت کنی.

    یادآوری

    لازم نیست همه‌ی ابزارها و کتابخانه‌ها را پیش از ساخت پروژه یاد بگیری. پروژه‌ای کوچک انتخاب کن، با ابزارهایی که می‌شناسی بساز و هنگام نیاز سراغ موضوع تازه برو.

    سه پروژه برای ادامه

    پروژه‌ای انتخاب کن که بتوانی آن را به بخش‌های کوچک تقسیم کنی و در چند مرحله کاملش کنی. این سه ایده از تمرین رابط کاربری تا کار با داده و API پیش می‌روند.

    پروژه ویژگی‌های پیشنهادی مهارت‌هایی که تمرین می‌کنی
    صفحه‌ی معرفی شخصی معرفی، مهارت‌ها، نمونه‌کارها، راه ارتباطی و طراحی واکنش‌گرا HTML معنایی، CSS، طراحی واکنش‌گرا، دسترس‌پذیری
    مدیریت کارهای روزانه افزودن، انجام‌شده‌کردن و حذف کارها؛ فیلترکردن فهرست DOM، رویدادها، آرایه‌ها، توابع و مدیریت وضعیت رابط
    نمایشگر اطلاعات از API دریافت داده، نمایش حالت بارگذاری، پیام خطا و نتایج fetch، async/await، Promiseها و مدیریت خطا

    پروژه را به قدم‌های کوچک تقسیم کن

    1. هدف پروژه و کاربرانی را که قرار است از آن استفاده کنند، در یک یا دو جمله تعریف کن.
    2. ویژگی‌های اصلی را فهرست کن و فقط چند مورد ضروری را برای نسخه‌ی اول انتخاب کن.
    3. ساختار HTML را آماده کن؛ بعد با CSS ظاهر و چیدمان را بساز.
    4. با JavaScript یک تعامل کوچک اضافه کن و رفتار آن را در مرورگر بررسی کن.
    5. اندازه‌های مختلف صفحه و مسیرهای استفاده با صفحه‌کلید را امتحان کن؛ متن‌ها، کنتراست و برچسب کنترل‌ها را هم بررسی کن.
    6. کد را مرتب کن، تغییرات مهم را ثبت کن و پروژه را برای نمایش به دیگران آماده کن.

    نسخه‌ی کوچک بهتر از پروژه‌ی ناتمام است

    اول یک نسخه‌ی ساده بساز که درست کار کند. سپس ویژگی‌ها را یکی‌یکی اضافه کن. این روش کمک می‌کند زودتر نتیجه بگیری و هر تغییر را جداگانه آزمایش کنی.

    موضوعات پیشنهادی برای یادگیری بعدی

    پس از ساخت چند پروژه‌ی پایه، می‌توانی موضوعات زیر را به‌ترتیب نیازت یاد بگیری. همه‌ی آن‌ها را هم‌زمان شروع نکن؛ وقتی پروژه‌ای به قابلیتی نیاز دارد، همان موضوع را عمیق‌تر بررسی کن.

    • دسترس‌پذیری: ساخت صفحه‌هایی که با صفحه‌کلید و فناوری‌های کمکی قابل استفاده باشند؛ از HTML معنایی و برچسب‌های درست شروع کن.
    • Git و کنترل نسخه: ثبت تغییرات پروژه و امکان بازگشت به نسخه‌های قبلی.
    • ابزارهای توسعه: مدیریت وابستگی‌ها، اجرای پروژه محلی و آشنایی با ابزارهای ساخت.
    • تست: نوشتن تست برای رفتارهای مهم و پیدا کردن خطاها پیش از انتشار.
    • امنیت و کار با داده: شناخت خطرهای رایج و برخورد مسئولانه با داده‌هایی که برنامه دریافت یا نمایش می‌دهد.
    • کتابخانه‌ها و چارچوب‌ها: پس از درک HTML، CSS و JavaScript پایه، یکی را بر اساس نیاز پروژه انتخاب و یاد بگیر.

    دسترس‌پذیری، کنترل نسخه، تست و ابزارهای توسعه از جمله موضوعاتی هستند که در برنامه‌های آموزشی فرانت‌اند در کنار مهارت‌های اصلی و تکمیلی مطرح می‌شوند.

    به سراغ چارچوب‌ها با پایه‌ی محکم برو

    قبل از انتخاب چارچوب، مطمئن شو می‌توانی یک رابط ساده را با HTML، CSS و JavaScript معمولی بسازی. درک پایه‌ها باعث می‌شود مفاهیم چارچوب‌ها را بهتر بفهمی و هنگام خطا راحت‌تر عیب‌یابی کنی.

    روش‌هایی برای ادامه‌ی مؤثر

    • هر روز یا هر هفته زمان کوتاهی را به کدنویسی اختصاص بده؛ استمرار از جلسه‌های پراکنده و طولانی مفیدتر است.
    • وقتی به خطا می‌رسی، پیام خطا را بخوان، مسئله را به نمونه‌ای کوچک تبدیل کن و یک تغییر را در هر مرحله آزمایش کن.
    • از مستندات و مثال‌ها برای پاسخ‌گرفتن استفاده کن و کدی را که پیدا می‌کنی با پروژه‌ی خودت تطبیق بده.
    • پروژه‌هایت را بازبینی کن: چه چیزی درست پیش رفت؟ چه چیزی را دفعه‌ی بعد ساده‌تر یا بهتر انجام می‌دهی؟
    • از دیگران بازخورد بگیر و توضیح بده که پروژه چه مسئله‌ای را حل می‌کند و چطور باید از آن استفاده کرد.

    چک‌لیست پیش از پایان پروژه

    • صفحه در اندازه‌های مختلف نمایشگر قابل استفاده است.
    • عنوان‌ها و بخش‌های صفحه ساختار روشن و معناداری دارند.
    • کنترل‌های تعاملی برچسب قابل‌فهم دارند و با صفحه‌کلید قابل دسترسی‌اند.
    • حالت‌های موفقیت، بارگذاری و خطا در صورت نیاز دیده می‌شوند.
    • کدهای HTML، CSS و JavaScript مرتب و قابل‌خواندن هستند.
    • می‌توانی توضیح بدهی هر بخش پروژه چه کاری انجام می‌دهد.

    خلاصه

    حالا یک مسیر روشن داری: پروژه‌ای کوچک انتخاب کن، نسخه‌ی اولیه‌اش را کامل کن، آن را آزمایش کن و بعد با بازخورد و نیازهای پروژه گسترشش بده. یادگیری توسعه‌ی وب با ساختن، بررسی‌کردن و اصلاح‌کردن پروژه‌های واقعی ادامه پیدا می‌کند.

    قدم بعدی تو

    همین حالا یک پروژه از بخش بالا انتخاب کن و سه ویژگی اصلی نسخه‌ی اولش را بنویس. سپس با ساده‌ترین ویژگی شروع به کدنویسی کن.

    دوره را به یک پروژه تبدیل کن

    در تمرین پایانی، پروژه‌ی بعدی‌ات را انتخاب و برای شروع برنامه‌ریزی کن.

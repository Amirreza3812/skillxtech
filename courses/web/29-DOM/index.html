آشنایی با DOM

یاد می‌گیریم مرورگر چطور ساختار HTML را به شکل یک درخت در اختیار جاوااسکریپت می‌گذارد و چطور عناصر صفحه را پیدا کنیم، متنشان را بخوانیم یا تغییر دهیم.

در این درس

    DOM چیست؟

    DOM کوتاه‌شده‌ی Document Object Model است. مرورگر هنگام خواندن HTML، عناصر صفحه را به شکل مجموعه‌ای از آبجکت‌های مرتبط می‌سازد. جاوااسکریپت می‌تواند از این ساختار برای پیدا کردن عناصر و تغییر صفحه استفاده کند.

    می‌توانیم DOM را مانند نقشه‌ای درختی از صفحه تصور کنیم: یک عنصر در رأس قرار دارد و عناصر دیگر به‌صورت فرزند یا نواده‌ی آن دیده می‌شوند.

    مفهوم‌های درخت

    در این نمونه، html والد عناصر head و body است. عنصر body هم والد h1 و p به شمار می‌آید.

    رابطه‌ی HTML و DOM

    HTML متنی است که برای ساختار صفحه می‌نویسیم. DOM ساختار آبجکتی‌ای است که مرورگر از آن HTML می‌سازد و جاوااسکریپت با آن کار می‌کند. پس DOM خود فایل HTML نیست، بلکه نمایی قابل‌دسترسی از ساختار صفحه در مرورگر است.

    پیدا کردن عنصر با querySelector

    برای انتخاب عنصر از صفحه می‌توانیم از document.querySelector() استفاده کنیم. این دستور یک انتخاب‌گر CSS می‌گیرد و اولین عنصری را که با آن انتخاب‌گر جور باشد برمی‌گرداند.

    برای انتخاب کلاس، نقطه می‌گذاریم؛ برای انتخاب شناسه، از # استفاده می‌کنیم. برای انتخاب تگ هم نام تگ را می‌نویسیم. 

    const heading = document.querySelector("h1");
const message = document.querySelector(".message");
const button = document.querySelector("#change-button");

    اگر عنصری پیدا نشود

    اگر صفحه عنصری مطابق انتخاب‌گر نداشته باشد، querySelector() مقدار null برمی‌گرداند. پس پیش از استفاده از عنصر، مطمئن شو انتخاب‌گر با HTML هماهنگ است.

    خواندن و تغییر متن

    بعد از پیدا کردن عنصر، می‌توانیم متن درون آن را با ویژگی textContent بخوانیم یا تغییر دهیم. 

    const heading = document.querySelector("h1");

console.log(heading.textContent);
heading.textContent = "عنوان جدید";

    در این مثال، کد جاوااسکریپت دکمه و عنوان را پیدا می‌کند. هنگام کلیک روی دکمه، متن عنوان عوض می‌شود.

    تغییر ظاهر با classList

    برای تغییر ظاهر عنصر، معمولاً بهتر است کلاس CSS را اضافه یا حذف کنیم، به‌جای آن‌که همه‌ی سبک‌ها را مستقیماً از جاوااسکریپت تغییر دهیم. ویژگی classList متدهایی مثل add()، remove() و toggle() دارد. 

    element.classList.add("highlight");
element.classList.remove("highlight");
element.classList.toggle("highlight");

    جای قرار دادن کد جاوااسکریپت

    اگر اسکریپت پیش از ساخته‌شدن عناصر صفحه اجرا شود، ممکن است querySelector() نتواند آن‌ها را پیدا کند. برای نمونه‌های این درس، تگ <script> را بعد از عناصر HTML و پیش از پایان </body> گذاشتیم تا عناصر هنگام اجرای کد موجود باشند.

    برای فایل جداگانه

    اگر جاوااسکریپت را در فایل جداگانه می‌نویسی، می‌توانی اسکریپت را پیش از </body> قرار دهی یا از ویژگی defer در تگ <script> استفاده کنی.

    جمع‌بندی

    در این درس یاد گرفتیم:

    • مرورگر از HTML ساختار درختی DOM را می‌سازد.
    • document.querySelector() برای پیدا کردن یک عنصر به کار می‌رود.
    • textContent متن عنصر را می‌خواند یا تغییر می‌دهد.
    • classList امکان اضافه، حذف یا جابه‌جایی کلاس‌های CSS را می‌دهد.
    • زمان اجرای جاوااسکریپت باید با زمان ساخته‌شدن عناصر صفحه هماهنگ باشد.

    آماده‌ای؟

    در تمرین‌ها با انتخاب عناصر و تغییر محتوای صفحه کار کن.

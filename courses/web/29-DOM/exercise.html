تمرین: آشنایی با DOM

کدهای جاوااسکریپت را در کادرها بنویس و اجرا کن.

  1. انتخاب عنوان صفحه

    عنصر h1 را با document.querySelector() پیدا کن و متن آن را با textContent در کنسول نمایش بده.

    راهنمایی

    برای انتخاب تگ عنوان می‌توانی از انتخاب‌گر "h1" استفاده کنی.

  2. تغییر متن با کلیک

    وقتی کاربر روی دکمه کلیک می‌کند، متن پاراگراف را به متن با جاوااسکریپت تغییر کرد! تغییر بده.

    راهنمایی

    پاراگراف و دکمه را با انتخاب‌گر مناسب پیدا کن و برای دکمه از addEventListener("click", ...) استفاده کن.

  3. تغییر کلاس CSS

    با کلیک روی دکمه، کلاس highlight را به پاراگراف اضافه یا از آن حذف کن. از classList.toggle() استفاده کن.

    راهنمایی

    ابتدا یک قانون CSS برای .highlight بنویس؛ سپس با classList.toggle("highlight") آن را جابه‌جا کن.

  4. تغییر عنوان با یک ورودی

    یک فیلد متنی و یک دکمه بساز. با کلیک روی دکمه، متن واردشده در فیلد را به‌عنوان متن عنوان h1 قرار بده. اگر فیلد خالی بود، عنوان را تغییر نده.

    راهنمایی

    مقدار ورودی را از ویژگی value بخوان و با if بررسی کن که خالی نباشد.

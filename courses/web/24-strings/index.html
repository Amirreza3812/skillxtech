طراحی وب

متن‌ها در JavaScript

در این درس با رشته‌ها آشنا می‌شویم، متن‌ها را به هم وصل می‌کنیم و با template literal مقدار متغیرها را داخل متن قرار می‌دهیم.

در این درس

    رشته یا String چیست؟

    رشته (String) نوعی داده برای نگهداری متن است؛ مثل نام، پیام، عنوان صفحه یا نشانی ایمیل. برای اینکه JavaScript متوجه شود بخشی از کد یک متن است، آن را داخل کوتیشن قرار می‌دهیم. 

    const courseName = "طراحی وب";
const greeting = 'سلام!';
const message = `به دوره خوش آمدی`;

    نکته

    برای تعریف رشته می‌توانی از کوتیشن تکی (' ')، کوتیشن دوتایی (" ") یا بک‌تیک (` `) استفاده کنی. کوتیشن آغاز و پایان رشته باید از یک نوع باشد.

    چسباندن رشته‌ها با عملگر +

    عملگر + می‌تواند دو رشته را به هم وصل کند. اگر چند بخش متن داشته باشیم، می‌توانیم آن‌ها را به همین روش ترکیب کنیم. 

    const firstName = "سارا";
const greeting = "سلام " + firstName + "!";
console.log(greeting);

    خروجی در کنسول:

    سلام سارا!

    یادآوری

    برای دیدن خروجی console.log()، کنسول مرورگر را باز کن. در Chrome می‌توانی از منوی مرورگر وارد More tools > Developer tools شوی و زبانهٔ Console را انتخاب کنی.

    Template literal و جای‌گذاری متغیر

    بک‌تیک‌ها امکان دیگری برای ساخت رشته فراهم می‌کنند که به آن template literal می‌گویند. با نوشتن ${...} می‌توانیم مقدار یک متغیر یا نتیجهٔ یک عبارت را داخل متن قرار دهیم. 

    const firstName = "سارا";
const age = 20;

const introduction = `اسم من ${firstName} است و ${age} سال دارم.`;
console.log(introduction);

    خروجی:

    اسم من سارا است و 20 سال دارم.

    داخل ${...} فقط متغیر نمی‌نویسیم؛ یک عبارت هم می‌تواند قرار بگیرد: 

    const result = `حاصل جمع 2 و 3 برابر ${2 + 3} است.`;
console.log(result);

    خروجی:

    حاصل جمع 2 و 3 برابر 5 است.

    رشته‌های چندخطی

    رشته‌ای که با بک‌تیک نوشته شده باشد می‌تواند چند خط داشته باشد. خط جدیدی که در کد می‌نویسیم، در متن رشته هم حفظ می‌شود. 

    const message = `خط اول
خط دوم
خط سوم`;

console.log(message);

    مراقب باش

    برای نوشتن template literal از بک‌تیک استفاده کن، نه کوتیشن تکی یا دوتایی. این دو روش، عبارت‌های ${...} را به‌عنوان جای‌گذاری متغیر پردازش نمی‌کنند.

    طول رشته و دسترسی به کاراکترها

    ویژگی length تعداد کاراکترهای رشته را برمی‌گرداند. برای دسترسی به یک کاراکتر نیز می‌توانیم شمارهٔ جایگاه آن را داخل کروشه بنویسیم. شماره‌گذاری از صفر آغاز می‌شود. 

    const word = "Hello";

console.log(word.length); // 5
console.log(word[0]);     // H
console.log(word[1]);     // e

    نکته

    اگر طول رشته ۵ باشد، جایگاه‌های کاراکترها از ۰ تا ۴ هستند؛ بنابراین جایگاه آخر برابر است با length - 1.

    امتحان کن

    نام، سن و شهر را در کد تغییر بده. ببین چطور با template literal یک معرفی کوتاه می‌سازیم.

    خلاصه

    • رشته‌ها برای نگهداری متن استفاده می‌شوند.
    • رشته را می‌توان با کوتیشن تکی، کوتیشن دوتایی یا بک‌تیک نوشت.
    • با + می‌توان رشته‌ها را به هم وصل کرد.
    • template literal با بک‌تیک نوشته می‌شود و از ${...} برای جای‌گذاری مقدار استفاده می‌کند.
    • با length طول رشته و با شمارهٔ جایگاه به کاراکترهای آن دسترسی داریم.

    آماده‌ای؟

    حالا چند تمرین دربارهٔ رشته‌ها انجام بده.

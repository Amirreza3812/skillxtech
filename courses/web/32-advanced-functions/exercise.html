تمرین: توابع پیشرفته — پارت اول

تعریف تابع، محدوده‌ی متغیرها و callback را با کدنویسی تمرین کن.

  1. نوشتن function expression

    یک تابع به نام getArea در متغیری با const ذخیره کن. تابع باید دو پارامتر برای طول و عرض بگیرد و مساحت را با return برگرداند. سپس آن را فراخوانی و نتیجه را در کنسول نمایش بده.

    راهنمایی

    بعد از const getArea = یک تابع با کلمه‌ی function بنویس. حاصل‌ضرب دو پارامتر را return کن.

  2. بررسی محدوده‌ی متغیر

    تابعی به نام makeMessage بنویس که داخل خودش متغیر message را تعریف و آن را در کنسول نمایش دهد. سپس توضیح بده چرا نمی‌توان همان متغیر را بیرون از تابع استفاده کرد.

    راهنمایی

    متغیر را داخل بدنه‌ی تابع با const تعریف کن و دستور console.log(message) را یک‌بار داخل تابع و یک‌بار بیرون آن امتحان کن.

  3. ساخت تابعی که callback می‌گیرد

    تابعی به نام runCallback بساز که یک تابع را به‌عنوان پارامتر دریافت کند و آن را اجرا کند. سپس تابع دیگری به نام sayWelcome تعریف کن و آن را به runCallback بده.

    راهنمایی

    هنگام فرستادن تابع، نام آن را بدون پرانتز بنویس. داخل runCallback، پارامتر دریافتی را با پرانتز اجرا کن.

  4. callback همراه مقدار

    تابعی به نام formatPrice بنویس که یک عدد را بگیرد و متن قیمت را در کنسول نمایش دهد. سپس تابع showValue را طوری بنویس که عدد و callback را دریافت کند و آن عدد را به callback بفرستد.

    راهنمایی

    داخل showValue، callback را با آرگومان عدد فراخوانی کن: callback(value).

طراحی وب

توابع پیشرفته — پارت اول

با شکل‌های مختلف تعریف تابع، محدوده‌ی دسترسی متغیرها و ارسال تابع به‌عنوان ورودی آشنا می‌شویم.

در این درس

    مرور کوتاه توابع

    تابع مجموعه‌ای از دستورهاست که برای انجام یک کار مشخص نام‌گذاری می‌کنیم. با فراخوانی تابع، دستورهای داخل آن اجرا می‌شوند. تابع‌ها کمک می‌کنند کد را سازمان‌دهی کنیم و از تکرار بی‌مورد جلوگیری کنیم. 

    function greet(name) {
  return "سلام " + name;
}

const message = greet("سارا");
console.log(message);

    تعریف تابع با function declaration

    شکل آشنای تعریف تابع را function declaration می‌نامند. در این روش، نام تابع پس از کلمه‌ی function می‌آید. 

    function multiply(a, b) {
  return a * b;
}

console.log(multiply(4, 3)); // 12

    در این مثال، a و b پارامتر هستند. هنگام فراخوانی تابع، مقدارهای 4 و 3 به‌ترتیب آرگومان‌های تابع می‌شوند.

    عبارت تابع یا function expression

    تابع را می‌توان در یک متغیر هم ذخیره کرد. وقتی تابع به‌صورت یک مقدار ساخته و به متغیر نسبت داده می‌شود، به این الگو function expression می‌گویند. 

    const multiply = function (a, b) {
  return a * b;
};

console.log(multiply(4, 3)); // 12

    در این شکل، تابع را از طریق نام متغیر فراخوانی می‌کنیم. خود عبارت تابع در این نمونه نام جداگانه‌ای ندارد؛ به همین دلیل معمولاً به آن تابع بی‌نام هم می‌گویند.

    دو شکل تعریف تابع

    هم function declaration و هم function expression برای ساخت تابع به کار می‌روند. در این درس مهم است بتوانی هر دو شکل را بخوانی و تفاوت نوشتاری‌شان را تشخیص بدهی.

    محدوده‌ی دسترسی متغیرها

    محدوده‌ی دسترسی یا scope مشخص می‌کند متغیر را در کدام بخش‌های کد می‌توان استفاده کرد. متغیری که داخل تابع با let یا const ساخته می‌شود، معمولاً فقط در همان تابع قابل استفاده است. 

    function showMessage() {
  const message = "سلام!";
  console.log(message); // قابل دسترسی است
}

showMessage();

// اینجا message در دسترس نیست

    متغیرهای تعریف‌شده داخل یک بلوک با آکولاد، مانند if یا حلقه، نیز محدود به همان بلوک هستند. 

    if (true) {
  const status = "آماده";
  console.log(status); // قابل دسترسی است
}

// status بیرون از بلوک قابل استفاده نیست

    محدوده‌ی متغیر را رعایت کن

    اگر متغیری را داخل تابع یا بلوک تعریف کرده‌ای، بیرون از آن بخش نمی‌توانی به آن دسترسی داشته باشی. متغیرها را تا جای ممکن در کوچک‌ترین محدوده‌ی لازم تعریف کن.

    تابع به‌عنوان ورودی تابع دیگر

    در JavaScript، تابع یک مقدار است؛ بنابراین می‌توان آن را به تابع دیگری به‌عنوان آرگومان فرستاد. تابعی که به تابع دیگری داده می‌شود تا آن تابع در زمان مناسب اجرا کند، callback نام دارد. 

    function sayHello() {
  console.log("سلام!");
}

function runTask(task) {
  task();
}

runTask(sayHello);

    در فراخوانی runTask(sayHello)، تابع sayHello را بدون پرانتز می‌فرستیم؛ یعنی خود تابع را ارسال می‌کنیم. داخل runTask، دستور task() تابع دریافت‌شده را اجرا می‌کند.

    ارسال تابع یا اجرای تابع؟

    نوشتن sayHello به معنی فرستادن خود تابع است؛ نوشتن sayHello() آن را همان‌جا اجرا می‌کند و نتیجه‌اش را برمی‌گرداند.

    callback همراه پارامتر

    تابع دریافت‌کننده می‌تواند هنگام اجرای callback، مقداری هم به آن بدهد. در مثال زیر، processNumber عدد را به تابع showDouble می‌فرستد. 

    function showDouble(number) {
  console.log(number * 2);
}

function processNumber(number, callback) {
  callback(number);
}

processNumber(5, showDouble); // 10

    دیدن callback در عمل

    کد را اجرا کن و مقدار ورودی و نتیجه را تغییر بده. تابع printResult به‌عنوان callback به تابع calculate فرستاده می‌شود.

    یک اشاره‌ی کوتاه به arrow function

    در JavaScript شکل خلاصه‌تری برای نوشتن تابع وجود دارد که arrow function نامیده می‌شود. فعلاً کافی است بدانی ممکن است آن را در کدهای دیگر ببینی؛ در این بخش روی تعریف‌های تابعی که یاد گرفتیم تمرکز می‌کنیم. 

    const double = (number) => {
  return number * 2;
};

    جمع‌بندی

    تابع را می‌توان با function declaration تعریف کرد یا آن را در یک متغیر قرار داد و به شکل function expression نوشت. محدوده‌ی دسترسی تعیین می‌کند متغیر در کجا قابل استفاده است. همچنین می‌توان تابع را به تابع دیگری فرستاد؛ تابعی که به این شکل دریافت می‌شود، callback نام دارد.

    آماده‌ای؟

    با تمرین‌های این درس، تعریف تابع و callback را امتحان کن.

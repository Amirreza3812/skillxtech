انتخابگرهای پیشرفته در CSS

در این درس با انتخابگرهای ترکیبی، گروه‌بندی انتخابگرها و مفهوم specificity آشنا می‌شوی تا بتوانی عناصر دقیق‌تری را هدف بگیری.

در این درس

    مرور انتخابگرها

    انتخابگر مشخص می‌کند کدام عنصرهای HTML با یک قانون CSS هدف قرار بگیرند. برای مثال، انتخابگر نوعی p همه‌ی پاراگراف‌ها را انتخاب می‌کند، کلاس با نقطه نوشته می‌شود و شناسه با علامت #. 

    p {
  color: #333;
}

.note {
  color: darkblue;
}

#main-title {
  color: darkgreen;
}

    گروه‌بندی انتخابگرها

    وقتی چند انتخابگر به یک مجموعه از قانون‌های یکسان نیاز دارند، آن‌ها را با ویرگول جدا می‌کنیم. این کار از تکرار CSS جلوگیری می‌کند. 

    h1,
h2,
h3 {
  font-family: sans-serif;
  color: #234;
}

    نکته

    ویرگول یعنی هر انتخابگر جداگانه انتخاب شود. مثلاً h1, p هم تیترها و هم پاراگراف‌ها را انتخاب می‌کند.

    انتخابگرهای ترکیبی

    انتخابگرهای ترکیبی کمک می‌کنند عنصرها را با توجه به جایگاهشان در ساختار HTML انتخاب کنیم.

    انتخابگر معنا نمونه
    .card p همه‌ی پاراگراف‌های داخل عنصر دارای کلاس card فرزند در هر عمقی
    .card > p پاراگراف‌هایی که فرزند مستقیم card هستند فقط یک سطح پایین‌تر
    h2 + p پاراگراف بلافاصله بعد از h2 همسایه‌ی بعدی
    h2 ~ p پاراگراف‌های بعد از h2 با همان والد همسایه‌های بعدی

    فرزند در هر عمق و فرزند مستقیم

    فاصله‌ی خالی بین دو انتخابگر، همه‌ی عنصرهای منطبق در هر عمقی را انتخاب می‌کند. علامت > فقط فرزند مستقیم را انتخاب می‌کند. 

    /* همه‌ی pهای داخل card، حتی اگر داخل عنصر دیگری باشند */
.card p {
  color: #315b7d;
}

/* فقط pهایی که مستقیماً داخل card هستند */
.card > p {
  font-weight: 700;
}

    انتخابگرهای همسایه

    علامت + عنصر بلافاصله پس از عنصر اول را هدف می‌گیرد. علامت ~ همه‌ی همسایه‌های بعدی منطبق را انتخاب می‌کند؛ در هر دو حالت، عنصرها باید یک والد مشترک داشته باشند. 

    /* پاراگراف بلافاصله پس از h2 */
h2 + p {
  margin-top: 0;
}

/* همه‌ی پاراگراف‌های بعد از h2 با همان والد */
h2 ~ p {
  color: #555;
}

    Specificity یا میزان اختصاصی بودن

    اگر چند قانون متفاوت روی یک عنصر اثر بگذارند، مرورگر برای انتخاب قانون برنده specificity را در نظر می‌گیرد. به‌طور ساده، انتخابگر شناسه از کلاس اختصاصی‌تر است و کلاس از انتخابگر نوعی مانند p اختصاصی‌تر است. 

    p {
  color: black;
}

.message {
  color: blue;
}

#intro {
  color: darkgreen;
}

    اگر هر سه قانون روی یک عنصر اعمال شوند، قانون شناسه معمولاً برنده می‌شود. وقتی specificity برابر باشد، قانونی که دیرتر در CSS آمده است برنده می‌شود.

    از !important بی‌دلیل استفاده نکن

    !important ترتیب عادی اولویت را مختل می‌کند و پیدا کردن علت اعمال نشدن استایل‌ها را دشوار می‌سازد. بهتر است انتخابگرها را ساده و قابل پیش‌بینی نگه داری.

    امتحان کن

    قانون‌های CSS را تغییر بده. مثلاً انتخابگر فرزند مستقیم را با انتخابگر همه‌ی فرزندها مقایسه کن یا specificity انتخابگرها را تغییر بده.

    خلاصه‌ی درس

    • با ویرگول می‌توان چند انتخابگر را برای قانون‌های یکسان گروه‌بندی کرد.
    • فاصله، همه‌ی فرزندهای منطبق در هر عمقی را انتخاب می‌کند.
    • > فقط فرزند مستقیم را انتخاب می‌کند.
    • + همسایه‌ی بلافاصله بعدی و ~ همسایه‌های بعدی را انتخاب می‌کند.
    • در برخورد قانون‌ها، specificity و سپس ترتیب قرارگیری قانون‌ها اهمیت دارد.

    آماده‌ای؟

    با تمرین انتخابگرها، عناصر دقیق‌تری را در صفحه هدف بگیر.

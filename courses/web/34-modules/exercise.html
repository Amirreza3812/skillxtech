تمرین: ماژول‌ها در جاوااسکریپت

تمرین‌ها را با ساخت فایل‌های جداگانه انجام بده و مسیرهای import را بررسی کن.

  1. ساخت یک خروجی نام‌دار

    در فایل calculator.js تابعی به نام multiply بنویس که دو عدد بگیرد و حاصل‌ضرب آن‌ها را برگرداند. تابع را به‌صورت خروجی نام‌دار صادر کن.

    راهنمایی

    تعریف تابع را با export function شروع کن و نتیجه را با return برگردان.

  2. وارد کردن تابع

    در فایل main.js، تابع multiply را از calculator.js وارد کن و حاصل‌ضرب 8 و 5 را در کنسول چاپ کن.

    راهنمایی

    چون خروجی نام‌دار است، نام تابع را داخل آکولاد بنویس. اگر دو فایل کنار هم هستند، مسیر import برابر "./calculator.js" است.

  3. ساخت خروجی پیش‌فرض

    در فایل greeting.js یک تابع به نام greet بنویس که نامی بگیرد و جمله‌ی «سلام، [نام]!» را برگرداند. تابع را به‌صورت خروجی پیش‌فرض صادر کن.

    راهنمایی

    از export default استفاده کن. برای ساخت جمله می‌توانی از template literal استفاده کنی.

  4. اتصال فایل ماژول به HTML

    یک فایل HTML بساز که عنصر p با شناسه‌ی message داشته باشد و فایل main.js را به‌عنوان ماژول بارگذاری کند. در main.js تابع greet را وارد کن و پیام خوش‌آمدگویی را داخل همان عنصر قرار بده.

    راهنمایی

    برای بارگذاری فایل از <script type="module" src="./main.js"> استفاده کن. در جاوااسکریپت، عنصر را با document.querySelector("#message") انتخاب کن.

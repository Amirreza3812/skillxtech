طراحی وب

ماژول‌ها در جاوااسکریپت

یاد می‌گیریم کد جاوااسکریپت را میان فایل‌ها تقسیم کنیم و با export و import بخش‌های موردنیاز را به هم وصل کنیم.

در این درس

    چرا از ماژول استفاده می‌کنیم؟

    وقتی برنامه بزرگ‌تر می‌شود، نگه‌داشتن همه‌ی کدها در یک فایل دشوار است. ماژول‌ها کمک می‌کنند برنامه را به فایل‌های کوچک‌تر تقسیم کنیم؛ هر فایل می‌تواند مسئولیت مشخصی داشته باشد و کدهای لازم را در اختیار فایل‌های دیگر بگذارد.

    برای مثال، می‌توانیم توابع مربوط به محاسبات را در یک فایل و کد مربوط به صفحه را در فایل دیگری بنویسیم. این کار خوانایی و نگه‌داری پروژه را بهتر می‌کند.

    نکته

    در این درس، math.js و main.js نام فایل‌های نمونه‌اند. برای اجرای آن‌ها باید هر دو فایل در پروژه وجود داشته باشند.

    خروجی نام‌دار با export

    برای آن‌که فایل دیگری بتواند یک تابع، متغیر یا مقدار ثابت را استفاده کند، آن را با export صادر می‌کنیم. نمونه‌ی زیر در فایل math.js قرار می‌گیرد: 

    export function add(a, b) {
  return a + b;
}

export const taxRate = 0.09;

    می‌توان چند مقدار را هم در انتهای فایل صادر کرد. در این شکل، نام‌هایی که صادر می‌شوند باید در فهرست export نوشته شوند: 

    function subtract(a, b) {
  return a - b;
}

const appName = "ماشین حساب";

export { subtract, appName };

    یادت باشد

    در خروجی نام‌دار، هر مقدار با همان نامی که صادر شده وارد می‌شود؛ مگر آن‌که هنگام import برایش نام مستعار تعریف کنیم.

    وارد کردن خروجی نام‌دار با import

    در فایل دیگری مثل main.js، از مسیر نسبی فایل مبدأ استفاده می‌کنیم. پسوند .js را هم می‌نویسیم: 

    import { add, taxRate } from "./math.js";

console.log(add(4, 3));
console.log(taxRate);

    آکولادها در این مثال بخشی از دستور import هستند و نام‌ها باید با نام‌های صادرشده یکی باشند. برای انتخاب نام متفاوت می‌توان از as استفاده کرد: 

    import { add as sum } from "./math.js";

console.log(sum(4, 3));

    مسیر فایل را دقیق بنویس

    مسیر ./math.js یعنی فایل math.js در همان پوشه‌ی فایل فعلی قرار دارد. اگر فایل در پوشه‌ی دیگری باشد، مسیر را متناسب با ساختار پروژه تغییر بده.

    خروجی پیش‌فرض

    هر فایل می‌تواند یک خروجی پیش‌فرض داشته باشد. این روش زمانی مفید است که فایل یک مقدار یا کارکرد اصلی دارد: 

    export default function greet(name) {
  return `سلام ${name}`;
}

    خروجی پیش‌فرض را بدون آکولاد وارد می‌کنیم. نامی که هنگام import انتخاب می‌کنیم لازم نیست با نام تابع در فایل اصلی یکسان باشد: 

    import sayHello from "./greet.js";

console.log(sayHello("سارا"));

    یک فایل می‌تواند چند خروجی نام‌دار داشته باشد، اما فقط یک خروجی پیش‌فرض می‌تواند داشته باشد.

    استفاده از ماژول در HTML

    برای آن‌که مرورگر فایل جاوااسکریپت اصلی را به‌صورت ماژول اجرا کند، ویژگی type="module" را به تگ script اضافه می‌کنیم: 

    <script type="module" src="./js/main.js"></script>

    سپس در main.js می‌توانیم مقادیر را از فایل‌های دیگر وارد کنیم: 

    // js/main.js
import { add } from "./math.js";

console.log(add(2, 5));

    پروژه را از سرور اجرا کن

    ماژول‌های مرورگر را با بازکردن مستقیم فایل HTML از نوع file:// اجرا نکن. پروژه را با یک وب‌سرور محلی اجرا کن تا مرورگر فایل‌های ماژول را درست بارگذاری کند.

    امتحان کن

    در مثال زیر، هر دو فایل را کنار هم در یک پوشه قرار بده. فایل HTML فقط main.js را بارگذاری می‌کند؛ این فایل تابع را از math.js وارد می‌کند و نتیجه را در صفحه نمایش می‌دهد. 

    <!-- index.html -->
<p id="result">در حال محاسبه...</p>
<script type="module" src="./main.js"></script>

// math.js
export function multiply(a, b) {
  return a * b;
}

// main.js
import { multiply } from "./math.js";

document.querySelector("#result").textContent =
  `حاصل: ${multiply(6, 7)}`;

    ساختار فایل‌ها

    در این مثال، index.html، main.js و math.js همگی باید در یک پوشه باشند تا مسیرهای نوشته‌شده در کد درست عمل کنند.

    جمع‌بندی

    ماژول‌ها کد را میان فایل‌ها تقسیم می‌کنند. با export مقادیر را در دسترس فایل‌های دیگر می‌گذاریم و با import از آن‌ها استفاده می‌کنیم. خروجی نام‌دار با آکولاد وارد می‌شود، اما خروجی پیش‌فرض بدون آکولاد. برای اجرای ماژول جاوااسکریپت در صفحه، از <script type="module"> استفاده می‌کنیم.

    آماده‌ای؟

    با چند تمرین، export و import را در فایل‌های جداگانه به کار ببر.

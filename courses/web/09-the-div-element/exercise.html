طراحی وب

تمرین: المان div

در هر تمرین، گروه‌بندی محتوا با div و استایل‌دهی به آن را تمرین کن.

  1. گروه‌بندی یک کارت

    عنوان، توضیح و لینک زیر را داخل یک div قرار بده تا همگی اعضای یک گروه باشند.

    راهنمایی

    یک تگ div باز پیش از عنوان و یک تگ بسته بعد از لینک بنویس.

  2. ساخت دو کارت با class

    به هر دو گروه کلاس course-card بده. سپس در CSS برای این کلاس رنگ پس‌زمینه، فاصله‌ی داخلی و حاشیه تعیین کن.

    راهنمایی

    کلاس را داخل تگ باز به شکل class="course-card" بنویس و در CSS با .course-card انتخابش کن.

  3. گروه تو در تو

    اطلاعات دانشجو را داخل divای با کلاس profile-info بگذار. خود این گروه را داخل div دیگری با کلاس profile قرار بده.

    راهنمایی

    گروه profile-info باید فرزند گروه profile باشد؛ تگ‌ها را با ترتیب درست ببند.

  4. انتخاب المان مناسب

    در کد زیر بخش ناوبری با div مشخص شده است. آن را با المان معنادار مناسب جایگزین کن.

    راهنمایی

    برای گروهی از لینک‌های ناوبری از nav استفاده می‌کنیم.

  5. برجسته کردن بخشی از متن

    به عبارت «یادگیری وب» یک span با کلاس highlight اضافه کن. سپس در CSS رنگ متن آن را تغییر بده.

    راهنمایی

    span را دور همان عبارت قرار بده تا فقط همان بخش از جمله انتخاب شود.

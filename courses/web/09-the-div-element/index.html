المان div در HTML

یاد می‌گیری چطور با div چند المان را گروه‌بندی کنی و با CSS روی یک بخش از صفحه اثر بگذاری.

در این درس

    div چیست؟

    div یک المان عمومی برای گروه‌بندی محتواست. خودش معنی ویژه‌ای مثل «سربرگ» یا «منو» ندارد، اما می‌تواند چند المان را کنار هم نگه دارد تا ساختار صفحه را مرتب کنیم یا با CSS به آن‌ها سبک بدهیم.

    div به‌طور پیش‌فرض یک عنصر بلوکی است؛ یعنی معمولاً از خط جدید شروع می‌شود و فضای ردیف را می‌گیرد.

    div به‌تنهایی ظاهر خاصی ندارد

    اگر div خالی باشد یا استایلی برایش ننوشته باشیم، معمولاً چیزی برای دیدن در صفحه ندارد. کاربرد اصلی آن گروه‌بندی و ساختن بخش‌های قابل هدف‌گیری با CSS است.

    گروه‌بندی چند المان

    فرض کن کارت معرفی یک دوره شامل عنوان، توضیح و لینک است. می‌توانی همه‌ی آن‌ها را داخل یک div بگذاری تا یک گروه واحد بسازند.

    در این مثال، div والدِ عنوان، پاراگراف و لینک است و آن سه المان فرزند آن هستند. می‌توانی بخش‌های مختلف صفحه را با همین روش گروه‌بندی کنی.

    استفاده از class برای استایل‌دهی

    برای انتخاب یک div مشخص در CSS، معمولاً به آن یک ویژگی class می‌دهیم. نام کلاس باید توصیفی باشد و در CSS با نقطه نوشته شود.

    نام کلاس را با توجه به نقش انتخاب کن

    نامی مثل course-card درباره‌ی کاربرد گروه توضیح می‌دهد. بهتر است به‌جای نام‌هایی مثل blue-box که فقط رنگ فعلی را بیان می‌کنند، نامی انتخاب کنی که معنی بخش را نشان بدهد.

    قرار دادن div داخل div

    می‌توانی یک گروه را داخل گروه دیگری قرار بدهی. به این کار تو‌در‌تو کردن می‌گویند. برای خوانایی، هر سطح را کمی تورفته‌تر بنویس و تگ‌ها را به‌ترتیب درست ببند.

    چه زمانی از div استفاده کنیم؟

    اگر برای محتوا المانی معنادار وجود دارد، معمولاً همان را انتخاب کن. مثلاً برای سربرگ از header، برای منو از nav و برای محتوای اصلی از main استفاده کن. وقتی المان معناداری مناسب نیست و فقط به یک گروه عمومی نیاز داری، div انتخاب خوبی است.

    نیاز المان پیشنهادی
    گروه عمومی برای CSS div
    سربرگ صفحه یا بخش header
    مجموعه‌ای از لینک‌های ناوبری nav
    محتوای اصلی صفحه main
    یک بخش موضوعی section
    یک مطلب مستقل article

    همه‌چیز را داخل div نگذار

    استفاده‌ی بیش‌ازحد از div می‌تواند ساختار صفحه را نامشخص کند. وقتی یک المان HTML معنای دقیق‌تری دارد، از همان استفاده کن؛ این کار فهم ساختار صفحه را برای ابزارهای کمکی و مرورگرها آسان‌تر می‌کند.

    تفاوت div و span

    هر دو المان عمومی‌اند، اما رفتار پیش‌فرضشان فرق دارد: div بلوکی است و معمولاً برای گروه‌بندی بخش‌های بزرگ‌تر به کار می‌رود؛ span درون‌خطی است و معمولاً برای انتخاب یا استایل دادن به بخشی از متن استفاده می‌شود.

    خلاصه

    • div المانی عمومی برای گروه‌بندی محتواست و به‌تنهایی معنی ویژه‌ای ندارد.
    • برای انتخاب یک گروه در CSS می‌توانی از ویژگی class استفاده کنی.
    • یک div می‌تواند چند فرزند داشته باشد و خودش هم داخل گروه دیگری قرار بگیرد.
    • اگر المان معناداری مثل header یا main مناسب است، آن را به div ترجیح بده.
    • span برای گروه‌بندی درون‌خطی، به‌ویژه بخشی از متن، کاربرد دارد.

    آماده‌ای؟

    با چند تمرین کوتاه، گروه‌بندی محتوا و استایل‌دهی به div را تمرین کن.

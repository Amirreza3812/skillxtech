تمرین: چارچوب‌های تست

فایل‌های تمرین را در یک پروژه‌ی Node.js بساز و تست‌ها را از ترمینال اجرا کن.

  1. تعریف تابع و تست آن

    در فایل multiply.js تابع multiply(a, b) را صادر کن تا حاصل‌ضرب دو ورودی را برگرداند. سپس در multiply.test.js تستی بنویس که بررسی کند multiply(3, 4) برابر با 12 است.

    راهنمایی

    در فایل تست، expect و test را از vitest وارد کن و تابع را از ./multiply.js وارد کن.

  2. تست چند ورودی

    برای تابع multiply تست‌های جداگانه بنویس که حاصل multiply(2, 5)، multiply(0, 8) و multiply(-2, 3) را بررسی کنند.

    راهنمایی

    برای هر حالت از یک test() جدا استفاده کن و مقدار مورد انتظار را با toBe() بررسی کن.

  3. گروه‌بندی تست‌ها

    تست‌های تابع multiply را با describe() زیر عنوان «تابع multiply» گروه‌بندی کن. دست‌کم دو تست داخل گروه قرار بده.

    راهنمایی

    describe را هم از vitest وارد کن و تست‌ها را داخل callback آن بنویس.

  4. اجرای تست‌ها

    Vitest را به‌عنوان وابستگی توسعه نصب کن، در فایل package.json اسکریپت test را اضافه کن و تست‌ها را از ترمینال اجرا کن. نام فایل تست باید شامل .test. یا .spec. باشد.

    راهنمایی

    دستور نصب: npm install -D vitest. سپس در بخش scripts بنویس "test": "vitest" و اجرا کن: npm run test.

توابع در جاوااسکریپت

در این درس یاد می‌گیریم چطور مجموعه‌ای از دستورها را در قالب تابع بنویسیم، آن را اجرا کنیم و با پارامترها و مقدار بازگشتی، کدهای کاربردی‌تر و قابل‌استفاده‌مجدد بسازیم.

در این درس

    تابع چیست؟

    تابع، مجموعه‌ای نام‌گذاری‌شده از دستورهاست که می‌توانیم هر زمان لازم بود آن را اجرا کنیم. به‌جای تکرار یک قطعه کد در چند جای برنامه، آن را یک‌بار در تابع می‌نویسیم و هر بار تابع را صدا می‌زنیم.

    برای نمونه، اگر قرار باشد چند بار پیام خوشامدگویی نمایش دهیم، می‌توانیم دستور نمایش پیام را داخل یک تابع قرار دهیم.

    نکته

    نوشتن تابع به‌تنهایی دستورهای درون آن را اجرا نمی‌کند. برای اجرا باید تابع را با نامش صدا بزنیم.

    تعریف و اجرای تابع

    برای تعریف تابع از واژه‌ی function استفاده می‌کنیم. بعد از آن نام تابع، پرانتز و بدنه‌ی تابع داخل آکولاد قرار می‌گیرد. 

              
          function sayHello() {
            console.log("سلام!");
          }
            sayHello();

    در مثال بالا، sayHello نام تابع است. خط sayHello(); آن را اجرا می‌کند. پرانتزهای خالی نشان می‌دهند که تابع در این مثال ورودی‌ای دریافت نمی‌کند.

    یادت باشد

    نام تابع را با پرانتز تعریف می‌کنیم، اما اجرای آن با نوشتن نام و پرانتز انجام می‌شود؛ مثلاً sayHello().

    پارامترها و آرگومان‌ها

    گاهی می‌خواهیم تابع با ورودی‌های متفاوت کار کند. برای این کار، هنگام تعریف تابع نام ورودی‌ها را داخل پرانتز می‌نویسیم. به این نام‌ها پارامتر می‌گوییم. مقداری که هنگام اجرای تابع به آن می‌دهیم، آرگومان نام دارد. 

    function greet(name) {
  console.log(`سلام، ${name}!`);
}

greet("سارا");
greet("آرمان");

    در این مثال، name پارامتر تابع است. رشته‌های "سارا" و "آرمان" آرگومان‌هایی هستند که در دو اجرای جداگانه به تابع داده شده‌اند.

    چند پارامتر

    یک تابع می‌تواند چند پارامتر داشته باشد. پارامترها را با ویرگول از هم جدا می‌کنیم و هنگام فراخوانی نیز آرگومان‌ها را به همان ترتیب می‌فرستیم. 

    function addNumbers(firstNumber, secondNumber) {
  console.log(firstNumber + secondNumber);
}

addNumbers(4, 6);

    ترتیب ورودی‌ها مهم است

    هر آرگومان بر اساس جایگاهش به پارامتر متناظر می‌رسد. اگر ترتیب آرگومان‌ها را عوض کنیم، مقدار هر پارامتر هم عوض می‌شود.

    بازگرداندن مقدار با return

    console.log() فقط مقداری را در کنسول نمایش می‌دهد؛ اما ممکن است بخواهیم نتیجه‌ی تابع را در ادامه‌ی برنامه استفاده کنیم. در این حالت از return استفاده می‌کنیم. 

    function addNumbers(firstNumber, secondNumber) {
  return firstNumber + secondNumber;
}

const total = addNumbers(4, 6);
console.log(total);

    دستور return نتیجه را از تابع بیرون می‌فرستد و اجرای تابع را در همان نقطه پایان می‌دهد. در مثال بالا، حاصل جمع در متغیر total ذخیره شده است.

    تفاوت return و console.log

    این دو دستور کار یکسانی ندارند: console.log() برای دیدن مقدار در کنسول است، ولی return مقدار را از تابع برمی‌گرداند تا بتوانیم آن را ذخیره کنیم یا در محاسبه‌ی دیگری به کار ببریم. 

    function doubleNumber(number) {
  return number * 2;
}

const result = doubleNumber(5);
console.log(result);

    روش فکر کردن

    اگر هدف فقط بررسی یا نمایش موقت یک مقدار است، از console.log() کمک بگیر. اگر قرار است برنامه با نتیجه‌ی تابع کار کند، معمولاً return انتخاب مناسب‌تری است.

    جمع‌بندی

    در این درس یاد گرفتیم:

    • تابع مجموعه‌ای از دستورهاست که می‌توان آن را دوباره اجرا کرد.
    • با function تابع را تعریف و با نام و پرانتز اجرا می‌کنیم.
    • پارامترها ورودی‌های تابع‌اند و آرگومان‌ها مقدارهایی هستند که می‌فرستیم.
    • return نتیجه را از تابع برمی‌گرداند.
    • console.log() مقدار را در کنسول نمایش می‌دهد و جایگزین return نیست.

    آماده‌ای؟

    با تمرین‌های این درس، تعریف تابع، ورودی‌ها و مقدار بازگشتی را تمرین کن.

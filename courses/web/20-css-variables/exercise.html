تمرین: متغیرهای CSS

متغیرها را تعریف کن و از آن‌ها برای یک‌دست کردن استایل‌ها کمک بگیر.

  1. تعریف رنگ‌های اصلی

    برای :root دو متغیر تعریف کن: یکی برای رنگ اصلی با نام --color-primary و دیگری برای رنگ متن با نام --color-text. سپس از آن‌ها برای عنوان و دکمه استفاده کن.

    راهنمایی

    متغیرها را در :root تعریف کن و در قوانین CSS با var(--color-primary) و var(--color-text) بخوان.

  2. استفاده از فاصله‌ی مشترک

    متغیری به نام --card-padding بساز و مقدار آن را 20px قرار بده. از آن برای فاصله‌ی داخلی دو کارت استفاده کن.

    راهنمایی

    برای هر دو کارت، مقدار padding را با var(--card-padding) تعیین کن.

  3. ساخت کارت با مقدار محلی

    دو کارت بساز. هر دو از متغیرهای رنگی پیش‌فرض استفاده کنند، اما کارت دوم با کلاس dark-card رنگ پس‌زمینه و متن مخصوص خودش را داشته باشد.

    راهنمایی

    مقدارهای پیش‌فرض را در :root بگذار. سپس متغیرها را داخل .dark-card دوباره تعریف کن.

  4. افزودن مقدار جایگزین

    قانون .notice را طوری کامل کن که رنگ متن از --notice-color گرفته شود و اگر متغیر تعریف نشده بود، رنگ #92400e به کار برود.

    راهنمایی

    مقدار جایگزین را بعد از ویرگول داخل var() بنویس: var(--notice-color, مقدار).

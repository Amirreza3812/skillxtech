متغیرهای CSS

یاد می‌گیریم مقدارهای پرتکرار مثل رنگ، فاصله و اندازه را یک‌جا تعریف کنیم و در بخش‌های مختلف استایل‌ها به کار ببریم.

در این درس

    چرا از متغیرهای CSS استفاده کنیم؟

    ممکن است یک رنگ یا فاصله در بخش‌های زیادی از صفحه تکرار شود. اگر بخواهیم آن مقدار را عوض کنیم، بدون متغیر باید تک‌تک محل‌ها را پیدا کنیم. متغیر CSS کمک می‌کند مقدار را یک‌بار تعریف کنیم و هرجا لازم بود از آن استفاده کنیم.

    نام متغیرهای CSS با دو خط تیره آغاز می‌شود؛ برای مثال --main-color. برای خواندن مقدار آن از تابع var() استفاده می‌کنیم.

    نام‌گذاری خوانا

    نامی انتخاب کن که کاربرد مقدار را نشان دهد؛ مثل --color-primary یا --space-large، نه نامی مثل --blue2.

    تعریف متغیر در :root

    برای متغیرهایی که قرار است در سراسر صفحه در دسترس باشند، معمولاً آن‌ها را در انتخابگر :root تعریف می‌کنیم. این انتخابگر به ریشه‌ی سند HTML اشاره دارد. 

    :root {
  --color-primary: #2563eb;
  --color-text: #1f2937;
  --space-medium: 16px;
}

    هر تعریف از نام متغیر، دونقطه، مقدار و نقطه‌ویرگول تشکیل می‌شود. چون نام‌ها با -- شروع می‌شوند، با ویژگی‌های معمول CSS اشتباه گرفته نمی‌شوند.

    استفاده از متغیر با var()

    مقدار تعریف‌شده را داخل var() می‌گذاریم. در این نمونه، رنگ متن و پس‌زمینه‌ی دکمه از متغیرها گرفته شده‌اند: 

    :root {
  --color-primary: #2563eb;
  --color-text: #1f2937;
}

h1 {
  color: var(--color-text);
}

button {
  background-color: var(--color-primary);
}

    مقدار جایگزین

    اگر متغیری تعریف نشده باشد، می‌توانیم در var() یک مقدار جایگزین بنویسیم. مقدار بعد از ویرگول، زمانی استفاده می‌شود که متغیر پیدا نشود: 

    .notice {
  color: var(--notice-color, #92400e);
}

    نکته

    مقدار جایگزین فقط وقتی به کار می‌رود که متغیر در دسترس نباشد؛ نه زمانی که مقدار متغیر با سلیقه‌ی ما متفاوت است.

    محدوده‌ی دسترسی متغیرها

    متغیری که داخل :root تعریف می‌شود، معمولاً در همه‌ی صفحه قابل استفاده است. اما اگر آن را داخل یک کلاس تعریف کنیم، آن متغیر در همان عنصر و فرزندانش در دسترس خواهد بود. 

    .dark-card {
  --card-background: #1f2937;
  --card-text: #f9fafb;

  background-color: var(--card-background);
  color: var(--card-text);
}

    این ویژگی برای ساخت بخش‌هایی با ظاهر متفاوت مفید است؛ مثلاً می‌توانیم متغیرهای یک کارت تیره را فقط در همان کارت تعریف کنیم.

    کاربردهای رایج

    متغیرها برای یک‌دست نگه داشتن طراحی صفحه کاربرد زیادی دارند:

    • رنگ‌های اصلی، فرعی و رنگ متن
    • فاصله‌های پرتکرار بین بخش‌ها و اجزا
    • اندازه‌ی گوشه‌های گرد یا سایه‌ها
    • مقدارهایی که می‌خواهیم برای یک بخش یا تم خاص بازنویسی کنیم

    اشتباه رایج

    نام متغیر باید با دو خط تیره شروع شود. تعریف color-primary به‌تنهایی یک متغیر CSS نمی‌سازد؛ از --color-primary استفاده کن.

    خلاصه

    • نام متغیرهای CSS با -- آغاز می‌شود.
    • برای تعریف متغیرهای عمومی معمولاً از :root استفاده می‌کنیم.
    • برای خواندن مقدار یک متغیر از var(--نام-متغیر) کمک می‌گیریم.
    • می‌توان برای متغیر، مقدار جایگزین تعیین کرد.
    • متغیرهای محلی در عنصر و فرزندانش در دسترس هستند.

    آماده‌ای؟

    با چند تمرین، متغیرهای CSS را در عمل به کار ببر.

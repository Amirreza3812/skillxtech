ویژگی position در CSS

یاد می‌گیری عناصر را با position در جای معمولی خود، نسبت به والد یا نسبت به پنجره‌ی مرورگر قرار بدهی.

در این درس

    ۱. position چه کاری انجام می‌دهد؟

    ویژگی position روش قرارگیری عنصر در صفحه را تعیین می‌کند. مقدار آن مشخص می‌کند عنصر در جریان عادی صفحه باقی بماند، نسبت به جای اصلی‌اش جابه‌جا شود، یا در موقعیتی ویژه قرار بگیرد.

    برای جابه‌جایی عنصر معمولاً از ویژگی‌های top، right، bottom و left استفاده می‌کنیم. این ویژگی‌ها در حالت position: static اثری ندارند.

    نکته

    در صفحه‌های راست‌به‌چپ هم left و right همچنان به سمت فیزیکی چپ و راست اشاره می‌کنند؛ جهت متن، معنای این ویژگی‌ها را عوض نمی‌کند.

    ۲. مقدار static

    مقدار پیش‌فرض همه‌ی عناصر static است. عنصر در جریان عادی سند قرار می‌گیرد و ویژگی‌های top، right، bottom و left آن را جابه‌جا نمی‌کنند. 

    .box {
  position: static;
}

    ۳. مقدار relative

    با position: relative عنصر ابتدا جای معمولی خودش را حفظ می‌کند. سپس می‌توان آن را با ویژگی‌هایی مثل top و left نسبت به همان جای اولیه جابه‌جا کرد.

    فضای اولیه‌ی عنصر در صفحه همچنان رزرو می‌شود؛ بنابراین جابه‌جایی آن معمولاً باعث نمی‌شود عناصر اطراف جای آن را بگیرند. 

    .box {
  position: relative;
  top: 10px;
  left: 12px;
}

    کاربرد رایج

    یک والد را اغلب position: relative می‌کنیم تا فرزندِ position: absolute بتواند نسبت به همان والد جای‌گذاری شود.

    ۴. مقدار absolute

    عنصرِ position: absolute از جریان عادی صفحه خارج می‌شود؛ بنابراین فضای قبلی‌اش دیگر برای آن رزرو نمی‌ماند. موقعیتش نسبت به نزدیک‌ترین والدِ دارای position غیر از static محاسبه می‌شود.

    اگر چنین والدی وجود نداشته باشد، عنصر نسبت به بلوک اولیه‌ی صفحه موقعیت‌گیری می‌شود. 

    .card {
  position: relative;
}

.badge {
  position: absolute;
  top: 12px;
  right: 12px;
}

    والدِ مرجع را مشخص کن

    اگر عنصر مطلق در جای غیرمنتظره‌ای قرار گرفت، والدهایش را بررسی کن. معمولاً باید به والد موردنظر position: relative بدهی.

    ۵. مقدار fixed

    عنصرِ position: fixed معمولاً نسبت به پنجره‌ی مرورگر موقعیت‌گیری می‌شود. با اسکرول صفحه، در همان موقعیتِ صفحه‌نمایش می‌ماند؛ مثلاً برای دکمه‌ی بازگشت به بالای صفحه یا نوار ثابت. 

    .back-to-top {
  position: fixed;
  right: 20px;
  bottom: 20px;
}

    ۶. مقدار sticky

    عنصرِ position: sticky ابتدا در جریان عادی صفحه قرار می‌گیرد. هنگام اسکرول، پس از رسیدن به حدی که با top یا یکی از ویژگی‌های مشابه تعیین شده، در محدوده‌ی والدش می‌چسبد.

    برای چسبیدن به بالای ناحیه‌ی پیمایش، معمولاً باید top هم تعیین شود. 

    .section-title {
  position: sticky;
  top: 0;
}

    ۷. ترتیب لایه‌ها با z-index

    وقتی عناصر روی هم قرار می‌گیرند، ویژگی z-index می‌تواند ترتیب نمایش آن‌ها را کنترل کند. عدد بزرگ‌تر معمولاً عنصر را روی عنصرهای با عدد کوچک‌تر نشان می‌دهد. 

    .modal {
  position: fixed;
  z-index: 10;
}

.tooltip {
  position: absolute;
  z-index: 20;
}

    درباره‌ی z-index

    z-index به‌تنهایی جای عنصر را تعیین نمی‌کند و ممکن است تحت تأثیر زمینه‌های لایه‌ای والدها قرار بگیرد. اگر نتیجه مطابق انتظار نبود، موقعیت و ساختار والدها را هم بررسی کن.

    ۸. نمونه را امتحان کن

    مقدار position نشان را عوض کن. با تغییر top و right هم جابه‌جایی آن را بررسی کن.

    ۹. مقایسه‌ی مقدارها

    مقدار رفتار کلی مبنای موقعیت‌گیری
    static در جریان عادی صفحه می‌ماند موقعیت عادی سند
    relative جای اولیه‌اش را حفظ می‌کند و از آن جابه‌جا می‌شود جای اولیه‌ی خودش
    absolute از جریان عادی خارج می‌شود نزدیک‌ترین والدِ موقعیت‌دار
    fixed معمولاً هنگام اسکرول در جای صفحه‌نمایش می‌ماند پنجره‌ی مرورگر
    sticky در محدوده‌ی والد به لبه می‌چسبد جای عادی و محدوده‌ی پیمایش

    خلاصه‌ی درس

    • static حالت پیش‌فرض است و با ویژگی‌های جهت‌دار جابه‌جا نمی‌شود.
    • relative عنصر را نسبت به جای اولیه‌اش جابه‌جا می‌کند.
    • absolute عنصر را از جریان عادی خارج می‌کند.
    • fixed برای قرارگیری ثابت نسبت به پنجره‌ی مرورگر کاربرد دارد.
    • sticky پس از رسیدن به حد تعیین‌شده، در محدوده‌ی والد می‌چسبد.
    • z-index به کنترل ترتیب لایه‌ها کمک می‌کند.

    آماده‌ای؟

    در تمرین‌ها از position برای جای‌گذاری عناصر استفاده کن.

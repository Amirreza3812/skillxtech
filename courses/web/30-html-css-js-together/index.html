طراحی وب

ترکیب HTML و CSS و JavaScript

یاد می‌گیریم HTML را برای ساختار صفحه، CSS را برای ظاهر و JavaScript را برای رفتارهای تعاملی به کار ببریم و این سه را به هم متصل کنیم.

در این درس

    سه زبان، سه نقش

    یک صفحه‌ی وب معمولاً از سه بخش مکمل ساخته می‌شود. HTML عناصر صفحه را تعریف می‌کند، CSS ظاهر آن‌ها را می‌سازد و JavaScript به صفحه رفتار و واکنش اضافه می‌کند.

    فناوری نقش نمونه
    HTML ساختار و محتوا عنوان، دکمه و پاراگراف
    CSS ظاهر و چیدمان رنگ، اندازه و فاصله
    JavaScript رفتار و تعامل واکنش به کلیک دکمه

    یک تشبیه ساده

    HTML شبیه اسکلت ساختمان، CSS شبیه طراحی و رنگ‌آمیزی آن و JavaScript شبیه بخش‌هایی است که با استفاده از آن‌ها می‌توان کاری انجام داد.

    اتصال فایل CSS

    برای اینکه فایل CSS جداگانه به صفحه متصل شود، از عنصر <link> در بخش <head> استفاده می‌کنیم. مقدار href باید مسیر درست فایل CSS باشد. 

    <head>
  <link rel="stylesheet" href="css/style.css">
</head>

    اگر فایل HTML و پوشه‌ی css هم‌سطح باشند، مسیر css/style.css از محل فایل HTML شروع می‌شود.

    اتصال فایل JavaScript

    فایل JavaScript را می‌توان با عنصر <script> به صفحه متصل کرد. قرار دادن آن نزدیک پایان <body> باعث می‌شود عناصر صفحه پیش از اجرای اسکریپت خوانده شوند. 

    <body>
  <h1>صفحه‌ی من</h1>

  <script src="js/main.js"></script>
</body>

    نکته

    مسیر فایل در ویژگی src نسبت به فایل HTML نوشته می‌شود؛ مثلاً اگر فایل در پوشه‌ی js باشد، مسیر js/main.js است.

    سه فایل را به هم متصل کنیم

    در یک پروژه‌ی کوچک می‌توانیم فایل HTML را در ریشه‌ی پروژه و فایل‌های CSS و JavaScript را در پوشه‌های جداگانه قرار دهیم: 

    my-page/
├── index.html
├── css/
│   └── style.css
└── js/
    └── main.js

    در فایل index.html، هر دو فایل را به این شکل متصل کن:

    <head>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <button id="message-button">نمایش پیام</button>
  <p id="message">هنوز دکمه را نزده‌ای.</p>

  <script src="js/main.js"></script>
</body>

    حالا CSS می‌تواند ظاهر عناصر را تغییر دهد و JavaScript می‌تواند با پیدا کردن آن‌ها در DOM، به رویدادها پاسخ دهد.

    ساخت یک تعامل ساده

    در نمونه‌ی زیر، با کلیک روی دکمه، متن پاراگراف عوض می‌شود و یک کلاس CSS نیز به آن اضافه می‌شود. کد را اجرا و سپس بخش‌های مختلف آن را تغییر بده.

    کد را مرحله‌به‌مرحله دنبال کنیم

    ابتدا HTML دکمه و پاراگراف را می‌سازد. ویژگی‌های id به JavaScript کمک می‌کنند هر عنصر را پیدا کند. سپس querySelector() هر دو عنصر را انتخاب می‌کند.

    addEventListener("click", ...) می‌گوید هنگام کلیک روی دکمه، تابع داخل آن اجرا شود. تابع متن پاراگراف را با textContent عوض می‌کند و با classList.add() کلاس highlight را به آن اضافه می‌کند. در نهایت CSS ظاهر این کلاس را مشخص می‌کند.

    اشتباه رایج در مسیر فایل‌ها

    اگر فایل CSS یا JavaScript بارگذاری نشود، مسیر href یا src را بررسی کن. نام پوشه‌ها و فایل‌ها باید دقیقاً با ساختار پروژه مطابقت داشته باشد.

    جمع‌بندی

    HTML ساختار، CSS ظاهر و JavaScript رفتار صفحه را مدیریت می‌کنند. فایل CSS با <link> و فایل JavaScript با <script> متصل می‌شود. JavaScript می‌تواند عناصر HTML را انتخاب کند، به رویدادهایی مثل کلیک گوش دهد و با تغییر متن یا کلاس‌ها، صفحه را به‌روز کند.

    آماده‌ای؟

    با تمرین‌های این درس، سه بخش یک صفحه‌ی وب را به هم وصل کن.

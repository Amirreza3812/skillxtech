تمرین: ترکیب HTML و CSS و JavaScript

در هر تمرین، ساختار HTML را بساز، ظاهرش را با CSS تنظیم کن و با JavaScript به صفحه رفتار تعاملی بده.

  1. اتصال سه بخش

    یک صفحه با عنوان، یک پاراگراف و یک دکمه بساز. یک قانون CSS اضافه کن که دکمه را رنگی کند و فایل JavaScript را به صفحه متصل کن تا هنگام بارگذاری، پیامی را با console.log() نمایش دهد.

    راهنمایی

    CSS را داخل تگ <style> و JavaScript را داخل تگ <script> بنویس. هر سه عنصر می‌توانند در یک فایل HTML باشند.

  2. تغییر متن با کلیک

    دکمه‌ای بساز که با کلیک روی آن، متن یک پاراگراف تغییر کند. از document.querySelector() برای انتخاب عناصر و از addEventListener() برای تشخیص کلیک استفاده کن.

    راهنمایی

    به دکمه و پاراگراف id بده. داخل تابع رویداد، مقدار textContent پاراگراف را تغییر بده.

  3. تغییر ظاهر با کلاس

    با کلیک روی دکمه، کلاس active را به یک پیام اضافه کن. در CSS، برای این کلاس رنگ متن و رنگ پس‌زمینه‌ی متفاوتی تعیین کن.

    راهنمایی

    از classList.add("active") در تابع کلیک استفاده کن. تعریف کلاس .active را در بخش CSS بنویس.

  4. ساخت دکمه‌ی روشن و خاموش

    یک دکمه بساز که با هر کلیک، کلاس active را روی یک کارت روشن یا خاموش کند. متن دکمه را هم با استفاده از JavaScript متناسب با وضعیت کارت تغییر بده.

    راهنمایی

    برای روشن و خاموش کردن کلاس از classList.toggle("active") استفاده کن. وضعیت کلاس را با classList.contains("active") بررسی کن.

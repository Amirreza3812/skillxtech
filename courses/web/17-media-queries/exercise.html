تمرین: Media Query در CSS

کدها را کامل کن و اندازه‌ی کادر پیش‌نمایش را برای دیدن تغییرات عوض کن.

  1. تغییر رنگ در صفحه‌ی بزرگ‌تر

    با یک Media Query کاری کن که پس‌زمینه‌ی جعبه در عرض‌های ۶۰۰ پیکسل یا بیشتر سبز شود.

    راهنمایی

    از شرط min-width: 600px استفاده کن.

  2. کارت‌ها در موبایل و دسکتاپ

    کارت‌ها را در حالت پایه زیر هم نمایش بده. از عرض ۷۰۰ پیکسل به بالا، آن‌ها را در دو ستون قرار بده.

    راهنمایی

    برای حالت پایه از یک ستون و داخل @media (min-width: 700px) از دو ستون استفاده کن.

  3. تغییر اندازه‌ی عنوان

    اندازه‌ی عنوان را در حالت پایه ۲۴ پیکسل بگذار. از عرض ۸۰۰ پیکسل به بالا، اندازه‌اش را به ۳۶ پیکسل تغییر بده.

    راهنمایی

    قانون پایه را بیرون از Media Query بنویس و مقدار بزرگ‌تر را در شرط min-width قرار بده.

  4. شرط عرض و جهت نمایشگر

    پس‌زمینه‌ی بنر را فقط زمانی نارنجی کن که عرض صفحه حداقل ۷۰۰ پیکسل و جهت نمایشگر افقی باشد.

    راهنمایی

    شرط‌ها را در یک Media Query با and ترکیب کن و از orientation: landscape استفاده کن.

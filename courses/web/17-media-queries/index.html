Media Query در CSS

یاد می‌گیری با استفاده از Media Query، ظاهر صفحه را برای اندازه‌های مختلف نمایشگر تغییر بدهی و چیدمانی واکنش‌گرا بسازی.

در این درس

    Media Query چیست؟

    Media Query روشی در CSS است که به کمک آن می‌توانیم برای شرایط مختلف، مثل عرض صفحه یا جهت نمایشگر، قانون‌های متفاوتی بنویسیم. برای مثال، ممکن است کارت‌ها در صفحه‌ی بزرگ کنار هم باشند، اما در صفحه‌ی کوچک زیر یکدیگر قرار بگیرند.

    پیش‌نیاز مهم

    برای اینکه مرورگر صفحه را با عرض واقعی دستگاه نمایش دهد، سند HTML باید شامل تگ viewport باشد: 

    <meta name="viewport" content="width=device-width, initial-scale=1">

    ساختار پایه

    قانون‌های داخل @media فقط زمانی اجرا می‌شوند که شرط نوشته‌شده برقرار باشد. در نمونه‌ی زیر، رنگ پس‌زمینه از عرض ۶۰۰ پیکسل به بالا عوض می‌شود: 

    .box {
  background: lightblue;
}

@media (min-width: 600px) {
  .box {
    background: lightgreen;
  }
}

    شرط min-width: 600px یعنی عرض صفحه باید حداقل ۶۰۰ پیکسل باشد. شرط max-width: 600px یعنی عرض صفحه حداکثر ۶۰۰ پیکسل باشد.

    توجه به مرزها

    در شرط‌های min-width و max-width مقدار مرزی هم شامل شرط می‌شود. برای جلوگیری از هم‌پوشانی قانون‌ها، مرزها را با دقت انتخاب کن.

    روش Mobile First

    در روش Mobile First، ابتدا استایل ساده و مناسب صفحه‌ی کوچک را می‌نویسیم؛ سپس با min-width برای صفحه‌های بزرگ‌تر تغییرات لازم را اضافه می‌کنیم. 

    /* استایل پایه: صفحه‌های کوچک */
.cards {
  display: grid;
  grid-template-columns: 1fr;
  gap: 1rem;
}

/* صفحه‌های بزرگ‌تر */
@media (min-width: 700px) {
  .cards {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (min-width: 1000px) {
  .cards {
    grid-template-columns: repeat(3, 1fr);
  }
}

    این روش کمک می‌کند استایل پایه برای موبایل قابل استفاده باشد و فقط تغییرات لازم برای صفحه‌های بزرگ‌تر را اضافه کنیم.

    انتخاب Breakpoint

    Breakpoint نقطه‌ای از عرض صفحه است که در آن چیدمان تغییر می‌کند. لازم نیست برای مدل‌های خاص گوشی یا تبلت عددهای زیادی حفظ کنی. ابتدا محتوای صفحه را بررسی کن و هرجا چیدمان دیگر مناسب نبود، یک breakpoint اضافه کن.

    برای نمونه، اگر کارت‌ها در عرض کم فشرده شده‌اند، می‌توانی از یک ستون به دو ستون تغییرشان بدهی. مقدار breakpoint به محتوای همان صفحه بستگی دارد.

    امتحان کن

    عرض کادر پیش‌نمایش را تغییر بده. وقتی عرض به ۶۰۰ پیکسل یا بیشتر برسد، کارت‌ها کنار هم نمایش داده می‌شوند.

    شرط‌های دیگر

    Media Query فقط برای عرض صفحه نیست. برای مثال، با orientation می‌توان جهت نمایشگر را بررسی کرد. شرط‌های مختلف را هم می‌توان با and ترکیب کرد: 

    /* صفحه‌ای با عرض حداقل 700px و حالت افقی */
@media (min-width: 700px) and (orientation: landscape) {
  .banner {
    min-height: 50vh;
  }
}

    روش بررسی

    در مرورگر، ابزارهای توسعه‌دهنده را باز کن و حالت نمایش موبایل یا تغییر اندازه‌ی صفحه را به کار ببر. سپس بررسی کن که محتوا در عرض‌های مختلف خوانا و قابل استفاده باشد.

    خلاصه‌ی درس

    • Media Query اجازه می‌دهد CSS را بر اساس شرایط صفحه تغییر بدهی.
    • min-width برای عرض برابر یا بزرگ‌تر از مقدار تعیین‌شده است.
    • max-width برای عرض برابر یا کوچک‌تر از مقدار تعیین‌شده است.
    • در روش Mobile First، ابتدا استایل موبایل و سپس استایل صفحه‌های بزرگ‌تر را می‌نویسیم.
    • Breakpoint را با توجه به نیاز چیدمان انتخاب کن، نه فقط نام دستگاه.

    آماده‌ای؟

    در تمرین‌ها، چیدمان‌ها را برای عرض‌های مختلف تنظیم کن.

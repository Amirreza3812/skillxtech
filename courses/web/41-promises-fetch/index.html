Promise و Fetch در جاوااسکریپت

با Promiseها و وضعیت‌های آن‌ها آشنا می‌شوی و یاد می‌گیری با fetch() درخواستی بفرستی، پاسخ را بررسی کنی و خطاها را مدیریت کنی.

در این درس

    ۱. کارهای غیرهم‌زمان

    بعضی کارها زمان می‌برند؛ برای نمونه، دریافت داده از یک سرور. جاوااسکریپت می‌تواند منتظر پایان چنین کاری بماند، بی‌آنکه اجرای بقیه‌ی برنامه را متوقف کند. به این نوع کار، غیرهم‌زمان یا asynchronous می‌گوییم.

    برای مدیریت نتیجه‌ی یک کار غیرهم‌زمان، یکی از ابزارهای جاوااسکریپت Promise است.

    ۲. Promise و وضعیت‌های آن

    Promise نماینده‌ی نتیجه‌ای است که ممکن است در آینده آماده شود. این نتیجه معمولاً در یکی از سه وضعیت قرار دارد:

    • pending: کار هنوز تمام نشده است.
    • fulfilled: کار با موفقیت پایان یافته است.
    • rejected: کار با خطا پایان یافته است.

    به‌جای متوقف‌کردن برنامه تا آماده‌شدن نتیجه، می‌توانیم مشخص کنیم پس از موفقیت یا خطا چه کاری انجام شود.

    ۳. استفاده از then و catch

    متد .then() برای رسیدگی به نتیجه‌ی موفق و .catch() برای رسیدگی به خطا به کار می‌روند. معمولاً متدهایی که برای کارهای غیرهم‌زمان استفاده می‌شوند یک Promise برمی‌گردانند. 

    const promise = new Promise((resolve) => {
  resolve("کار با موفقیت انجام شد.");
});

promise
  .then((result) => {
    console.log(result);
  })
  .catch((error) => {
    console.error(error);
  });

    در این مثال، تابع resolve() نتیجه‌ی موفق را اعلام می‌کند. برای اعلام شکست می‌توان از reject() استفاده کرد. 

    const promise = new Promise((resolve, reject) => {
  const succeeded = true;

  if (succeeded) {
    resolve("همه‌چیز خوب است.");
  } else {
    reject(new Error("عملیات ناموفق بود."));
  }
});

promise
  .then((result) => console.log(result))
  .catch((error) => console.error(error.message));

    Promiseهای زنجیره‌ای

    اگر داخل تابع then() یک مقدار برگردانی، آن مقدار به مرحله‌ی بعدی زنجیره می‌رود. اگر Promise برگردانی، مرحله‌ی بعد پس از تعیین نتیجه‌ی آن Promise اجرا می‌شود.

    ۴. فرستادن درخواست با fetch

    تابع fetch() برای فرستادن درخواست شبکه استفاده می‌شود و یک Promise برمی‌گرداند. وقتی پاسخ اولیه برسد، Promise آن با یک شیء Response موفق می‌شود.

    اگر پاسخ شامل JSON باشد، می‌توانیم با متد response.json() محتوای آن را بخوانیم. این متد هم یک Promise برمی‌گرداند؛ بنابراین نتیجه‌اش را با then() دریافت می‌کنیم. 

    fetch("https://jsonplaceholder.typicode.com/todos/1")
  .then((response) => response.json())
  .then((data) => {
    console.log(data);
  })
  .catch((error) => {
    console.error("مشکلی در درخواست پیش آمد:", error);
  });

    ۵. بررسی موفقیت پاسخ با response.ok

    یک نکته‌ی مهم: fetch() معمولاً به‌خاطر دریافت پاسخ HTTP مانند 404 یا 500 به‌تنهایی وارد catch() نمی‌شود. پاسخ سرور دریافت شده، اما نشان می‌دهد درخواست موفق نبوده است. برای بررسی این وضعیت، ویژگی response.ok را کنترل کن. 

    fetch("https://jsonplaceholder.typicode.com/todos/1")
  .then((response) => {
    if (!response.ok) {
      throw new Error(`خطای HTTP: ${response.status}`);
    }

    return response.json();
  })
  .then((data) => {
    console.log(data);
  })
  .catch((error) => {
    console.error("خطا:", error.message);
  });

    دو نوع خطا را از هم جدا کن

    catch() برای خطاهایی مثل قطع اتصال یا خطایی که خودمان با throw پرتاب می‌کنیم به کار می‌آید. چون پاسخ ناموفق HTTP لزوماً Promise مربوط به fetch() را رد نمی‌کند، معمولاً باید response.ok را هم بررسی کنیم.

    ۶. استفاده از finally

    متد .finally() پس از پایان Promise اجرا می‌شود؛ چه Promise موفق شده باشد و چه با خطا پایان یافته باشد. برای نمونه، می‌توان از آن برای پاک‌کردن وضعیت «در حال بارگذاری» استفاده کرد. 

    fetch("https://jsonplaceholder.typicode.com/todos/1")
  .then((response) => {
    if (!response.ok) {
      throw new Error("دریافت داده ناموفق بود.");
    }

    return response.json();
  })
  .then((data) => {
    console.log(data);
  })
  .catch((error) => {
    console.error(error.message);
  })
  .finally(() => {
    console.log("درخواست پایان یافت.");
  });

    ۷. امتحان کن

    دکمه را بزن تا داده‌ی آزمایشی از یک API دریافت شود و عنوان آن در صفحه نمایش داده شود. این مثال به اتصال اینترنت نیاز دارد. اگر درخواست ناموفق بود، پیام خطا را در صفحه و کنسول بررسی کن.

    ۸. جمع‌بندی

    Promise نماینده‌ی نتیجه‌ی یک کار غیرهم‌زمان است و می‌تواند در وضعیت انتظار، موفق یا ناموفق باشد. با then() نتیجه‌ی موفق و با catch() خطا را مدیریت می‌کنیم؛ finally() پس از پایان کار اجرا می‌شود. تابع fetch() برای درخواست شبکه Promise برمی‌گرداند. در پاسخ JSON، ابتدا موفقیت HTTP را با response.ok بررسی کن و سپس محتوای پاسخ را با response.json() بخوان.

    آماده‌ای؟

    با زنجیره‌کردن Promiseها و دریافت داده با fetch تمرین کن.

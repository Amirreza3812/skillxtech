تمرین: مدل جعبه‌ای در CSS

مقدارهای CSS را تغییر بده و اثر آن‌ها را روی اندازه و فاصله‌ی جعبه‌ها ببین.

  1. اضافه کردن فاصله‌ی داخلی

    برای جعبه ۲۰ پیکسل فاصله‌ی داخلی، کادر آبی ۳ پیکسلی و فاصله‌ی بیرونی ۱۲ پیکسلی تنظیم کن.

    راهنمایی

    از ویژگی‌های padding، border و margin استفاده کن.

  2. محاسبه با content-box

    عرض محتوا را ۲۰۰ پیکسل، padding را ۱۰ پیکسل و border را ۴ پیکسل قرار بده. عرض نهایی جعبه چند پیکسل می‌شود؟

    راهنمایی

    در content-box، دو طرف padding و دو طرف border را هم به عرض محتوا اضافه کن.

  3. ثابت نگه داشتن عرض با border-box

    عرض جعبه را ۲۸۰ پیکسل نگه دار و برای آن ۲۴ پیکسل padding و border دوپیکسلی تنظیم کن. از border-box استفاده کن.

    راهنمایی

    با box-sizing: border-box، عرض تعیین‌شده شامل padding و border هم می‌شود.

  4. فاصله‌ی متفاوت در چهار طرف

    با یک اعلان کوتاه، margin را طوری تنظیم کن که بالا ۸، راست ۱۶، پایین ۲۴ و چپ ۳۲ پیکسل باشد.

    راهنمایی

    در شکل چهارمقداری، ترتیب مقادیر بالا، راست، پایین و چپ است.

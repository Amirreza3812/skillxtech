طراحی وب

مدل جعبه‌ای در CSS

یاد می‌گیری هر عنصر HTML چگونه از محتوا، فاصله‌ی داخلی، کادر و فاصله‌ی بیرونی تشکیل می‌شود و چطور اندازه‌ی نهایی آن را کنترل کنی.

در این درس

    مدل جعبه‌ای چیست؟

    مرورگر هر عنصر را مانند یک جعبه در نظر می‌گیرد. این جعبه از چهار بخش تشکیل شده است: محتوای عنصر، فاصله‌ی داخلی، کادر و فاصله‌ی بیرونی. تنظیم این بخش‌ها روی اندازه و جای عنصر در صفحه اثر می‌گذارد.

    ترتیب بخش‌ها

    از داخل به بیرون: content، سپس padding، بعد border و در آخر margin.

    محتوا و فاصله‌ی داخلی

    content همان محتوای عنصر است؛ مثل متن یا تصویر. ویژگی padding فاصله‌ی بین محتوا و کادر را تنظیم می‌کند. پس‌زمینه‌ی عنصر معمولاً محتوای داخلی و padding را می‌پوشاند. 

    .card {
  width: 240px;
  padding: 20px;
  background: #e7f2ff;
}

    در این مثال، عرض محتوا ۲۴۰ پیکسل است. با مقدار پیش‌فرض box-sizing: content-box، padding به عرض بیرونی اضافه می‌شود.

    کادر و فاصله‌ی بیرونی

    ویژگی border خط دور عنصر را تعیین می‌کند. ویژگی margin فاصله‌ی بیرونی عنصر را تنظیم می‌کند؛ یعنی فضای اطرافش تا عنصرهای دیگر. 

    .card {
  border: 2px solid #4677a8;
  margin: 16px;
}

    تفاوت padding و margin

    اگر می‌خواهی فضای داخلی عنصر، بین محتوا و کادر، را زیاد کنی از padding استفاده کن. برای فاصله‌ی عنصر از عنصرهای اطرافش از margin استفاده کن.

    محاسبه‌ی اندازه‌ی عنصر

    با مقدار پیش‌فرض content-box، عرض نهایی عنصر برابر است با عرض محتوا به‌علاوه‌ی padding چپ و راست و border چپ و راست. به همین دلیل ممکن است عنصری که عرضش را ۳۰۰ پیکسل تعیین کرده‌ای، در صفحه از ۳۰۰ پیکسل عریض‌تر شود. 

    .box {
  width: 300px;
  padding: 20px;
  border: 5px solid #333;
}

/* عرض نهایی:
   300 + 20 + 20 + 5 + 5 = 350px
*/

    استفاده از box-sizing

    وقتی box-sizing: border-box را تنظیم می‌کنی، مقدار width شامل محتوای عنصر، padding و border می‌شود. این روش محاسبه‌ی ابعاد را ساده‌تر و قابل پیش‌بینی‌تر می‌کند. 

    * {
  box-sizing: border-box;
}

.box {
  width: 300px;
  padding: 20px;
  border: 5px solid #333;
}

/* عرض بیرونی عنصر 300px می‌ماند */

    الگوی رایج

    بسیاری از طراحان این قانون را ابتدای CSS می‌گذارند تا محاسبه‌ی عرض عنصرها ساده‌تر شود: 

    *,
*::before,
*::after {
  box-sizing: border-box;
}

    تعیین فاصله‌ها با یک مقدار یا چند مقدار

    برای padding و margin می‌توانی به‌جای نوشتن چهار ویژگی جدا، از شکل کوتاه استفاده کنی:

    نمونه نتیجه
    margin: 10px; هر چهار طرف ۱۰ پیکسل
    margin: 10px 20px; بالا و پایین ۱۰، چپ و راست ۲۰ پیکسل
    margin: 10px 20px 30px; بالا ۱۰، چپ و راست ۲۰، پایین ۳۰ پیکسل
    margin: 10px 20px 30px 40px; بالا، راست، پایین، چپ؛ به همین ترتیب

    امتحان کن

    عرض، padding، border و box-sizing را تغییر بده. دقت کن که تغییر box-sizing چه اثری روی عرض بیرونی جعبه دارد.

    خلاصه‌ی درس

    • مدل جعبه‌ای از محتوا، padding، border و margin تشکیل شده است.
    • padding فاصله‌ی محتوا تا کادر را تعیین می‌کند.
    • margin فاصله‌ی بیرونی عنصر را تنظیم می‌کند.
    • در content-box، padding و border به عرض تعیین‌شده اضافه می‌شوند.
    • در border-box، عرض تعیین‌شده شامل padding و border است.

    آماده‌ای؟

    با تمرین‌های این درس، اندازه و فاصله‌ی جعبه‌ها را کنترل کن.

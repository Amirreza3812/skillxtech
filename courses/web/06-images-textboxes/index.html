طراحی وب

تصویر و کادر متن

عکس را در صفحه بیاور و با object-fit اندازه‌اش را کنترل کن. بعد با کادر متن و چند کادر انتخابی، آماده‌ی ساختن فرم شو.

در این درس

    تگ img

    برای آوردن عکس در صفحه از تگ img استفاده می‌کنیم. این تگ محتوا و تگ بسته ندارد و همه‌ی اطلاعاتش در ویژگی‌هاست:

    • src: آدرس عکس (مهم‌ترین ویژگی)
    • alt: توضیح متنی عکس، که اگر عکس نیامد یا کاربر نابینا بود خوانده می‌شود
    • width و height: عرض و ارتفاع به پیکسل (اختیاری)

    نیاز به اینترنت

    عکس‌های نمونه‌ی این درس از سایت placehold.co می‌آیند که تصویرهای رنگی نمونه می‌سازد. پس برای دیدنشان باید اینترنت وصل باشد.

    نوشتن آدرس عکس در src

    مهم‌ترین قسمت کار با عکس این است که آدرس را درست بنویسی. اگر اشتباه باشد مرورگر عکس را پیدا نمی‌کند و به‌جای آن فقط متن alt را نشان می‌دهد:

    ۱. عکس از روی اینترنت

    آدرس کامل عکس را که با https:// شروع می‌شود می‌نویسیم:

    <img src="https://placehold.co/300x150" alt="نمونه">

    برای پیدا کردن آدرس یک عکس در سایت‌ها، روی آن راست‌کلیک کن و Copy image address را بزن، یا از Inspect استفاده کن. روش دوم را در درس Chrome DevTools دیدی.

    عکسی که از سایت دیگری می‌آید ممکن است عوض شود یا از بین برود

    اگر صاحب سایت عکس را حذف کند، عکس تو هم می‌پرد. برای عکس‌های مهم سایتت، فایل را دانلود کن (اگر مجوز داشتی) و در پوشه‌ی خودت بگذار.

    ۲. عکس از روی کامپیوتر خودمان

    وقتی عکس در پوشه‌ی پروژه‌ی خودت است، آدرس را «نسبت به فایل HTML» می‌نویسیم. فرض کن ساختار پروژه این باشد:

    my-site/
├── index.html
├── logo.png
├── images/
│   ├── photo.jpg
│   └── icons/
│       └── star.png
└── pages/
    └── contact.html
    صفحه‌ی HTMLعکسآدرس در src
    index.htmllogo.png (کنار صفحه)logo.png
    index.htmlimages/photo.jpgimages/photo.jpg
    index.htmlimages/icons/star.pngimages/icons/star.png
    pages/contact.htmlimages/photo.jpg../images/photo.jpg
    pages/contact.htmllogo.png../logo.png

    قاعده‌ی ساده‌ای دارد:

    1. از پوشه‌ای که خود فایل HTML در آن است شروع کن.
    2. هر ../ یعنی «یک پوشه بیا بالا».
    3. بعد اسم پوشه‌ها را با / بنویس تا به اسم فایل برسی.
    <!-- در index.html -->
<img src="images/photo.jpg" alt="عکس من">

<!-- در pages/contact.html -->
<img src="../images/photo.jpg" alt="عکس من">

    آدرس را خودت تایپ نکن

    در VS Code روی فایل عکس (در فهرست فایل‌ها) راست‌کلیک کن و Copy Relative Path را بزن. آدرس نسبی آن را می‌دهد که می‌توانی در src بچسبانی. اگر در پوشه‌ی دیگری از پروژه هستی، ممکن است لازم شود فقط ../ اضافه کنی.

    اشتباه‌هایی که باعث می‌شوند عکس نیاید

    • آدرس کامل کامپیوتر خودت. مثل C:\Users\Ali\photo.jpg. روی کامپیوتر تو کار می‌کند ولی روی GitHub Pages و کامپیوتر بقیه نه.
    • شروع آدرس با /. مثل /images/photo.jpg. این آدرس از ریشه‌ی کل دامنه شروع می‌شود و روی GitHub Pages (که سایتت زیر اسم ریپازیتوری است) درست جواب نمی‌دهد. از آدرس نسبی بدون / در ابتدا استفاده کن.
    • حروف بزرگ و کوچک. Photo.JPG با photo.jpg فرق دارد. اسم فایل‌ها را کوچک و بدون فاصله بنویس.
    • پسوند اشتباه. اگر فایل photo.png است، نباید photo.jpg بنویسی. پسوند فایل‌ها را در سیستم‌عاملت قابل مشاهده کن.
    • اسم فارسی یا فاصله در اسم فایل. کار می‌کند ولی دردسر می‌سازد. فایل‌ها را انگلیسی و با خط تیره نام‌گذاری کن، مثل my-photo.jpg.

    وقتی عکس نمی‌آید

    صفحه را Inspect کن و به پنل Network برو. اگر کنار عکس خطای 404 بود یعنی مرورگر فایلی با آن آدرس پیدا نکرده و باید مسیر را بازبینی کنی.

    اندازه‌ی عکس با CSS

    اندازه‌ی عکس را هم می‌شود در HTML (width و height) و هم با CSS تنظیم کرد. CSS معمولاً بهتر است چون می‌شود همه‌ی عکس‌ها را با یک قانون کنترل کرد.

    • اگر فقط width بدهی، ارتفاع خودکار و با نسبت درست محاسبه می‌شود.
    • اگر هر دو را بدهی و نسبتشان با نسبت عکس فرق داشته باشد، عکس کش می‌آید و خراب می‌شود (مثل مثال دوم).
    • max-width: 100% کاری می‌کند که عکس هیچ‌وقت از عرض جایی که در آن است بزرگ‌تر نشود. برای صفحه‌هایی که روی موبایل هم باز می‌شوند خیلی مفید است.

    عکس‌هایت را سبک کن

    عکس‌های موبایل و دوربین چند مگابایت‌اند و صفحه را کند می‌کنند. قبل از گذاشتن در سایت، اندازه‌شان را کوچک کن (عرض حدود ۱۲۰۰ پیکسل کافی است) و از فرمت‌های سبک مثل .jpg یا .webp استفاده کن.

    object-fit

    اگر عکس را در یک قاب با اندازه‌ی ثابت بگذاری، باید مشخص کنی عکس چطور آن قاب را پر کند. این کار را object-fit انجام می‌دهد:

    مقدارنتیجه
    fillپیش‌فرض: عکس کش می‌آید تا قاب را پر کند (خراب می‌شود)
    containکل عکس دیده می‌شود با همان نسبت، ولی ممکن است جای خالی بماند
    coverقاب کامل پر می‌شود با همان نسبت، ولی لبه‌های عکس بریده می‌شود
    noneعکس با اندازه‌ی اصلی می‌ماند و فقط وسطش دیده می‌شود

    کدام را انتخاب کنم؟

    برای عکس‌های پروفایل، کارت‌ها و گالری معمولاً cover بهترین انتخاب است. وقتی نباید هیچ بخشی از عکس (مثلاً یک لوگو) بریده شود، contain را بگذار.

    object-position: کدام قسمت عکس دیده شود؟

    وقتی با cover یک قسمت از عکس بریده می‌شود، object-position مشخص می‌کند کدام قسمت بماند. مقدارش left، center، right، top، bottom یا ترکیب آن‌هاست. عکس این کادر سه رنگ دارد (قرمز، طلایی و آبی) تا ببینی کدام قسمت برش می‌خورد.

    آدرس طولانی داخل src در این کادر خود عکس را داخل کد دارد. فقط برای این‌که نمونه بدون اینترنت و فایل جدا کار کند از آن استفاده کرده‌ایم. تو در پروژه‌ات آدرس یک فایل را می‌نویسی.

    بازی با عکس‌ها

    چند ویژگی دیگر که با آن‌ها ظاهر عکس را می‌توانی عوض کنی:

    ویژگیکاربردمثال
    border-radiusگوشه‌ی گرد. مقدار 50% روی عکس مربعی آن را دایره می‌کندborder-radius: 50%
    box-shadowسایه (درس قبل)0 4px 12px rgba(0,0,0,0.25)
    opacityشفافیت از ۰ تا ۱opacity: 0.6
    filterافکت‌هایی مثل سیاه‌وسفید یا محوgrayscale(100%)، blur(4px)، brightness(1.2)
    transformبزرگ و کوچک کردن یا جابه‌جاییscale(1.05)

    حالا این‌ها را با :hover و transition از درس قبل ترکیب می‌کنیم: یک عکس پروفایل دایره‌ای و یک عکس که سیاه‌وسفید است و با رفتن موس روی آن رنگی و کمی بزرگ‌تر می‌شود:

    کادر متن (input)

    برای این‌که کاربر بتواند چیزی تایپ کند، از تگ input استفاده می‌کنیم. مثل img این تگ هم محتوا و تگ بسته ندارد. نوع آن را ویژگی type مشخص می‌کند. برای متن چندخطی هم تگ textarea هست.

    نوع‌های رایج type

    typeکاربرد
    textمتن معمولی (پیش‌فرض)
    passwordحرف‌ها به‌صورت نقطه نمایش داده می‌شوند
    emailمرورگر هنگام ارسال بررسی می‌کند شکل ایمیل درست باشد
    numberفقط عدد، با دکمه‌های بالا و پایین
    telشماره‌ی تلفن (در موبایل کیبورد عددی باز می‌شود)
    searchکادر جستجو
    dateانتخاب تاریخ از تقویم
    colorانتخاب رنگ

    ویژگی‌های مفید

    ویژگیکاربرد
    placeholderمتن راهنمای کم‌رنگ داخل کادر که با تایپ کردن پاک می‌شود
    valueمقدار اولیه‌ی کادر
    requiredپر کردن کادر اجباری است (هنگام ارسال فرم بررسی می‌شود)
    maxlengthحداکثر تعداد حرف‌ها
    min و maxکمترین و بیشترین مقدار برای عدد و تاریخ
    disabledکادر غیرفعال می‌شود

    همیشه برای کادر یک label بگذار

    تگ label با ویژگی for به id کادر وصل می‌شود. وقتی کاربر روی نوشته‌ی label کلیک کند، کادر انتخاب می‌شود. نابینایان هم از آن می‌فهمند کادر برای چیست. placeholder جای label را نمی‌گیرد، چون با تایپ کردن ناپدید می‌شود.

    استایل کادر متن

    کادرها را هم مثل بقیه‌ی المان‌ها با CSS استایل می‌دهیم و با :focus حالت انتخاب‌شده را مشخص می‌کنیم:

    فونت کادرها خودکار از صفحه نمی‌آید

    مرورگر برای input و textarea فونت خودش را می‌گذارد. با font-family: inherit آن‌ها را مجبور می‌کنی فونت صفحه را بگیرند. اگر outline: none را می‌نویسی، حتماً یک نشانه‌ی دیگر برای حالت focus (مثل رنگ کادر یا سایه) بگذار تا کاربرانی که با کیبورد کار می‌کنند بفهمند کجا هستند.

    چند کادر دیگر

    برای انتخاب کردن به‌جای تایپ کردن:

    • checkbox: تیک‌زدنی، هر مورد مستقل
    • radio: فقط یکی از چند گزینه. گزینه‌های هم‌گروه باید name یکسان داشته باشند.
    • select: لیست کشویی که گزینه‌هایش با option ساخته می‌شوند

    این‌جا input را داخل label گذاشتیم. این هم یک روش وصل کردن label به کادر است و دیگر به for و id نیازی ندارد.

    بعدش چه؟

    کادرهایی که ساختیم فعلاً فقط روی صفحه هستند و اطلاعاتشان جایی نمی‌رود. برای ارسال اطلاعات باید آن‌ها را داخل یک «فرم» بگذاریم. در درس بعد یاد می‌گیریم فرم چیست، برای چه کاری است و چطور ساخته می‌شود.

    اشتباه‌های رایج

    • آدرس اشتباه عکس. فاصله‌ی پوشه‌ها، پسوند، حروف بزرگ و کوچک و ../ را چک کن.
    • نوشتن alt را فراموش کردن. هر عکس معنادار باید alt داشته باشد.
    • دادن هم width هم height با نسبت اشتباه. عکس کش می‌آید. یا یکی را بده یا از object-fit استفاده کن.
    • کادر بدون label. فقط placeholder کافی نیست.
    • رادیوهای هم‌گروه با name متفاوت. کاربر می‌تواند چند تا را با هم انتخاب کند.
    • یکی بودن id چند المان. هر id باید در صفحه یکتا باشد.

طراحی وب

پروژه‌ی ساخت یک صفحه‌ی ریسپانسیو

در این پروژه یک طرح مناسب پیدا می‌کنی، آن را تحلیل می‌کنی و با مفاهیم HTML و CSS دوره به صفحه‌ای واکنش‌گرا تبدیلش می‌کنی.

در این درس

    هدف پروژه

    تا اینجا با HTML و CSS، چیدمان صفحه، Flexbox، Grid، موقعیت‌دهی، متغیرهای CSS و طراحی واکنش‌گرا آشنا شده‌ای. حالا وقت آن است که این مهارت‌ها را در یک پروژه‌ی کوچک کنار هم به کار ببری.

    پروژه، ساخت یک صفحه‌ی معرفی برای یک موضوع دلخواه است؛ مثلاً یک کافه، فروشگاه کوچک، دوره‌ی آموزشی، محصول خیالی یا صفحه‌ی معرفی خودت.

    هدف، کپی‌کردن طرح نیست

    از نمونه‌ها برای گرفتن ایده استفاده کن؛ اما محتوا، رنگ‌ها، تصویرها و جزئیات طراحی نهایی را خودت انتخاب کن.

    UI و UX یعنی چه؟

    UI یا رابط کاربری، بخش‌هایی است که کاربر می‌بیند و با آن‌ها تعامل می‌کند؛ مثل دکمه‌ها، منو، کارت‌ها، عنوان‌ها و تصویرها. UX یا تجربه‌ی کاربری، تجربه‌ی کلی فرد هنگام استفاده از محصول است: آیا می‌تواند به‌راحتی اطلاعات موردنیازش را پیدا کند؟ آیا مسیر رسیدن به هدف برایش روشن است؟

    بنابراین یک صفحه ممکن است ظاهر زیبایی داشته باشد، اما اگر پیدا کردن اطلاعات یا استفاده از دکمه‌ها دشوار باشد، تجربه‌ی خوبی ایجاد نمی‌کند. طراحی مناسب هم به ظاهر توجه دارد و هم به نیاز و هدف کاربر.

    مثال

    در صفحه‌ی یک کافه، UI شامل منو، عکس غذاها و دکمه‌ی تماس است. از جنبه‌ی UX می‌پرسیم: آیا کاربر می‌تواند سریع آدرس، ساعت کاری یا منو را پیدا کند؟

    از کجا نمونه‌ی طراحی پیدا کنیم؟

    برای شروع، موضوع صفحه‌ات را مشخص کن و بعد نمونه‌های نزدیک به همان موضوع را ببین. این گالری‌ها برای جست‌وجوی ایده و مشاهده‌ی نمونه‌های طراحی وب مناسب‌اند:

    Awwwards

    گالری وب‌سایت‌ها و مجموعه‌های الهام‌بخش.

    Dribbble

    طرح‌ها و نمونه‌کارهای تصویری طراحان.

    Behance

    پروژه‌های طراحی که گاهی روند و بخش‌های مختلفشان را هم نشان می‌دهند.

    نمونه‌های ساده و خلوت

    برای دیدن نمونه‌هایی با چیدمان مرتب و تمرکز بر محتوای مهم.

    طرح‌های الهام‌بخش همیشه ساده نیستند

    بعضی وب‌سایت‌های نمایشی از انیمیشن‌ها و جلوه‌های پیچیده استفاده می‌کنند. برای پروژه‌ی این دوره، نمونه‌ای انتخاب کن که بتوانی بخش‌های اصلی آن را با HTML و CSSهایی که یاد گرفته‌ای بسازی.

    چطور نمونه‌ی مناسب انتخاب کنیم؟

    هنگام انتخاب نمونه، این موارد را بررسی کن:

    • آیا موضوع نمونه با موضوع پروژه‌ات ارتباط دارد؟
    • آیا می‌توانی بخش‌های اصلی صفحه را به‌وضوح تشخیص بدهی؟
    • آیا چیدمانش را می‌توان با Flexbox یا Grid پیاده‌سازی کرد؟
    • آیا می‌توانی حدس بزنی صفحه در اندازه‌ی موبایل چه تغییری می‌کند؟
    • آیا می‌توانی یک نسخه‌ی ساده‌تر از آن را با مهارت‌های دوره بسازی؟

    قبل از کدنویسی، طرح را تحلیل کن

    بعد از انتخاب نمونه، فوراً سراغ کد نرو. اول بخش‌های صفحه و هدف هرکدام را یادداشت کن. برای نمونه، یک صفحه‌ی معرفی ممکن است این بخش‌ها را داشته باشد:

    1. سربرگ و منو
    2. بخش معرفی اصلی شامل عنوان، توضیح و دکمه
    3. بخش ویژگی‌ها یا کارت‌های محتوا
    4. بخش تصویر یا توضیح تکمیلی
    5. پاورقی شامل اطلاعات یا لینک‌ها

    سپس برای هر بخش تصمیم بگیر چه تگ HTMLای مناسب است و چیدمان آن را با کدام ابزار می‌سازی. مثلاً header برای سربرگ، main برای محتوای اصلی، section برای بخش‌های موضوعی و footer برای پاورقی.

    مفاهیم دوره را وارد پروژه کن

    قرار نیست همه‌ی ویژگی‌های CSS را به زور وارد صفحه کنی. از هر مفهوم جایی استفاده کن که برای چیدمان و ظاهر پروژه مناسب باشد:

    مفهوم نمونه‌ی کاربرد در پروژه
    ساختار معنایی HTML تقسیم صفحه به سربرگ، محتوای اصلی، بخش‌ها و پاورقی
    کلاس‌ها و انتخابگرها استایل دادن به کارت‌ها، دکمه‌ها و بخش‌های تکرارشونده
    Box Model و box-sizing کنترل اندازه، فاصله‌ی داخلی و حاشیه‌ی اجزا
    Flexbox یا Grid چیدمان منو، کارت‌ها یا بخش معرفی
    واحدها و Media Query تنظیم اندازه‌ها و تغییر چیدمان در صفحه‌های کوچک
    متغیرهای CSS تعریف رنگ‌ها و فاصله‌های پرتکرار در :root
    تصویر و object-fit نمایش تصویرها با اندازه و برش مناسب

    فرم فقط وقتی لازم است که با موضوع و هدف صفحه تناسب داشته باشد. اگر صفحه‌ات نیازی به فرم ندارد، لازم نیست فرمی را فقط برای استفاده از درس فرم‌ها اضافه کنی.

    پوشه‌بندی پروژه

    برای اینکه فایل‌ها مرتب باشند و مسیرهایشان را راحت‌تر پیدا کنی، پروژه را در یک پوشه‌ی اصلی نگه دار. در این تمرین از ساختار زیر استفاده می‌کنیم:

    responsive-project/ ├── index.html ├── css/ │ └── style.css ├── js/ │ └── main.js └── images/ └── your-image.jpg

    نام index.html را برای صفحه‌ی اصلی پروژه نگه دار. فایل‌های استایل، اسکریپت و تصویرها را هم در پوشه‌های مربوط به خودشان قرار بده. این یک ساختار تمرینی برای پروژه‌ی این دوره است؛ مهم این است که فایل‌ها را مرتب نگه داری و مسیرهایشان را درست بنویسی. 

    <link rel="stylesheet" href="css/style.css">
<script src="js/main.js"></script>
<img src="images/your-image.jpg" alt="توضیح مناسب برای تصویر">

    مسیرها را با اسلش رو به جلو بنویس

    در HTML مسیرهایی مانند images/photo.jpg بنویس؛ حتی اگر در ویندوز هستی، از \ استفاده نکن.

    مراحل انجام پروژه

    1. موضوع صفحه و مخاطب احتمالی آن را مشخص کن.
    2. یک یا دو نمونه‌ی مرتبط پیدا کن و نکات موردعلاقه‌ات را یادداشت کن.
    3. بخش‌های اصلی صفحه را روی کاغذ یا در یک فهرست ساده طراحی کن.
    4. پوشه‌ها و فایل‌های پروژه را طبق ساختار تمرین بساز.
    5. ساختار HTML را آماده کن و بخش‌های صفحه را با تگ‌های مناسب جدا کن.
    6. استایل پایه، رنگ‌ها، فاصله‌ها و چیدمان را در CSS پیاده‌سازی کن.
    7. با Media Query چیدمان را برای اندازه‌های مختلف تنظیم کن.
    8. صفحه را در مرورگر بررسی کن و اشکال‌های ظاهری و مسیر فایل‌ها را اصلاح کن.

    چک‌لیست ریسپانسیو بودن

    • در عرض موبایل، محتوای صفحه بیرون از viewport نمی‌زند.
    • متن‌ها و دکمه‌ها خوانا و قابل استفاده‌اند.
    • کارت‌ها و ستون‌ها در صفحه‌ی کوچک چیدمان مناسبی دارند.
    • تصاویر بیش از اندازه‌ی ظرف خود بزرگ نمی‌شوند.
    • منو و فاصله‌های صفحه در اندازه‌های مختلف قابل استفاده‌اند.
    • صفحه را دست‌کم در اندازه‌ی کوچک و بزرگ مرورگر بررسی کرده‌ای.

    خلاصه

    • UI بخش دیداری و تعاملی صفحه است؛ UX تجربه‌ی کلی استفاده از آن.
    • نمونه‌ها را برای یادگیری و ایده گرفتن بررسی کن، نه برای کپی مستقیم.
    • پیش از کدنویسی، بخش‌ها و هدف هرکدام را مشخص کن.
    • از مفاهیم دوره در جای مناسب استفاده کن؛ لازم نیست همه‌چیز را به زور وارد کنی.
    • پوشه‌ها و مسیر فایل‌ها را مرتب و دقیق نگه دار.
    • صفحه را در اندازه‌های گوناگون بررسی و اصلاح کن.

    حالا نوبت پروژه‌ی توست

    موضوعت را انتخاب کن، نمونه را تحلیل کن و صفحه‌ات را بساز.

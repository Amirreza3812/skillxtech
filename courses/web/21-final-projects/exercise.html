پروژه‌ی پایانی: صفحه‌ی ریسپانسیو

یک صفحه‌ی معرفی طراحی کن که در اندازه‌های مختلف نمایشگر مرتب و قابل استفاده باشد.

  1. انتخاب موضوع و نمونه‌ی الهام‌بخش

    موضوع صفحه‌ات را انتخاب کن؛ مثلاً کافه، فروشگاه، محصول، دوره‌ی آموزشی یا صفحه‌ی شخصی. سپس از یکی از گالری‌های درس یک نمونه‌ی مرتبط پیدا کن و بنویس چه دو ویژگی‌ای از آن برایت جالب بوده است.

    راهنمایی

    ویژگی‌ها می‌توانند چیدمان، رنگ، تصویر، اندازه‌ی عنوان یا شکل کارت‌ها باشند. قرار نیست نمونه را عیناً کپی کنی.

  2. طرح‌ریزی بخش‌های صفحه

    دست‌کم چهار بخش برای صفحه‌ات مشخص کن؛ مثلاً سربرگ، معرفی اصلی، کارت‌های ویژگی و پاورقی. برای هرکدام بنویس چه محتوایی در آن قرار می‌دهی.

    راهنمایی

    برای ساختار صفحه می‌توانی از تگ‌هایی مثل header، main، section و footer استفاده کنی.

  3. ساخت پوشه‌ها و فایل‌های پروژه

    یک پوشه‌ی اصلی به نام responsive-project بساز و فایل‌ها را با این ساختار در آن قرار بده: 

    responsive-project/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── images/

    برای این تمرین، فایل اصلی را index.html نام‌گذاری کن. اگر در صفحه‌ات از JavaScript یا تصویر استفاده نمی‌کنی، باز هم پوشه‌ی مربوط به آن‌ها را می‌توانی خالی نگه داری.

    راهنمایی

    مسیر CSS از فایل HTML برابر css/style.css است. برای تصویر داخل پوشه‌ی images، مسیر را به شکل images/image-name.jpg بنویس.

  4. پیاده‌سازی ساختار HTML

    فایل index.html را با ساختار پایه‌ی HTML بساز. بخش‌های پروژه را با تگ‌های مناسب جدا کن و برای تصویرهای محتوایی، متن جایگزین مناسب بنویس.

    راهنمایی

    معمولاً عنوان اصلی صفحه یک h1 دارد. برای بخش‌های اصلی از عنوان‌های مرتبه‌ی بعدی استفاده کن و نام کلاس‌ها را بر اساس کاربردشان انتخاب کن.

  5. استایل‌دهی و واکنش‌گرا کردن صفحه

    در css/style.css رنگ‌ها، فونت، فاصله‌ها و چیدمان صفحه را تنظیم کن. از Flexbox یا Grid برای چیدمان مناسب استفاده کن و با Media Query صفحه را برای نمایشگرهای کوچک‌تر اصلاح کن.

    راهنمایی

    می‌توانی ابتدا استایل صفحه‌ی کوچک را بنویسی و در Media Query چیدمان مناسب صفحه‌ی بزرگ‌تر را اضافه کنی. برای رنگ و فاصله‌های پرتکرار هم از متغیرهای CSS استفاده کن.

  6. بررسی نهایی و آماده‌سازی برای نمایش

    پروژه را در مرورگر باز کن و در عرض‌های کوچک و بزرگ بررسی کن. مسیر CSS، تصویرها و فایل‌های دیگر را هم بررسی کن. اگر خواستی تصویر صفحه‌ات را برای ارائه آماده کنی، در ویندوز می‌توانی از Windows + Shift + S برای گرفتن اسکرین‌شات استفاده کنی.

    چک‌لیست تحویل
    • فایل اصلی index.html است.
    • فایل CSS در پوشه‌ی css قرار دارد.
    • مسیر فایل‌ها درست است و تصویرها بارگذاری می‌شوند.
    • عنوان‌ها و متن‌ها در اندازه‌ی کوچک خوانا هستند.
    • صفحه در موبایل اسکرول افقی ناخواسته ندارد.
    • از دست‌کم یک مفهوم چیدمان مثل Flexbox یا Grid استفاده شده است.
    • از Media Query برای تنظیم چیدمان استفاده شده است.

انتشار کارها

اگر قرار است پروژه‌ات در گالری نمونه‌کارهای دوره نمایش داده شود، پیش از انتشار، رضایتت گرفته می‌شود. می‌توانی نام نمایشی دلخواهت را انتخاب کنی.

    CSS چیست؟

    CSS مخفف Cascading Style Sheets است. در درس قبل با HTML اسکلت صفحه را ساختیم؛ CSS ظاهر آن را تعیین می‌کند: رنگ، اندازه‌ی نوشته، فاصله‌ها و حاشیه‌ها.

    مثال زیر یک HTML ساده است. دکمه‌ی «برگرداندن کد اصلی» را بزن و ببین بدون CSS چه شکلی بود:

    برای دیدن نسخه‌ی بدون CSS، کل بخش <style> را از کادر بالا پاک کن.

    سه روش اضافه کردن CSS

    ۱. داخل خود تگ (inline)

    CSS را در ویژگی style همان المان می‌نویسیم. فقط روی همان یک المان اثر دارد.

    ۲. داخل تگ style در همان صفحه (internal)

    CSS را داخل <style> می‌نویسیم، معمولاً داخل <head>. همین روش را در کادرهای «امتحان کن» این درس استفاده کرده‌ایم. 

    <head>
  <style>
    h1 {
      color: crimson;
    }
  </style>
</head>

    ۳. فایل جدا (external)

    CSS را در یک فایل با پسوند .css می‌نویسیم و با تگ link به صفحه وصل می‌کنیم. این بهترین روش است، چون یک فایل CSS را می‌شود برای همه‌ی صفحه‌های سایت استفاده کرد.

    my-site/
├── index.html
└── style.css
    <head>
  <link rel="stylesheet" href="style.css">
</head>

    کدام روش را انتخاب کنم؟

    برای پروژه‌های واقعی از فایل جدا استفاده کن. استایل inline فقط برای تست سریع خوب است و استایل internal برای صفحه‌های تکی و نمونه‌ها.

    ساختار یک قانون CSS

    CSS از «قانون»ها ساخته می‌شود. هر قانون می‌گوید کدام المان‌ها (انتخابگر) چه ویژگی‌هایی با چه مقادیری داشته باشند.

    p {
      color: gray;
      font-size: 20px;
    }

    • انتخابگر (selector)
    • ویژگی (property)
    • مقدار (value)
    • آکولاد، دونقطه و نقطه‌ویرگول
    • انتخابگر مشخص می‌کند قانون روی چه چیزی اثر کند.
    • هر ویژگی و مقدارش با : از هم جدا می‌شوند.
    • بعد از هر مقدار ; می‌گذاریم.
    • همه‌ی ویژگی‌ها داخل { } قرار می‌گیرند.

    نقطه‌ویرگول را فراموش نکن

    اگر بعد از یک مقدار ; نگذاری، مرورگر آن خط و خط بعدش را نادیده می‌گیرد و خطایی هم نشان نمی‌دهد. این رایج‌ترین اشتباه شروع CSS است.

    انتخابگرها

    چهار نوع انتخابگر ساده برای شروع کافی است:

    انتخابگرنمونهروی چه چیزی اثر می‌گذارد؟
    تگpهمه‌ی المان‌های p
    کلاس.noteهر المانی که class="note" دارد (با نقطه شروع می‌شود)
    آیدی#titleالمانی که id="title" دارد (با # شروع می‌شود)
    گروهیh2, h3هر دو تگ با یک قانون (با کاما جدا می‌شوند)

    کلاس یا آیدی؟

    یک کلاس را می‌شود روی چند المان گذاشت، ولی یک id باید در صفحه یکتا باشد. در عمل بیشتر از کلاس استفاده می‌کنیم و id را برای المان‌های یکتا نگه می‌داریم.

    رنگ‌ها

    دو ویژگی رنگی که زیاد لازم می‌شوند: color برای رنگ نوشته و background-color برای رنگ پس‌زمینه. رنگ را به سه شکل می‌شود نوشت:

    • نام رنگ: red، royalblue، gray
    • کد هگز: #2f5bea (با # شروع می‌شود)
    • rgb: rgb(14, 143, 110) (میزان قرمز، سبز و آبی از ۰ تا ۲۵۵)

    برای پیدا کردن کد هگز یک رنگ، می‌توانی از «color picker» جستجوی گوگل یا ابزار رنگ‌انتخاب VS Code استفاده کنی.

    استایل متن

    ویژگیکاربردمقدار نمونه
    font-familyنوع فونتTahoma, sans-serif
    font-sizeاندازه‌ی نوشته20px
    font-weightضخامت نوشتهbold
    text-alignتراز متنcenter، right، left
    line-heightفاصله‌ی خط‌ها1.8
    text-decorationخط زیر یا روی نوشتهunderline، none

    px یعنی چه؟

    px مخفف پیکسل است و واحد اصلی اندازه‌ها در این درس است. واحدهای دیگری مثل rem و درصد هم وجود دارند که بعداً با آن‌ها آشنا می‌شویم.

    جعبه‌ی هر المان

    مرورگر هر المان را مثل یک جعبه می‌بیند. این جعبه چهار لایه دارد که از داخل به بیرون این‌ها هستند:

    لایهویژگیکاربرد
    محتواwidth / heightاندازه‌ی خود محتوا
    فضای داخلیpaddingفاصله‌ی بین محتوا و حاشیه
    حاشیهborderخط دور جعبه
    فضای بیرونیmarginفاصله‌ی جعبه با المان‌های اطراف
    • مقدار border سه بخش دارد: ضخامت، نوع خط و رنگ، مثل 4px solid #2f5bea.
    • اگر دو عدد بنویسی، مثل padding: 10px 30px، عدد اول برای بالا و پایین و عدد دوم برای چپ و راست است.
    • اگر چهار عدد بنویسی، ترتیب آن‌ها بالا، راست، پایین، چپ است.

    فرق padding و margin

    padding داخل حاشیه است و رنگ پس‌زمینه‌ی المان آن را هم می‌پوشاند. margin بیرون حاشیه است و همیشه شفاف است. در کادر بالا اعدادشان را عوض کن تا فرقشان را ببینی.

    اندازه‌ی واقعی جعبه

    در حالت پیش‌فرض، width: 200px فقط عرض محتواست. عرض کل جعبه با اضافه شدن padding و border بیشتر می‌شود. در جعبه‌ی بالا عرض کل می‌شود ۲۰۰ + ۴۰ + ۸ = ۲۴۸ پیکسل.

    وقتی دو قانون با هم تضاد دارند

    اگر چند قانون یک ویژگی را روی یک المان تعیین کنند، کدام برنده می‌شود؟ سه قاعده‌ی ساده:

    1. قانونی که پایین‌تر نوشته شده، برنده است (وقتی انتخابگرها هم‌وزن باشند).
    2. انتخابگر دقیق‌تر برنده است: id قوی‌تر از کلاس و کلاس قوی‌تر از تگ است.
    3. استایل inline از همه‌ی اینها قوی‌تر است.

    دیدن و تست CSS در مرورگر

    روی هر قسمت از صفحه راست‌کلیک کن و گزینه‌ی Inspect را بزن (یا کلید F12). در پنجره‌ی باز شده می‌بینی کدام قانون CSS روی آن المان اثر گذاشته و می‌توانی مقدارها را همان‌جا عوض کنی و نتیجه را زنده ببینی.

    تغییراتی که در این پنجره می‌دهی موقتی است و با رفرش صفحه از بین می‌رود. برای نگه داشتن تغییرها باید در فایل خودت اعمالشان کنی.

    اشتباه‌های رایج

    • جا انداختن نقطه‌ویرگول. مرورگر آن خط را نادیده می‌گیرد.
    • نوشتن = به‌جای : مثلاً color = red اشتباه و color: red درست است.
    • یادت رفته نقطه یا # بگذاری. note یعنی تگی به اسم note، ولی .note یعنی کلاس note.
    • غلط املایی در اسم ویژگی. مثلاً colour یا font-sise. مرورگر خطایی نشان نمی‌دهد و ویژگی را نادیده می‌گیرد.
    • مسیر اشتباه فایل CSS. اگر style.css وصل نمی‌شود، اسم فایل و محل آن نسبت به صفحه را چک کن.
    • تغییر دادی ولی چیزی عوض نشد. فایل را ذخیره کرده‌ای و صفحه را رفرش کرده‌ای؟ گاهی هم باید کش مرورگر را با Ctrl+F5 پاک کنی.

تمرین: مبانی CSS

کد هر تمرین را ویرایش کن و نتیجه را همان لحظه کنارش ببین.

  1. رنگ‌ها

    داخل تگ style دو قانون بنویس: رنگ نوشته‌ی h1 را با یک کد هگز آبی (مثلاً #2f5bea) و رنگ نوشته‌ی همه‌ی pها را خاکستری کن. بعد برای h1 یک background-color هم امتحان کن.

    راهنمایی

    ساختار هر قانون: selector { property: value; }. اگر چیزی عوض نشد، نقطه‌ویرگول‌ها را چک کن.

  2. کلاس و آیدی

    فقط پاراگراف «تمرین CSS» را با یک کلاس به اسم important زرد کن (background-color). بعد با یک آیدی به اسم title رنگ نوشته‌ی h2 را قرمز کن.

    راهنمایی

    ابتدا در HTML ویژگی class="important" را به همان پاراگراف اضافه کن و بعد در CSS با .important انتخابش کن. برای آیدی از #title استفاده کن.

  3. استایل متن

    این کارها را انجام بده: عنوان h1 را وسط‌چین و ۳۶ پیکسلی کن. اندازه‌ی پاراگراف را ۱۸ پیکسل و فاصله‌ی خط‌هایش را 2 کن. خط زیر لینک را بردار و لینک را ضخیم کن.

    راهنمایی

    ویژگی‌های لازم: text-align، font-size، line-height، text-decoration و font-weight.

  4. یک کارت ساده

    با کلاس card به این المان ظاهر یک کارت بده: عرض ۲۵۰ پیکسل، padding برابر ۱۶ پیکسل، یک border دو پیکسلی، margin برابر ۲۰ پیکسل و یک رنگ پس‌زمینه‌ی ملایم.

    راهنمایی

    ویژگی border سه بخش دارد: ضخامت، نوع خط و رنگ. مثلاً 2px solid gray.

  5. پیدا کردن خطاها

    این کد چهار اشتباه دارد و هیچ‌کدام از استایل‌ها درست اعمال نمی‌شوند. اشتباه‌ها را پیدا و درست کن تا عنوان قرمز، یادداشت زرد و وسط‌چین با فونت ۲۰ پیکسل و مقدمه خاکستری شود.

    راهنمایی

    دنبال این‌ها بگرد: غلط املایی در اسم یک ویژگی، علامتی که به‌جای : نوشته شده، یک ; جا افتاده و یک انتخابگر که علامتش را ندارد.

  6. فایل CSS جدا

    صفحه‌ای که در تمرین «مبانی HTML» ساختی را روی کامپیوتر خودت باز کن. یک فایل style.css کنار آن بساز، با تگ link به صفحه وصلش کن و چند قانون برای رنگ، متن و جعبه‌ی المان‌ها در آن بنویس. صفحه را در مرورگر باز کن و نتیجه را ببین.

    راهنمایی

    تگ link داخل head می‌رود: <link rel="stylesheet" href="style.css">. هر دو فایل باید در یک پوشه باشند.

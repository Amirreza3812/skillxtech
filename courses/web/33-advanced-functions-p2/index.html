توابع پیشرفته — پارت دوم

یاد می‌گیریم تابعی را به‌عنوان ورودی به تابع دیگری بدهیم و از متدهای آرایه برای پیمایش، تبدیل و فیلترکردن داده‌ها استفاده کنیم.

در این درس

    تابع مرتبه‌بالا چیست؟

    تابعی که تابع دیگری را به‌عنوان ورودی دریافت کند یا یک تابع را برگرداند، تابع مرتبه‌بالا نامیده می‌شود. در پارت قبل دیدیم که تابع می‌تواند آرگومان تابع دیگری باشد؛ در این درس همین ایده را در کاربردهای بیشتری می‌بینیم. 

    function runTask(task) {
  task();
}

function sayHello() {
  console.log("سلام!");
}

runTask(sayHello);

    در این نمونه، runTask یک تابع دریافت می‌کند و آن را اجرا می‌کند؛ پس runTask تابع مرتبه‌بالاست و sayHello نقش callback را دارد.

    پیمایش آرایه با forEach()

    متد forEach() تابعی می‌گیرد و آن را برای هر عضو آرایه اجرا می‌کند. این متد برای انجام کاری با هر عضو مناسب است؛ مثلاً نمایش اعضا در کنسول. 

    const names = ["سارا", "آرمان", "مینا"];

names.forEach(function (name) {
  console.log("سلام " + name);
});

    تابعی که به forEach() داده‌ایم برای هر عضو اجرا می‌شود. در هر بار اجرا، پارامتر name مقدار یکی از اعضای آرایه را می‌گیرد.

    forEach چه چیزی برمی‌گرداند؟

    معمولاً از forEach() برای انجام یک کار با اعضا استفاده می‌کنیم؛ این متد آرایه‌ی تازه‌ای از نتایج نمی‌سازد. اگر می‌خواهی بر اساس اعضای آرایه، آرایه‌ی تازه‌ای بسازی، به map() نگاه کن.

    ساخت آرایه‌ی تازه با map()

    متد map() روی اعضای آرایه کار می‌کند و از نتیجه‌ی callback برای هر عضو، آرایه‌ی تازه‌ای می‌سازد. آرایه‌ی اصلی با این روش تغییر نمی‌کند. 

    const prices = [10, 20, 30];

const doubledPrices = prices.map(function (price) {
  return price * 2;
});

console.log(doubledPrices); // [20, 40, 60]
console.log(prices);        // [10, 20, 30]

    مقدار return از callback، به عضو متناظر در آرایه‌ی جدید تبدیل می‌شود. بنابراین بهتر است callback در map() برای هر عضو یک مقدار برگرداند.

    فیلترکردن آرایه با filter()

    متد filter() آرایه‌ی تازه‌ای می‌سازد که فقط عضوهایی را شامل می‌شود که شرط callback برایشان درست باشد. 

    const scores = [45, 82, 67, 30, 95];

const passingScores = scores.filter(function (score) {
  return score >= 60;
});

console.log(passingScores); // [82, 67, 95]

    callback در filter() باید نتیجه‌ای مانند true یا false بدهد. عضوهایی که نتیجه‌ی شرط برایشان درست باشد، در آرایه‌ی جدید قرار می‌گیرند.

    متد کاربرد نتیجه
    forEach() انجام کاری برای هر عضو آرایه‌ی تازه‌ای نمی‌سازد
    map() تبدیل هر عضو به مقداری دیگر آرایه‌ی تازه با همان تعداد عضو
    filter() انتخاب اعضایی که شرط را دارند آرایه‌ی تازه با صفر یا چند عضو

    پارامترهای callback در متدهای آرایه

    callback این متدها می‌تواند علاوه بر مقدار عضو، اندیس آن را هم دریافت کند. در صورت نیاز می‌توان پارامتر دوم را برای اندیس به کار برد. 

    const colors = ["آبی", "سبز", "قرمز"];

colors.forEach(function (color, index) {
  console.log(index, color);
});

    پارامتر اول مقدار عضو فعلی است و پارامتر دوم اندیس آن. اگر به اندیس نیاز نداشته باشی، می‌توانی فقط پارامتر اول را بنویسی.

    ترکیب متدها در یک نمونه

    در نمونه‌ی زیر، ابتدا محصول‌های موجود را با filter() جدا می‌کنیم و سپس نام آن‌ها را با map() به یک آرایه‌ی تازه تبدیل می‌کنیم.

    نتیجه‌ی filter() آرایه‌ای از محصول‌های موجود است. سپس map() از آن آرایه، آرایه‌ای از نام‌ها می‌سازد.

    کدام متد را انتخاب کنیم؟

    • اگر می‌خواهی برای هر عضو کاری انجام بدهی، از forEach() استفاده کن.
    • اگر می‌خواهی هر عضو را تبدیل کنی و آرایه‌ی تازه‌ای بسازی، از map() استفاده کن.
    • اگر می‌خواهی فقط اعضای مطابق یک شرط را نگه داری، از filter() استفاده کن.

    اشتباه رایج

    در callback متد map()، اگر مقداری return نکنی، آن خانه در آرایه‌ی جدید مقدار undefined خواهد داشت. در filter() هم callback باید شرطی را بررسی کند که نتیجه‌اش درست یا نادرست باشد.

    جمع‌بندی

    توابع مرتبه‌بالا می‌توانند تابع دیگری را دریافت کنند یا برگردانند. متد forEach() برای انجام کاری روی اعضای آرایه، map() برای ساخت آرایه‌ای از مقادیر تبدیل‌شده و filter() برای ساخت آرایه‌ای از اعضای مطابق شرط به کار می‌روند. callback این متدها را با تابع معمولی هم می‌توان نوشت.

    آماده‌ای؟

    در تمرین‌ها از callback و متدهای آرایه استفاده کن.

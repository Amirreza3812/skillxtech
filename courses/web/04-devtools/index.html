طراحی وب

Chrome DevTools

کد هر سایتی را ببین، جعبه‌ی المان‌ها را بررسی کن و بدون نوشتن حتی یک خط در فایلت، CSS را روی صفحه امتحان کن.

در این درس

    DevTools برای چیست؟

    تا حالا از خودت پرسیده‌ای فلان سایت زیبا چطور ساخته شده؟ یا چرا فاصله‌ی بین دو المان در صفحه‌ی خودت اندازه‌ی دلخواه نیست؟ مرورگر جواب هر دو سؤال را دارد: ابزاری به اسم DevTools (ابزارهای توسعه‌دهنده) که در Chrome و Edge و Firefox هست.

    با این ابزار می‌توانی:

    • HTML و CSS هر صفحه را ببینی و بفهمی هر چیز با چه کدی ساخته شده
    • CSS را روی صفحه تغییر بدهی و نتیجه را همان لحظه ببینی
    • جعبه‌ی هر المان (margin، border و padding) را دقیق ببینی
    • بفهمی چرا یک المان آن‌طور که می‌خواستی دیده نمی‌شود
    • فایل‌های یک صفحه مثل تصویرها را پیدا کنی

    در این درس از Chrome استفاده می‌کنیم. در Edge تقریباً همه چیز یکی است.

    باز کردن Inspect

    چند راه برای باز کردن DevTools هست. ساده‌ترینش این است: روی هر قسمت از یک صفحه راست‌کلیک کن و گزینه‌ی Inspect را بزن.

    کارویندوز و لینوکسمک
    باز و بسته کردن DevToolsF12 یا Ctrl+Shift+ICmd+Option+I
    انتخاب یک المان با موسCtrl+Shift+CCmd+Shift+C
    حالت نمایش موبایلCtrl+Shift+MCmd+Shift+M
    دیدن کد اصلی صفحه (View Source)Ctrl+UCmd+Option+U

    پنجره‌ی DevTools چند «پنل» دارد که در نوار بالای آن دیده می‌شوند. فعلاً این‌ها برایمان مهم‌اند:

    پنلکاربرد
    Elementsدیدن و تغییر دادن HTML و CSS صفحه
    Consoleنمایش خطاها و پیام‌ها (در درس‌های JavaScript زیاد از آن استفاده می‌کنیم)
    Sourcesدیدن فایل‌های سایت مثل HTML، CSS و JS
    Networkفهرست همه‌ی چیزهایی که صفحه دانلود کرده، مثل عکس‌ها
    Applicationاطلاعاتی که سایت در مرورگر ذخیره کرده

    پنل Elements

    مهم‌ترین پنل برای ما همین است. دو بخش اصلی دارد:

    • درخت HTML: همه‌ی تگ‌های صفحه. وقتی موس را روی یکی از آن‌ها ببری، همان المان در صفحه رنگی می‌شود.
    • پنل Styles: همه‌ی قانون‌های CSS که روی المان انتخاب‌شده اثر دارند.

    چطور CSS را زنده تغییر بدهیم؟

    1. روی المان مورد نظر راست‌کلیک کن و Inspect را بزن (یا با Ctrl+Shift+C روی آن کلیک کن).
    2. در پنل Styles روی مقدار یک ویژگی کلیک کن و آن را عوض کن، مثلاً رنگ را. تغییر همان لحظه روی صفحه دیده می‌شود.
    3. با تیک کنار هر ویژگی می‌توانی آن را موقتاً خاموش و روشن کنی تا بفهمی چه اثری دارد.
    4. با کلیک روی یک مقدار عددی و فشردن کلیدهای بالا و پایین می‌توانی عدد را کم و زیاد کنی (مثلاً padding).
    5. با کلیک روی فضای خالی داخل قانون می‌توانی یک ویژگی جدید اضافه کنی.
    6. متن صفحه را هم می‌شود تغییر داد: روی متن داخل درخت HTML دوبار کلیک کن.

    تغییرها موقتی‌اند

    DevTools سایت واقعی را عوض نمی‌کند، فقط نسخه‌ی داخل مرورگر خودت را. با رفرش صفحه همه چیز به حالت اول برمی‌گردد. وقتی چیزی را که می‌خواستی پیدا کردی، باید مقدار آن را در فایل CSS خودت بنویسی.

    دیدن حالت hover

    در درس قبل حالت :hover را یاد گرفتی. اما وقتی بخواهی استایل hover را در DevTools ببینی، موس را باید به پنجره‌ی DevTools ببری و hover از بین می‌رود. راه حلش دکمه‌ی :hov در بالای پنل Styles است: با آن می‌توانی حالت‌های :hover، :active و :focus را روی المان انتخاب‌شده اجباری روشن کنی.

    روی دکمه‌ی نتیجه (سمت راست کادر) راست‌کلیک کن و Inspect را بزن. بعد در پنل Styles روی :hov کلیک کن و تیک :hover را بزن. رنگ دکمه عوض می‌شود، بدون این‌که موس روی آن باشد.

    Box Model در DevTools

    در درس مبانی CSS دیدیم هر المان یک جعبه است با چهار لایه: محتوا، padding، border و margin. DevTools این جعبه را برایت نشان می‌دهد. المان را انتخاب کن و به تب Computed برو (در بعضی نسخه‌ها نمودار پایین پنل Styles هم هست):

    • آبی: محتوا (عرض و ارتفاع)
    • سبز: padding
    • زرد: border
    • نارنجی: margin

    اگر موس را روی نمودار ببری، همان لایه در صفحه با همان رنگ مشخص می‌شود. حتی با بردن موس روی هر تگ در درخت HTML، جعبه‌ی آن المان روی صفحه رنگ‌آمیزی می‌شود. این روش بهترین راه برای فهمیدن این است که فضای خالی دور یک المان از کجاست.

    روی جعبه‌ی نتیجه Inspect بزن و ببین عددهای نمودار با کد برابرند یا نه. بعد در Styles عدد padding را با کلیدهای بالا و پایین تغییر بده و نمودار را نگاه کن.

    وقتی فاصله‌ها را نمی‌فهمی

    اگر یک المان جای عجیبی افتاده یا فاصله‌ای بیشتر از انتظارت دارد، آن و المان‌های کنارش را Inspect کن. معمولاً یک margin یا padding که یادت رفته است دلیلش است.

    دیدن کد سایت‌های دیگر

    برای هر سایتی که دوست داشتی می‌توانی بفهمی چطور ساخته شده:

    1. روی بخش مورد نظر راست‌کلیک و Inspect کن.
    2. در درخت HTML ببین آن بخش با چه تگ‌هایی ساخته شده.
    3. در پنل Styles ببین چه ویژگی‌هایی ظاهرش را ساخته‌اند، مثل box-shadow یا border-radius.
    4. مقدارها را عوض کن و ببین هر کدام چه کاری می‌کنند.

    View Source یا Elements؟

    با Ctrl+U کد اصلی صفحه را همان‌طور که سرور فرستاده می‌بینی. پنل Elements ولی وضعیت فعلی صفحه را نشان می‌دهد، یعنی بعد از این‌که JavaScript صفحه را تغییر داده است. در سایت‌های امروزی معمولاً چیزی که می‌خواهی را باید در Elements پیدا کنی.

    پیدا کردن فایل CSS

    بالای سمت راست هر قانون در پنل Styles اسم فایل و شماره‌ی خط نوشته شده، مثل style.css:25. اگر روی آن کلیک کنی، آن فایل در پنل Sources باز می‌شود. اگر کد فشرده و در یک خط بود، دکمه‌ی { } پایین پنجره‌ی Sources آن را مرتب می‌کند.

    کپی کردن کد

    روی یک المان در درخت HTML راست‌کلیک کن و از منوی Copy یکی از این‌ها را انتخاب کن: Copy element برای کد HTML و Copy styles برای CSS آن.

    یاد بگیر، کپی نکن

    خواندن کد دیگران بهترین راه یادگیری است، ولی طراحی و کد هر سایت متعلق به سازنده‌ی آن است. تکنیک را یاد بگیر و کد را خودت بنویس. کپی کردن کامل یک سایت و منتشر کردنش به اسم خودت درست نیست.

    پیدا کردن تصویرها (مثل کاور)

    گاهی می‌خواهی ببینی یک تصویر، مثل کاور یک آهنگ یا پوستر یک فیلم، با چه آدرسی در صفحه آمده است. چند راه وجود دارد:

    راه اول: از طریق Elements

    1. روی تصویر راست‌کلیک و Inspect کن.
    2. در درخت HTML تگ img انتخاب می‌شود. آدرس تصویر در ویژگی src است.
    3. روی آدرس راست‌کلیک کن و Open in new tab را بزن.
    4. در زبانه‌ی جدید، تصویر به‌تنهایی باز می‌شود. روی آن راست‌کلیک و Save image as را بزن.
    <img src="/covers/album.jpg" alt="کاور آلبوم">

    گاهی تصویر با ویژگی srcset چند اندازه دارد. در این حالت اندازه‌ی بزرگ‌تر کیفیت بهتری دارد:

    <img src="small.jpg"
     srcset="small.jpg 300w, large.jpg 1200w"
     alt="کاور">

    راه دوم: تصویری که در CSS است

    بعضی تصویرها اصلاً تگ img ندارند و در CSS با background-image گذاشته شده‌اند. در این حالت المان را Inspect کن و در پنل Styles دنبال خطی مثل این بگرد. روی آدرس داخل url() کلیک کن تا تصویر باز شود:

    .cover {
  background-image: url("images/cover.jpg");
}

    راه سوم: پنل Network

    1. DevTools را باز کن و به پنل Network برو.
    2. در نوار فیلتر روی Img کلیک کن تا فقط تصویرها دیده شوند.
    3. صفحه را رفرش کن (Ctrl+R) تا همه‌ی تصویرها در فهرست بیایند.
    4. روی یک فایل کلیک کن و در تب Preview آن را ببین. با راست‌کلیک و Open in new tab هم باز می‌شود.

    اگر تصویر پیدا نشد

    • بعضی سایت‌ها تصویرها را موقع اسکرول بارگذاری می‌کنند، پس اول صفحه را تا پایین اسکرول کن.
    • ممکن است فایل با پسوند .webp ذخیره شود. این یک فرمت رایج و سبک برای وب است و بیشتر برنامه‌ها آن را باز می‌کنند.

    حق کپی‌رایت را رعایت کن

    کاور آهنگ، پوستر فیلم و عکس‌های یک سایت متعلق به صاحبان آن‌ها هستند. برای یادگیری یا استفاده‌ی شخصی (مثلاً مشاهده در کامپیوتر خودت) مشکلی نیست، ولی برای گذاشتن در سایت خودت باید اجازه داشته باشی. برای پروژه‌های خودت از تصویرهای رایگان با مجوز آزاد (مثل Unsplash یا Pexels) استفاده کن.

    نکته‌های کاربردی

    • نمایش موبایل: با Ctrl+Shift+M می‌توانی ببینی صفحه روی اندازه‌ی گوشی چطور دیده می‌شود.
    • جای DevTools: اگر پنجره کوچک بود، از سه نقطه‌ی بالای آن گزینه‌ی «Dock side» را عوض کن تا کنار یا زیر صفحه یا در پنجره‌ی جدا باشد.
    • رفرش کامل: اگر تغییری در CSS دادی و دیده نمی‌شود، Ctrl+Shift+R را بزن تا کش مرورگر پاک شود.
    • هنگام ساختن سایت خودت: برای هر مشکل ظاهری اول Inspect کن و بعد کد را عوض کن.

طراحی وب

کلاس‌ها در جاوااسکریپت

یاد می‌گیریم با کلاس‌ها قالبی برای ساختن چند شیء مشابه تعریف کنیم، داده‌های هر شیء را با سازنده مقداردهی کنیم و برای آن‌ها متد بنویسیم.

در این درس

    ۱. چرا به کلاس نیاز داریم؟

    در درس اشیا دیدیم که می‌توانیم داده‌های مرتبط را در یک شیء کنار هم نگه داریم. اگر چند شیء با ساختار مشابه بخواهیم، ساختن هرکدام به‌صورت دستی باعث تکرار کد می‌شود.

    کلاس راهی برای تعریف یک قالب مشترک است. از روی آن قالب می‌توانیم نمونه‌های جداگانه بسازیم؛ هر نمونه داده‌های خودش را دارد، اما ساختار و رفتار کلی آن‌ها مشترک است.

    تفاوت مهم

    کلاس خودِ یک کاربر یا محصول نیست؛ دستورالعملی برای ساختن نمونه‌هایی از آن‌هاست.

    ۲. تعریف کلاس

    برای تعریف کلاس از کلمه‌ی کلیدی class و سپس نام کلاس استفاده می‌کنیم. نام کلاس معمولاً با حرف بزرگ شروع می‌شود؛ برای نمونه User یا Product. 

    class User {
  // ویژگی‌ها و متدهای کلاس
}

    بدنه‌ی کلاس می‌تواند شامل سازنده و متدها باشد. در این مرحله یک کلاس خالی فقط قالبی است که هنوز هیچ نمونه‌ای از آن نساخته‌ایم.

    ۳. سازنده و ویژگی‌های نمونه

    متد ویژه‌ی constructor() هنگام ساختن هر نمونه اجرا می‌شود. ورودی‌هایی که به آن می‌دهیم می‌توانند برای مقداردهی ویژگی‌های همان نمونه استفاده شوند.

    کلمه‌ی this در سازنده به نمونه‌ای اشاره می‌کند که در حال ساخته‌شدن است. برای نمونه، this.name ویژگی name را روی همان نمونه قرار می‌دهد. 

    class User {
  constructor(name, email) {
    this.name = name;
    this.email = email;
  }
}

const userOne = new User("سارا", "sara@example.com");
const userTwo = new User("آرمان", "arman@example.com");

console.log(userOne.name); // سارا
console.log(userTwo.name); // آرمان

    نکته

    برای ساختن نمونه از کلمه‌ی کلیدی new استفاده می‌کنیم. فراموش‌کردن آن هنگام فراخوانی کلاس باعث خطا می‌شود.

    ۴. تعریف متد برای نمونه‌ها

    متدها توابعی هستند که داخل کلاس تعریف می‌شوند و رفتار نمونه‌ها را مشخص می‌کنند. برای نوشتن متد، نام و پارامترهای آن را می‌نویسیم و بدنه‌ی تابع را داخل آکولاد قرار می‌دهیم.

    در متدهای نمونه، this به نمونه‌ای اشاره می‌کند که متد را فراخوانی کرده است. به همین دلیل، یک متد می‌تواند به ویژگی‌های همان نمونه دسترسی داشته باشد. 

    class User {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    return `سلام، من ${this.name} هستم.`;
  }
}

const user = new User("سارا");
console.log(user.introduce());

    ۵. امتحان کن

    کد را تغییر بده: نام دو محصول را عوض کن و یک متد دیگر بنویس که قیمت محصول را همراه با واحد پول برگرداند.

    ۶. اشتباه‌های رایج

    • برای ساختن نمونه، new را فراموش نکن؛ new User("سارا") درست است.
    • نام کلاس را طبق قرارداد با حرف بزرگ شروع کن تا از نام متغیرها متمایز باشد.
    • در متدها برای دسترسی به ویژگی نمونه از this استفاده کن؛ مثلاً this.name.
    • هر نمونه ویژگی‌های خودش را دارد؛ تغییر ویژگی یک نمونه، ویژگی نمونه‌ی دیگر را خودبه‌خود تغییر نمی‌دهد.

    ۷. جمع‌بندی

    کلاس، قالبی برای ساختن نمونه‌های مشابه است. متد constructor() هنگام ساخت نمونه اجرا می‌شود، ویژگی‌های نمونه را معمولاً با this مقداردهی می‌کنیم و با new نمونه می‌سازیم. متدهای کلاس رفتارهای مشترک نمونه‌ها را تعریف می‌کنند.

    آماده‌ای؟

    با تعریف کلاس، ساخت نمونه و نوشتن متد تمرین کن.

کتابخانه‌های خارجی در جاوااسکریپت

یاد می‌گیریم کتابخانه‌های آماده را به صفحه اضافه کنیم، آن‌ها را از CDN بارگذاری کنیم و روش درست استفاده از API آن‌ها را پیدا کنیم.

در این درس

    کتابخانه‌ی خارجی چیست؟

    کتابخانه‌ی جاوااسکریپت مجموعه‌ای از کدهای آماده است که می‌توانیم برای انجام کارهای رایج در پروژه استفاده کنیم؛ برای نمونه، کار با تاریخ، ساخت نمودار یا مدیریت رابط کاربری. به‌جای نوشتن همه‌چیز از ابتدا، از قابلیت‌هایی استفاده می‌کنیم که کتابخانه فراهم کرده است.

    کتابخانه‌ها APIهای متفاوتی دارند؛ بنابراین بعد از بارگذاری آن‌ها باید مستندات همان کتابخانه را بخوانیم تا بدانیم چه تابع‌ها و گزینه‌هایی در دسترس‌اند.

    از کتابخانه فقط وقتی نیاز داری استفاده کن

    کتابخانه می‌تواند زمان توسعه را کم کند، اما هر وابستگی اضافه، کد بیشتری برای بارگذاری و نگه‌داری به پروژه می‌آورد.

    بارگذاری کتابخانه از CDN

    CDN شبکه‌ای از سرورها برای ارائه‌ی فایل‌هاست. بسیاری از کتابخانه‌ها را می‌توان با افزودن تگ script و نشانی فایل کتابخانه به صفحه آورد. در این مثال از Day.js برای قالب‌بندی تاریخ استفاده می‌کنیم: 

    <script src="https://cdn.jsdelivr.net/npm/dayjs@1/dayjs.min.js"></script>
<script>
  console.log(dayjs().format());
</script>

    وقتی فایل Day.js بارگذاری شود، می‌توان تابع dayjs() را صدا زد. قرارگرفتن اسکریپت کتابخانه پیش از کدی که به آن وابسته است مهم است؛ در غیر این صورت ممکن است کد خودمان پیش از آماده‌شدن کتابخانه اجرا شود.

    نیاز به اینترنت

    در این نمونه، فایل کتابخانه از یک CDN دریافت می‌شود. اگر اتصال برقرار نباشد یا فایل بارگذاری نشود، کدی که به آن وابسته است کار نخواهد کرد.

    نمایش نتیجه در صفحه

    معمولاً نتیجه‌ی کتابخانه را در یک عنصر HTML نشان می‌دهیم. در نمونه‌ی زیر جاوااسکریپت نتیجه را در عنصری با شناسه‌ی date قرار می‌دهد: 

    <p id="date"></p>

<script src="https://cdn.jsdelivr.net/npm/dayjs@1/dayjs.min.js"></script>
<script>
  const formattedDate = dayjs().format("YYYY-MM-DD");
  document.querySelector("#date").textContent = formattedDate;
</script>

    ترتیب اجرا

    در این مثال، عنصر p و سپس کتابخانه پیش از کدی قرار گرفته‌اند که از آن‌ها استفاده می‌کند. اگر فایل جاوااسکریپت را به فایل جداگانه منتقل کردی، ترتیب بارگذاری را هم بررسی کن.

    کتابخانه‌ی ماژولی یا اسکریپت معمولی؟

    همه‌ی کتابخانه‌ها به یک شکل بارگذاری نمی‌شوند. بعضی کتابخانه‌ها برای استفاده با import و export آماده‌اند؛ بعضی دیگر پس از افزودن تگ script یک نام عمومی در اختیار صفحه می‌گذارند. راهنمای رسمی همان کتابخانه مشخص می‌کند از کدام روش و کدام فایل استفاده کنی.

    نمونه‌ی Day.js در این درس از روش تگ script استفاده می‌کند و تابع dayjs() را در دسترس قرار می‌دهد. آن را با روش import ماژولی که در درس قبل آموختیم اشتباه نگیر.

    امتحان کن

    این کد را اجرا کن و قالب تاریخ را در رشته‌ی ورودی format() تغییر بده. برای نمونه، می‌توانی ترتیب سال، ماه و روز را عوض کنی.

    اگر مثال اجرا نشد

    ابتدا اتصال اینترنت و درست‌بودن نشانی CDN را بررسی کن. همچنین مطمئن شو نام تابع را درست نوشته‌ای و کتابخانه پیش از کدی که از آن استفاده می‌کند بارگذاری می‌شود.

    چند عادت خوب

    پیش از افزودن کتابخانه، بررسی کن آیا مرورگر یا کد فعلی پروژه همان نیاز را پوشش می‌دهد. از منبع و فایل معتبر کتابخانه استفاده کن، مستندات و مجوز استفاده از آن را بخوان و فقط قابلیت‌هایی را به کار ببر که واقعاً نیاز داری.

    برای پروژه‌های بزرگ‌تر، بهتر است روش نصب و نسخه‌بندی را طبق مستندات کتابخانه و ابزارهای پروژه انجام بده؛ شیوه‌ی CDN در این درس برای آشنایی ساده با مفهوم و آزمایش سریع مناسب است.

    جمع‌بندی

    کتابخانه‌ی خارجی کد آماده‌ای است که قابلیت‌هایی را برای پروژه فراهم می‌کند. برای استفاده از نسخه‌ی CDN، فایل را با تگ script بارگذاری می‌کنیم و سپس API آن را طبق مستنداتش به کار می‌بریم. ترتیب بارگذاری مهم است و روش استفاده به نوع کتابخانه بستگی دارد.

    آماده‌ای؟

    با تمرین‌های این درس، یک کتابخانه را به صفحه اضافه کن.

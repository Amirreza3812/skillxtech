واحدهای اندازه‌گیری در CSS

در این درس با واحدهای نسبی CSS مثل درصد، em، rem، vw و vh آشنا می‌شوی و یاد می‌گیری هرکدام را در چه موقعیتی به کار ببری.

در این درس

    چرا واحدهای CSS مهم‌اند؟

    در CSS برای تعیین اندازه‌ی متن، فاصله‌ها و ابعاد عناصر از واحد استفاده می‌کنیم. بعضی واحدها اندازه‌ای ثابت دارند؛ اما واحدهای نسبی با توجه به اندازه‌ی عنصر والد، فونت یا صفحه تغییر می‌کنند. واحدهای نسبی کمک می‌کنند چیدمان در اندازه‌های مختلف صفحه انعطاف‌پذیرتر باشد.

    نکته

    این درس روی واحدهای نسبی پرکاربرد تمرکز دارد. واحدهایی مثل px نیز در CSS استفاده می‌شوند، اما اندازه‌ی ثابتی دارند.

    درصد: %

    درصد معمولاً نسبت به اندازه‌ی عنصر والد محاسبه می‌شود. برای مثال اگر عرض والد ۶۰۰ پیکسل باشد، عنصری با width: 50% حدود ۳۰۰ پیکسل عرض می‌گیرد. 

    .card {
  width: 80%;
}

    در این مثال، عرض کارت ۸۰ درصد از عرض والدش است. اگر عرض والد تغییر کند، عرض کارت هم تغییر می‌کند.

    em و rem

    واحد em برای اندازه‌ی فونت معمولاً نسبت به اندازه‌ی فونت عنصر والد محاسبه می‌شود. اگر اندازه‌ی فونت والد ۲۰ پیکسل باشد، 1.5em برابر با ۳۰ پیکسل خواهد بود.

    واحد rem نسبت به اندازه‌ی فونت عنصر ریشه‌ی صفحه (html) محاسبه می‌شود. چون به والدهای تو‌در‌تو وابسته نیست، برای تعیین اندازه‌ی متن و فاصله‌ها انتخاب قابل پیش‌بینی‌تری است. 

    html {
  font-size: 16px;
}

.parent {
  font-size: 20px;
}

.child-em {
  font-size: 1.5em;  /* نسبت به والد */
}

.title {
  font-size: 2rem;   /* نسبت به html */
}

    روش ساده برای به‌خاطر سپردن

    em را به اندازه‌ی فونت والد و rem را به اندازه‌ی فونت ریشه‌ی صفحه ربط بده.

    vw و vh

    واحد vw بر اساس عرض صفحه و واحد vh بر اساس ارتفاع صفحه محاسبه می‌شود. هر واحد برابر با یک‌صدم اندازه‌ی مربوط است؛ بنابراین 50vw نصف عرض صفحه است. 

    .banner {
  width: 80vw;
  min-height: 40vh;
}

    این روش برای ساخت بخش‌هایی که با اندازه‌ی صفحه تغییر می‌کنند مفید است. برای متن‌های بزرگ، مقدارهای بسیار وابسته به صفحه ممکن است متن را در نمایشگرهای کوچک یا بزرگ ناخوانا کنند.

    مقایسه‌ی واحدها

    واحد نسبت به کاربرد رایج
    % عنصر والد عرض‌های انعطاف‌پذیر
    em اندازه‌ی فونت والد اندازه‌هایی که همراه متن والد تغییر می‌کنند
    rem اندازه‌ی فونت عنصر html فونت و فاصله‌های قابل پیش‌بینی
    vw عرض صفحه ابعاد وابسته به عرض صفحه
    vh ارتفاع صفحه ارتفاع بخش‌های صفحه

    امتحان کن

    مقدار واحدها را تغییر بده و نتیجه را ببین. می‌توانی عرض صفحه را هم با تغییر اندازه‌ی پنجره‌ی پیش‌نمایش عوض کنی.

    خلاصه‌ی درس

    • % معمولاً اندازه را نسبت به والد تعیین می‌کند.
    • em به اندازه‌ی فونت والد وابسته است.
    • rem به اندازه‌ی فونت عنصر ریشه‌ی صفحه وابسته است.
    • vw و vh به‌ترتیب نسبت به عرض و ارتفاع صفحه‌اند.
    • واحد مناسب را با توجه به چیزی انتخاب کن که می‌خواهی اندازه‌اش مبنا باشد.

    آماده‌ای؟

    با چند تمرین، کاربرد واحدهای نسبی را مرور کن.

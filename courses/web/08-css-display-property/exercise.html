تمرین: CSS Display

کد هر تمرین را تغییر بده و تفاوت شیوه‌های نمایش را در خروجی ببین.

  1. جعبه‌های بلوکی

    مقدار display کلاس .box را طوری تنظیم کن که هر جعبه در یک خط جدا قرار بگیرد.

    راهنمایی

    مقداری را انتخاب کن که عنصر را بلوکی می‌کند.

  2. برچسب‌های کنار هم

    کد را طوری تغییر بده که برچسب‌ها کنار هم قرار بگیرند. آن‌ها را به inline-block تبدیل کن و برای هر برچسب عرض ۱۲۰ پیکسل بگذار.

    راهنمایی

    مقدار display را تغییر بده و ویژگی width را به کلاس .tag اضافه کن.

  3. پنهان کردن یک پیام

    کاری کن پیام دوم نمایش داده نشود و جای خالی هم در صفحه باقی نماند.

    راهنمایی

    کلاس .secret را پیدا کن و مقدار مناسب display را برایش بنویس.

  4. تغییر رفتار لینک

    لینک‌ها به‌طور پیش‌فرض درون‌خطی هستند. کلاس .link-box را طوری تغییر بده که هر لینک در خط جدا قرار بگیرد و عرض ۲۰۰ پیکسل داشته باشد.

    راهنمایی

    برای جدا کردن هر لینک در خط خودش از block استفاده کن.

  5. کارت‌های ردیفی با flex

    مقدار display کلاس .cards را به flex تغییر بده تا کارت‌ها کنار هم قرار بگیرند. سپس با gap بین کارت‌ها ۱۰ پیکسل فاصله بساز.

    راهنمایی

    display: flex; را روی والد کارت‌ها بنویس و مقدار gap را تنظیم کن.

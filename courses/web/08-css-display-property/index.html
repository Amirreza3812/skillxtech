ویژگی display در CSS

یاد می‌گیری عناصر HTML چطور در صفحه کنار هم قرار می‌گیرند و چطور نمایش آن‌ها را با ویژگی display تغییر بدهی.

در این درس

    ویژگی display چیست؟

    ویژگی display یکی از ویژگی‌های CSS است که نوع نمایش یک عنصر را مشخص می‌کند؛ مثلاً عنصر در خط خودش قرار بگیرد، کنار عناصر دیگر بیاید یا اصلاً دیده نشود.

    در این درس با چهار مقدار پرکاربرد آشنا می‌شویم:

    • block: عنصر بلوکی
    • inline: عنصر درون‌خطی
    • inline-block: ترکیبی از درون‌خطی و بلوکی
    • none: پنهان کردن عنصر

    هر عنصر نمایش پیش‌فرض دارد

    مثلاً div به‌طور پیش‌فرض بلوکی است و span به‌طور پیش‌فرض درون‌خطی. با CSS می‌توانیم نوع نمایش آن‌ها را تغییر بدهیم.

    عنصرهای بلوکی: block

    عنصر بلوکی معمولاً از خط جدید شروع می‌شود و تا جایی که لازم باشد عرض ردیف را می‌گیرد. به همین دلیل، عنصر بعدی معمولاً در خط بعد قرار می‌گیرد.

    عنصرهایی مثل div، p و تیترهایی مثل h1 به‌طور پیش‌فرض بلوکی‌اند.

    عنصرهای درون‌خطی: inline

    عنصر درون‌خطی در همان خطِ متن قرار می‌گیرد و به‌اندازه‌ی محتوایش فضا می‌گیرد. اگر جا باشد، عنصر بعدی هم کنار آن می‌آید.

    span، a، strong و em معمولاً درون‌خطی هستند. به‌طور معمول، width و height روی عنصر درون‌خطی اثری ندارند.

    چرا width و height اعمال نشد؟

    عنصرهای inline برای قرار گرفتن داخل جریان متن طراحی شده‌اند؛ بنابراین معمولاً نمی‌توان با width و height اندازه‌ی آن‌ها را مثل یک جعبه کنترل کرد. برای این کار می‌توانی از inline-block استفاده کنی.

    ترکیب دو رفتار: inline-block

    عنصر inline-block کنار عناصر دیگر در همان خط قرار می‌گیرد، اما مثل یک جعبه می‌توانی برایش width، height، فاصله‌ی داخلی و حاشیه تعیین کنی.

    اگر عرض صفحه برای همه‌ی جعبه‌ها کافی نباشد، بعضی از آن‌ها به خط بعد می‌روند. به همین دلیل inline-block برای جعبه‌های کوچک و ردیفی مفید است.

    پنهان کردن عنصر با none

    وقتی مقدار display را none قرار بدهی، عنصر نمایش داده نمی‌شود و فضایی هم در چیدمان صفحه اشغال نمی‌کند.

    تفاوت display: none با visibility: hidden

    display: none عنصر را از نمایش و چیدمان صفحه حذف می‌کند. اما visibility: hidden عنصر را نامرئی می‌کند ولی جای خالی آن را نگه می‌دارد.

    مقایسه‌ی مقدارها

    مقدار شروع از خط جدید width و height نمونه‌ی رایج
    block بله قابل تنظیم div و p
    inline خیر معمولاً اثر ندارد a و span
    inline-block خیر، تا وقتی جا باشد قابل تنظیم برچسب‌ها و جعبه‌های ردیفی
    none نمایش داده نمی‌شود عنصر در چیدمان نیست محتوای پنهان

    نگاهی کوتاه به flex و grid

    دو مقدار مهم دیگر، flex و grid هستند. آن‌ها برای چیدمان چند عنصر داخل یک والد به کار می‌روند؛ مثلاً برای ساختن ردیف‌هایی انعطاف‌پذیر یا چیدمان شبکه‌ای.

    فعلاً کافی است بدانی با نوشتن display: flex یا display: grid روی یک عنصر والد، شیوه‌ی چیدمان فرزندانش را تغییر می‌دهی. در درس‌های بعدی جداگانه با آن‌ها کار می‌کنیم.

    خلاصه

    • display: block عنصر را بلوکی می‌کند؛ معمولاً از خط جدید شروع می‌شود.
    • display: inline عنصر را در جریان متن نگه می‌دارد؛ معمولاً width و height روی آن اثر ندارند.
    • display: inline-block عنصر را کنار بقیه نگه می‌دارد و امکان تنظیم اندازه‌ی جعبه را می‌دهد.
    • display: none عنصر را از نمایش و چیدمان صفحه حذف می‌کند.
    • display: flex و display: grid ابزارهایی برای چیدمان فرزندان یک عنصر والد هستند.

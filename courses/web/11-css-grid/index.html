آشنایی با CSS Grid

یاد می‌گیریم چطور با ساخت ردیف‌ها و ستون‌ها، چند بخش را در یک شبکه مرتب کنیم.

در این درس

    ۱. Grid چیست؟

    تا اینجا با چینش‌های بلوکی و inline-block آشنا شدیم. گاهی لازم است چند بخش را هم‌زمان در ردیف‌ها و ستون‌ها مرتب کنیم؛ مثلاً گالری عکس‌ها، فهرست کارت‌ها یا چیدمان اصلی یک صفحه. CSS Grid برای ساخت چنین شبکه‌هایی به کار می‌آید.

    برای ساخت شبکه، ابتدا به عنصر والد مقدار display: grid می‌دهیم. فرزندان مستقیم آن، آیتم‌های شبکه می‌شوند و بر اساس ردیف‌ها و ستون‌هایی که تعریف می‌کنیم در شبکه قرار می‌گیرند.

    نکته

    Grid را روی والد قرار می‌دهیم؛ نه روی تک‌تک کارت‌ها. در مثال‌های این درس، عنصرهایی که مستقیم داخل والد Grid هستند، خانه‌های شبکه‌اند.

    ۲. ساخت اولین شبکه

    در این مثال، به والد کلاس grid می‌دهیم و برای آن دو ستون تعریف می‌کنیم. شش فرزند شبکه، به‌ترتیب در این ستون‌ها قرار می‌گیرند و ردیف‌های لازم به‌صورت خودکار شکل می‌گیرند. 

    .grid {
  display: grid;
  grid-template-columns: 150px 150px;
  gap: 10px;
}

    ۳. تعریف ستون‌ها و ردیف‌ها

    با grid-template-columns تعداد و اندازهٔ ستون‌ها را مشخص می‌کنیم. برای نمونه، grid-template-columns: 120px 200px; دو ستون با عرض‌های متفاوت می‌سازد.

    برای تعریف ارتفاع ردیف‌ها از grid-template-rows استفاده می‌کنیم. اگر تعداد آیتم‌ها بیشتر از خانه‌های تعریف‌شده باشد، Grid می‌تواند ردیف‌های بیشتری برای آن‌ها بسازد. 

    .grid {
  display: grid;
  grid-template-columns: 120px 200px;
  grid-template-rows: 80px 120px;
  gap: 10px;
}

    ۴. واحد fr و تابع repeat()

    گاهی می‌خواهیم فضای موجود بین ستون‌ها تقسیم شود، نه این‌که برای هر ستون اندازه‌ای ثابت تعیین کنیم. واحد fr سهمی از فضای قابل‌استفاده را نشان می‌دهد. برای مثال، 1fr 1fr دو ستون هم‌اندازه می‌سازد و 1fr 2fr فضایی با نسبت یک به دو میان آن‌ها تقسیم می‌کند.

    اگر چند ستون هم‌اندازه لازم داشته باشیم، تابع repeat() از تکرار مقدار یکسان جلوگیری می‌کند: repeat(3, 1fr) یعنی سه ستون هم‌اندازه. 

    .grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}

    تفاوت px و fr

    مقدار px اندازهٔ ثابتی تعیین می‌کند؛ مقدار fr سهمی از فضای باقی‌ماندهٔ شبکه را به ستون می‌دهد. فعلاً برای تمرین، با تغییر مقادیر و مشاهدهٔ نتیجه تفاوتشان را بررسی کن.

    ۵. فاصلهٔ بین خانه‌ها

    ویژگی gap فاصلهٔ بین ردیف‌ها و ستون‌های شبکه را تنظیم می‌کند. با یک مقدار، فاصلهٔ ردیف‌ها و ستون‌ها یکسان می‌شود؛ با دو مقدار، مقدار اول فاصلهٔ ردیف‌ها و مقدار دوم فاصلهٔ ستون‌ها است. 

    .grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 8px 16px;
}

    در این نمونه، فاصلهٔ ردیف‌ها 8px و فاصلهٔ ستون‌ها 16px است. مقدار gap: 12px; هم برای هر دو جهت فاصلهٔ یکسان می‌گذارد.

    ۶. استفاده از Grid در بخش‌های تو در تو

    مثل چینش‌های درس قبل، می‌توانیم یک شبکه را داخل بخشی از شبکهٔ دیگر قرار دهیم. مثلاً کل صفحه بخش‌های اصلی خودش را داشته باشد و در بخش محتوای اصلی، شبکهٔ جداگانه‌ای از کارت‌ها بسازیم. 

    <div class="page">
  <header>سربرگ</header>
  <main class="cards">
    <article>کارت اول</article>
    <article>کارت دوم</article>
    <article>کارت سوم</article>
  </main>
</div>
    .page {
  display: grid;
  gap: 12px;
}

.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}

    ۷. خطاهای رایج

    • اگر شبکه ساخته نشد، بررسی کن display: grid روی والد آیتم‌ها باشد.
    • ویژگی grid-template-columns را روی عنصر والد شبکه می‌نویسیم، نه روی هر کارت.
    • اگر یک بخش Grid داخل بخش دیگری قرار دارد، باید برای همان بخش داخلی هم جداگانه display: grid تعریف کنی.
    • اگر کارت‌ها به اندازهٔ دلخواه نیستند، ابتدا تعداد ستون‌ها و مقادیر grid-template-columns را بررسی کن.

    جمع‌بندی

    برای ساخت شبکه، به والد display: grid می‌دهیم. با grid-template-columns ستون‌ها و با grid-template-rows ردیف‌ها را تعریف می‌کنیم. برای ساخت ستون‌های هم‌اندازه می‌توانیم از repeat() و fr استفاده کنیم و فاصلهٔ بین خانه‌ها را با gap تنظیم کنیم. همچنین می‌توانیم Grid را درون بخش‌های دیگر به‌صورت تو در تو به کار ببریم.

    آماده‌ای؟

    حالا با تعریف ستون‌ها و کارت‌ها یک شبکهٔ کوچک بساز.

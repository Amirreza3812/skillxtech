تمرین: CSS Grid

با تعریف ستون‌ها و فاصله‌ها، چند شبکهٔ ساده بساز و تغییرشان بده.

  1. ساخت شبکهٔ دو ستونه

    کد را کامل کن تا آیتم‌ها داخل دو ستون قرار بگیرند. برای ستون‌ها عرض ثابت انتخاب کن و بین خانه‌ها فاصله بگذار.

    راهنمایی

    به والد display: grid بده و برایش grid-template-columns تعریف کن. ویژگی gap فاصلهٔ بین خانه‌ها را تنظیم می‌کند.

  2. سه ستون هم‌اندازه با repeat و fr

    شبکه‌ای سه‌ستونه بساز که ستون‌ها فضای موجود را به شکل مساوی تقسیم کنند. شش کارت در HTML قرار دارد؛ CSS را طوری بنویس که در دو ردیف دیده شوند.

    راهنمایی

    از repeat(3, 1fr) برای تعریف سه ستون هم‌اندازه استفاده کن. آیتم‌های اضافه به ردیف بعدی می‌روند.

  3. ساخت شبکهٔ کارت‌ها با فاصله‌های متفاوت

    شبکه‌ای سه‌ستونه بساز و برای فاصلهٔ ردیف‌ها و ستون‌ها دو مقدار متفاوت تعیین کن. بعد مقدارها را تغییر بده و تفاوت فاصله‌ها را مشاهده کن.

    راهنمایی

    در gap، مقدار اول فاصلهٔ ردیف‌ها و مقدار دوم فاصلهٔ ستون‌هاست؛ مثلاً gap: 8px 20px;.

  4. ترکیب دو شبکهٔ تو در تو

    سربرگ را در بالای یک والد قرار بده و زیر آن بخشی بساز که سه کارت را در یک شبکهٔ سه‌ستونه نمایش دهد. برای والد اصلی و بخش کارت‌ها می‌توانی Gridهای جداگانه تعریف کنی.

    راهنمایی

    برای والد اصلی از display: grid استفاده کن. سپس به والد کارت‌ها هم display: grid و grid-template-columns: repeat(3, 1fr) بده.

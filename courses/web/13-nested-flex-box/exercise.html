تمرین: فلکس‌باکس تو‌در‌تو

تمرین‌ها را با تغییر HTML و CSS در کادرهای کدنویسی انجام بده و نتیجه را همان‌جا ببین.

  1. کارت عمودی با سرآیند افقی

    کلاس .card را طوری تنظیم کن که محتوای کارت عمودی چیده شود و بین بخش‌ها ۱۲ پیکسل فاصله باشد. سپس .card-header را به کانتینر فلکس افقی تبدیل کن.

    راهنمایی

    برای کارت از flex-direction: column استفاده کن. سرآیند به جهت پیش‌فرض فلکس نیاز دارد.

  2. دکمه‌های کنار هم

    به .actions چیدمان فلکس بده تا دو دکمه کنار هم قرار بگیرند. بین دکمه‌ها ۱۰ پیکسل فاصله بگذار و اجازه بده در فضای کم به خط بعد بروند.

    راهنمایی

    از display: flex، ویژگی gap و flex-wrap: wrap استفاده کن.

  3. ساخت کارت پروفایل تو‌در‌تو

    کارت بیرونی را به کانتینر فلکس عمودی تبدیل کن. سرآیند کارت باید عناصرش را افقی بچیند و بخش اطلاعات نام و توضیح را عمودی مرتب کند. برای هر کانتینر فاصله‌ی مناسبی بگذار.

    راهنمایی

    سه کانتینر متفاوت داری: .profile-card، .profile-header و .profile-info. هرکدام را جداگانه تنظیم کن.

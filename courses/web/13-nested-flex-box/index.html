فلکس‌باکس تو‌در‌تو

با قرار دادن کانتینرهای Flexbox داخل هم، می‌توانی بخش‌های مختلف صفحه را با چیدمان‌های مستقل و ترکیبی بسازی.

در این درس

    ۱. فلکس‌باکس تو‌در‌تو چیست؟

    هر عنصری که display: flex داشته باشد، فرزندان مستقیمش را با Flexbox مرتب می‌کند. اگر یکی از این فرزندان هم کانتینر فلکس باشد، می‌تواند فرزندان خودش را با تنظیمات جداگانه مرتب کند. به این ساختار، فلکس‌باکس تو‌در‌تو می‌گوییم.

    برای مثال، یک کارت می‌تواند محتوایش را عمودی بچیند، در حالی که بخش بالایی همان کارت، تصویر و عنوان را کنار هم نمایش می‌دهد.

    نکته

    هر کانتینر فلکس فقط چیدمان فرزندان مستقیم خودش را کنترل می‌کند. کانتینرهای تو‌در‌تو تنظیمات مستقل دارند.

    ۲. ساختار HTML را بساز

    در این نمونه، عنصر .card کانتینر بیرونی است و .card-header یک کانتینر فلکس داخلی. بخش پایینی کارت هم با یک کانتینر داخلی دیگر، دکمه‌ها را کنار هم می‌چیند. 

    <article class="card">
  <div class="card-header">
    <div class="avatar">ن</div>
    <div class="user-info">
      <h3>نگار احمدی</h3>
      <p>طراح رابط کاربری</p>
    </div>
  </div>

  <p class="card-description">
    یادگیری طراحی وب را از اینجا شروع کن.
  </p>

  <div class="card-actions">
    <button>مشاهده دوره</button>
    <button>ذخیره</button>
  </div>
</article>

    ۳. چیدمان کانتینر بیرونی

    به کارت display: flex و flex-direction: column می‌دهیم تا فرزندان مستقیم آن زیر هم قرار بگیرند. ویژگی gap فاصله‌ی یکنواختی میان آن‌ها ایجاد می‌کند. 

    .card {
  display: flex;
  flex-direction: column;
  gap: 16px;
  padding: 20px;
  border: 1px solid #d8dee9;
  border-radius: 12px;
}

    چرا از gap استفاده کنیم؟

    gap فاصله‌ی بین فرزندان مستقیم همان کانتینر را تنظیم می‌کند. در ساختار تو‌در‌تو، هر سطح می‌تواند مقدار gap مخصوص خودش را داشته باشد.

    ۴. چیدمان کانتینرهای داخلی

    حالا برای سرآیند کارت، جهت چیدمان را افقی می‌کنیم. کانتینر .user-info خودش فلکس‌باکس ستونی است تا نام و توضیح را زیر هم قرار دهد. همین‌طور دکمه‌های کارت داخل .card-actions کنار هم می‌آیند. 

    .card-header {
  display: flex;
  align-items: center;
  gap: 12px;
}

.user-info {
  display: flex;
  flex-direction: column;
  gap: 4px;
}

.card-actions {
  display: flex;
  gap: 8px;
}

    ۵. نمونه را امتحان کن

    مقدارهای flex-direction و gap را تغییر بده و نتیجه‌ی هر کانتینر را جداگانه ببین.

    ۶. اشتباه‌های رایج

    • تصور نکن تنظیم flex-direction روی والد، جهت چیدمان داخل همه‌ی فرزندان را هم تغییر می‌دهد.
    • align-items و justify-content را روی کانتینری تنظیم کن که قرار است فرزندان مستقیمش را مرتب کند.
    • اگر فرزندان از کانتینر بیرون می‌زنند، بررسی کن آیا به flex-wrap: wrap نیاز داری یا نه.

    یادت باشد

    هر بار مشخص کن کدام عنصر والد است و کدام فرزندان مستقیم آن هستند. سپس تنظیمات Flexbox را روی همان والد قرار بده.

    خلاصه‌ی درس

    • هر کانتینر فلکس، فرزندان مستقیم خودش را مرتب می‌کند.
    • کانتینر فلکس می‌تواند داخل کانتینر فلکس دیگری قرار بگیرد.
    • برای هر سطح می‌توانی جهت، فاصله و تراز مستقل تعیین کنی.
    • ترکیب چیدمان‌های افقی و عمودی، ساخت رابط‌های پیچیده را ساده‌تر می‌کند.

    آماده‌ای؟

    با تمرین‌های این درس، چیدمان‌های تو‌در‌تو بساز.

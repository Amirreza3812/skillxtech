متغیرها در JavaScript

یاد می‌گیریم داده‌ها را در متغیرها ذخیره کنیم، با let و const آشنا شویم و برای متغیرها نام‌های خوانا انتخاب کنیم.

در این درس

    متغیر چیست؟

    متغیر نامی است که به یک مقدار داده می‌شود تا بتوانیم آن مقدار را در برنامه نگه داریم و بعداً از آن استفاده کنیم. برای مثال، می‌توانیم نام دانشجو یا تعداد امتیازهای یک بازی را در متغیر ذخیره کنیم. 

    const studentName = "سارا";
let score = 10;

console.log(studentName);
console.log(score);

    در این مثال، studentName و score نام متغیرها هستند و رشتهٔ "سارا" و عدد 10 مقدارهای ذخیره‌شده در آن‌ها هستند.

    تعریف متغیر

    برای تعریف متغیر در JavaScript معمولاً از کلمه‌های کلیدی const یا let استفاده می‌کنیم. بعد از آن‌ها نام متغیر و در صورت نیاز مقدار اولیه را می‌نویسیم. 

    const courseName = "طراحی وب";
let lessonNumber = 25;

    علامت = در اینجا مقدار سمت راست را به متغیر سمت چپ نسبت می‌دهد. به این کار مقداردهی یا assignment می‌گوییم.

    نکته

    در JavaScript علامت = برای مقداردهی است؛ برای بررسی برابر بودن دو مقدار از روش‌های مقایسه استفاده می‌کنیم که در درس شرط‌ها با آن‌ها آشنا می‌شویم.

    تفاوت let و const

    از let برای متغیری استفاده می‌کنیم که قرار است مقدارش دوباره تغییر کند. از const برای نامی استفاده می‌کنیم که قرار نیست دوباره به مقدار دیگری نسبت داده شود. 

    let score = 10;
score = 15;

const courseName = "طراحی وب";

console.log(score);      // 15
console.log(courseName); // طراحی وب

    چون امتیاز ممکن است تغییر کند، آن را با let تعریف کردیم. نام دوره را تغییر نمی‌دهیم، پس برای آن از const استفاده کردیم.

    روش پیشنهادی

    اگر مقدار متغیر قرار نیست عوض شود، const انتخاب خوبی است. هر جا لازم شد مقدار متغیر را دوباره تغییر بدهی، از let استفاده کن.

    تغییر مقدار متغیر

    متغیری که با let تعریف شده باشد می‌تواند مقدار جدید بگیرد. هنگام تغییر مقدار، دوباره کلمهٔ let را نمی‌نویسیم؛ فقط نام متغیر و مقدار تازه را می‌آوریم. 

    let city = "تهران";
city = "شیراز";

console.log(city); // شیراز

    اما اگر بخواهیم متغیر تعریف‌شده با const را دوباره مقداردهی کنیم، JavaScript خطا می‌دهد: 

    const country = "ایران";
country = "ترکیه"; // خطا: امکان مقداردهی دوباره به const وجود ندارد

    مراقب باش

    متغیر const باید هنگام تعریف مقدار اولیه بگیرد. همچنین نمی‌توانی بعداً آن را به مقدار دیگری نسبت بدهی.

    تعریف متغیر بدون مقدار اولیه

    می‌توانیم متغیری را با let تعریف کنیم و بعداً به آن مقدار بدهیم. تا پیش از مقداردهی، مقدار آن undefined است؛ یعنی هنوز مقداری به آن اختصاص نداده‌ایم. 

    let favoriteColor;

console.log(favoriteColor); // undefined

favoriteColor = "آبی";
console.log(favoriteColor); // آبی

    تعریف const بدون مقدار اولیه مجاز نیست، چون مقدار آن باید همان ابتدا مشخص شود.

    نام‌گذاری متغیرها

    نام متغیر باید طوری انتخاب شود که هدف آن را روشن کند. در JavaScript نام متغیر معمولاً با حروف انگلیسی نوشته می‌شود و برای نام‌های چند کلمه‌ای، روش camelCase رایج است. 

    const studentName = "سارا";
let totalScore = 0;

    چند قانون مهم برای نام‌گذاری:

    • نام متغیر می‌تواند شامل حروف، عدد، زیرخط و علامت دلار باشد.
    • نام متغیر نباید با عدد شروع شود.
    • فاصله در نام متغیر مجاز نیست.
    • حروف بزرگ و کوچک متفاوت‌اند؛ score با Score یکی نیست.
    • از نام‌هایی استفاده کن که معنی مقدار را مشخص کنند.
    // نام‌های خوانا
const firstName = "سارا";
let itemCount = 3;

// نام‌های نامناسب یا غیرمجاز
// const 1name = "سارا";     // شروع با عدد
// const first name = "سارا"; // وجود فاصله

    امتحان کن

    مقدارهای نمونه را تغییر بده و دکمه را بزن تا یک جمله با مقدار متغیرها ساخته شود.

    خلاصه

    • متغیر نامی برای نگهداری و استفادهٔ دوباره از یک مقدار است.
    • let برای متغیری است که مقدارش می‌تواند تغییر کند.
    • const برای متغیری است که دوباره مقداردهی نمی‌شود.
    • متغیر const باید هنگام تعریف مقدار اولیه داشته باشد.
    • نام‌های روشن و معنادار، خواندن کد را آسان‌تر می‌کنند.

    آماده‌ای؟

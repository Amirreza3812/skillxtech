طراحی وب

آرایه‌ها و حلقه‌ها

در این درس یاد می‌گیریم چند مقدار را در یک آرایه نگه داریم، به اعضای آن دسترسی پیدا کنیم و با حلقه‌ها روی اعضا تکرار انجام دهیم.

در این درس

    آرایه چیست؟

    آرایه نوعی مقدار است که می‌تواند چند مقدار را به ترتیب در خود نگه دارد. برای نمونه، به‌جای ساختن یک متغیر جدا برای هر نام، می‌توانیم نام‌ها را در یک آرایه قرار دهیم. 

    const fruits = ["سیب", "موز", "پرتقال"];

    اعضای آرایه داخل کروشه‌ی [] نوشته می‌شوند و با ویرگول از هم جدا هستند. اعضا می‌توانند رشته، عدد، مقدار بولی یا حتی نوع‌های دیگری از داده باشند.

    شماره‌ی جایگاه یا index

    برای خواندن یک عضو از آرایه، از شماره‌ی جایگاه آن استفاده می‌کنیم. شماره‌گذاری از 0 شروع می‌شود: عضو اول اندیس 0، عضو دوم اندیس 1 و همین‌طور ادامه دارد. 

    const fruits = ["سیب", "موز", "پرتقال"];

console.log(fruits[0]); // سیب
console.log(fruits[1]); // موز

    یادت باشد

    اندیس از صفر شروع می‌شود؛ بنابراین در آرایه‌ای با سه عضو، اندیس آخر 2 است، نه 3.

    تعداد اعضای آرایه

    ویژگی length تعداد اعضای آرایه را نشان می‌دهد. برای دسترسی به آخرین عضو می‌توانیم از اندیس array.length - 1 استفاده کنیم. 

    const colors = ["آبی", "سبز", "قرمز"];

console.log(colors.length); // 3
console.log(colors[colors.length - 1]); // قرمز

    تغییر و اضافه‌کردن اعضا

    اگر آرایه با const تعریف شده باشد، نمی‌توان متغیر را دوباره به آرایه‌ی دیگری نسبت داد؛ اما می‌توان اعضای همان آرایه را تغییر داد. 

    const tasks = ["مطالعه", "تمرین"];

tasks[0] = "مطالعه‌ی JavaScript";
tasks.push("مرور");

console.log(tasks);

    متد push() یک یا چند عضو را به انتهای آرایه اضافه می‌کند. برای حذف عضو آخر، از pop() استفاده می‌شود. 

    const numbers = [10, 20, 30];

numbers.push(40); // [10, 20, 30, 40]
numbers.pop();    // حذف 40

    نکته درباره‌ی const

    const مانع انتساب دوباره‌ی خود متغیر می‌شود؛ اما تغییر محتوای یک آرایه یا شیء تعریف‌شده با const ممکن است.

    حلقه‌ی for

    وقتی می‌خواهیم کاری را چند بار تکرار کنیم، از حلقه استفاده می‌کنیم. حلقه‌ی for معمولاً سه بخش دارد: مقدار آغازین، شرط ادامه و تغییر مقدار شمارنده. 

    for (let i = 0; i < 3; i++) {
  console.log(i);
}

    این حلقه از i = 0 شروع می‌شود، تا وقتی i < 3 درست باشد اجرا می‌شود و بعد از هر دور i را یک واحد افزایش می‌دهد.

    پیمایش آرایه با for

    با استفاده از اندیس و ویژگی length می‌توانیم تک‌تک اعضای آرایه را بخوانیم. این روش وقتی مفید است که به شماره‌ی اندیس هم نیاز داشته باشیم. 

    const fruits = ["سیب", "موز", "پرتقال"];

for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}

    حلقه‌ی for...of

    اگر فقط به مقدار هر عضو نیاز داشته باشیم و اندیس برایمان مهم نباشد، حلقه‌ی for...of خواناتر است. 

    const fruits = ["سیب", "موز", "پرتقال"];

for (const fruit of fruits) {
  console.log(fruit);
}

    کدام حلقه را انتخاب کنم؟

    برای دسترسی مستقیم به مقدارها، for...of انتخاب ساده‌ای است. اگر به اندیس نیاز داری یا می‌خواهی از شمارنده استفاده کنی، for گزینه‌ی مناسبی است.

    نمایش اعضای آرایه در صفحه

    در این نمونه، JavaScript روی اعضای آرایه حلقه می‌زند و برای هر کدام یک عنصر جدید در صفحه می‌سازد.

    در کد بالا، createElement("li") یک عنصر فهرست می‌سازد، textContent متن آن را تعیین می‌کند و append() آن را به فهرست اضافه می‌کند.

    اشتباه‌های رایج

    • تلاش برای خواندن اندیسی که وجود ندارد؛ مثلاً fruits[fruits.length].
    • فراموش‌کردن اینکه اندیس آرایه از صفر شروع می‌شود.
    • نوشتن شرطی نادرست در حلقه که باعث تکرار بی‌پایان می‌شود.
    • فراموش‌کردن افزایش شمارنده در حلقه‌ی for.

    جمع‌بندی

    آرایه‌ها برای نگهداری مجموعه‌ای مرتب از مقدارها به کار می‌روند. اندیس اعضا از صفر شروع می‌شود و length تعداد آن‌ها را نشان می‌دهد. با push() و pop() می‌توان اعضای انتهایی را اضافه یا حذف کرد. حلقه‌های for و for...of کمک می‌کنند روی اعضای آرایه تکرار انجام دهیم.

    آماده‌ای؟

    با تمرین‌های زیر آرایه بساز و روی اعضای آن حلقه بزن.

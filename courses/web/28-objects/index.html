بازگشت به داشبورد تمرین این درس

طراحی وب

آبجکت‌ها در جاوااسکریپت

در این درس یاد می‌گیریم چطور با آبجکت‌ها اطلاعات مرتبط را در یک ساختار نگه داریم، ویژگی‌های آن‌ها را بخوانیم و تغییر بدهیم و متدهای ساده بسازیم.

در این درس

    آبجکت چیست؟

    آبجکت یا شیء راهی برای دسته‌بندی چند مقدار مرتبط در یک متغیر است. برای نمونه، اطلاعات یک کتاب مثل عنوان، نویسنده و تعداد صفحه‌ها می‌توانند ویژگی‌های یک آبجکت باشند.

    هر ویژگی از یک نام و یک مقدار تشکیل می‌شود. نام ویژگی را کلید و مقدار آن را مقدار ویژگی می‌نامیم.

    ساختن آبجکت

    برای ساخت آبجکت از آکولاد استفاده می‌کنیم. داخل آکولاد، ویژگی‌ها را به شکل کلید: مقدار می‌نویسیم و با ویرگول از هم جدا می‌کنیم. 

    const book = {
  title: "سفر به ماه",
  author: "مینا احمدی",
  pages: 120
};

    در این مثال، title، author و pages کلید هستند. مقدارهای آن‌ها به‌ترتیب رشته، رشته و عددند.

    نکته

    کلیدهایی که نام معتبر متغیر جاوااسکریپت هستند معمولاً بدون کوتیشن نوشته می‌شوند؛ مانند title. اگر نام کلید فاصله یا نشانه‌های خاص داشته باشد، باید آن را داخل کوتیشن بنویسیم.

    خواندن ویژگی‌ها

    برای خواندن یک ویژگی، معمولاً از نقطه استفاده می‌کنیم: objectName.propertyName. 

    const book = {
  title: "سفر به ماه",
  pages: 120
};

console.log(book.title);
console.log(book.pages);

    همچنین می‌توانیم از براکت استفاده کنیم. این روش به‌خصوص زمانی کاربرد دارد که نام کلید در یک متغیر ذخیره شده باشد یا کلید شامل فاصله باشد. 

    const book = {
  title: "سفر به ماه",
  "publication year": 2024
};

const propertyName = "title";

console.log(book[propertyName]);
console.log(book["publication year"]);

    تغییر و افزودن ویژگی

    ویژگی‌های آبجکت را می‌توانیم با استفاده از نقطه یا براکت تغییر دهیم. اگر کلیدی که می‌نویسیم از قبل وجود نداشته باشد، به آبجکت اضافه می‌شود. 

    const book = {
  title: "سفر به ماه",
  pages: 120
};

book.pages = 150;
book.author = "مینا احمدی";

console.log(book.pages);
console.log(book.author);

    آبجکت و const

    وقتی آبجکت را با const تعریف می‌کنیم، نمی‌توانیم متغیر را به آبجکت دیگری نسبت بدهیم؛ اما می‌توانیم ویژگی‌های همان آبجکت را تغییر دهیم یا ویژگی جدیدی اضافه کنیم.

    متدها؛ تابع درون آبجکت

    اگر مقدار یک ویژگی تابع باشد، به آن ویژگی متد می‌گوییم. متد می‌تواند از اطلاعات همان آبجکت استفاده کند یا کاری مرتبط با آن انجام دهد. 

    const user = {
  name: "سارا",
  greet: function () {
    console.log(`سلام، من ${this.name} هستم.`);
  }
};

user.greet();

    در این مثال، greet یک متد است. واژه‌ی this در این متد به آبجکتی اشاره می‌کند که متد روی آن فراخوانی شده است؛ اینجا یعنی user.

    به this دقت کن

    مقدار this به نحوه‌ی فراخوانی متد وابسته است. در این مثال، متد را با user.greet() اجرا می‌کنیم تا this به آبجکت user اشاره کند.

    استفاده از آبجکت با تابع

    آبجکت‌ها را می‌توان به تابع داد، درست مانند رشته‌ها و عددها. تابع می‌تواند یکی از ویژگی‌های آبجکت را بخواند و از آن استفاده کند. 

    const product = {
  name: "دفتر",
  price: 80
};

function showProduct(product) {
  console.log(`${product.name}: ${product.price} تومان`);
}

showProduct(product);

    جمع‌بندی

    در این درس یاد گرفتیم:

    • آبجکت برای نگهداری چند مقدار مرتبط در قالب ویژگی‌ها استفاده می‌شود.
    • ویژگی‌ها را با ساختار کلید: مقدار تعریف می‌کنیم.
    • برای خواندن ویژگی‌ها از نگارش نقطه‌ای یا براکتی استفاده می‌کنیم.
    • می‌توانیم ویژگی‌های آبجکت را تغییر دهیم یا ویژگی جدیدی اضافه کنیم.
    • تابعی که به‌عنوان ویژگی آبجکت تعریف شود، متد نام دارد.

    آماده‌ای؟

    با تمرین‌های این درس، ساخت و استفاده از آبجکت‌ها را تمرین کن.

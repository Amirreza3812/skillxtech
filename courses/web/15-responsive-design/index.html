طراحی وب

طراحی ریسپانسیو

یاد می‌گیری چرا یک صفحه باید در اندازه‌های مختلف صفحه‌نمایش خوانا و قابل‌استفاده بماند و با چه روش‌هایی می‌توان چیدمان آن را سازگار کرد.

در این درس

    ۱. طراحی ریسپانسیو چیست؟

    طراحی ریسپانسیو یعنی طراحی صفحه به شکلی که در اندازه‌ها و شرایط نمایش مختلف، محتوا همچنان قابل‌خواندن و استفاده باشد؛ از صفحه‌ی باریک موبایل تا نمایشگر بزرگ‌تر لپ‌تاپ.

    ریسپانسیو بودن فقط کوچک کردن همه‌چیز نیست. ممکن است در موبایل ستون‌ها زیر هم قرار بگیرند، فاصله‌ها تغییر کنند یا بعضی بخش‌ها شکل دیگری از چیدمان بگیرند تا استفاده از صفحه راحت‌تر شود.

    هدف اصلی

    محتوا باید در اندازه‌های مختلف بدون اسکرول افقی ناخواسته، متن ناخوانا یا کنترل‌های سخت‌دسترس نمایش داده شود.

    ۲. تنظیم viewport

    برای نمایش درست صفحه در مرورگر موبایل، این متا تگ را داخل <head> می‌گذاریم: 

    <meta name="viewport" content="width=device-width, initial-scale=1">

    عبارت width=device-width به مرورگر می‌گوید عرض صفحه را با عرض دستگاه هماهنگ کند. initial-scale=1 هم بزرگ‌نمایی اولیه را روی اندازه‌ی معمول قرار می‌دهد.

    این خط را فراموش نکن

    اگر viewport به‌درستی تنظیم نشده باشد، مرورگر موبایل ممکن است صفحه را شبیه یک صفحه‌ی دسکتاپ کوچک‌شده نمایش دهد؛ در این حالت قواعد ریسپانسیو نتیجه‌ی مورد انتظار را ندارند.

    ۳. چیدمان را با صفحه سازگار کن

    یک چیدمان مناسب برای نمایشگر بزرگ ممکن است روی موبایل جا نشود. برای نمونه، سه کارت کنار هم در عرض کم به کارت‌های فشرده و ناخوانا تبدیل می‌شوند. می‌توان آن‌ها را در موبایل زیر هم قرار داد و در نمایشگر بزرگ‌تر دوباره کنار هم چید.

    برای ساخت چنین رفتاری معمولاً از ترکیب CSS انعطاف‌پذیر و media query استفاده می‌کنیم. در درس‌های بعدی واحدهای منعطف و Media Query را جداگانه و با جزئیات تمرین می‌کنی.

    ۴. رویکرد mobile-first

    در رویکرد mobile-first، ابتدا چیدمان ساده و مناسب صفحه‌ی باریک را می‌سازیم. سپس برای صفحه‌های بزرگ‌تر، با افزودن قواعد CSS چیدمان را گسترش می‌دهیم. 

    /* چیدمان پایه: صفحه‌ی باریک */
.cards {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

/* چیدمان صفحه‌ی عریض‌تر */
@media (min-width: 700px) {
  .cards {
    grid-template-columns: repeat(3, 1fr);
  }
}

    چرا از موبایل شروع کنیم؟

    این رویکرد کمک می‌کند ابتدا محتوای ضروری و چیدمان پایه را مشخص کنی؛ بعد برای فضای بیشتر، ستون‌ها و امکانات لازم را اضافه کنی.

    ۵. هنگام ریسپانسیو کردن چه چیزهایی را بررسی کنیم؟

    • آیا متن بدون بزرگ‌نمایی اجباری خواناست؟
    • آیا کاربر مجبور است برای دیدن محتوا به چپ و راست اسکرول کند؟
    • آیا کارت‌ها و ستون‌ها در عرض کم به شکل مناسب چیده می‌شوند؟
    • آیا دکمه‌ها و لینک‌ها به‌اندازه‌ی کافی راحت قابل لمس‌اند؟
    • آیا تصویرها از محدوده‌ی صفحه بیرون می‌زنند؟
    • آیا فاصله‌ها و اندازه‌ی محتوا در صفحه‌های مختلف مناسب‌اند؟

    ۶. نمونه را امتحان کن

    اندازه‌ی پنجره‌ی پیش‌نمایش را تغییر بده. در صفحه‌ی باریک، کارت‌ها زیر هم قرار می‌گیرند و از عرض صفحه بیرون نمی‌زنند.

    خلاصه‌ی درس

    • طراحی ریسپانسیو، صفحه را برای اندازه‌های مختلف نمایش سازگار می‌کند.
    • متا تگ viewport نمایش مناسب صفحه در مرورگر موبایل را فراهم می‌کند.
    • چیدمان ریسپانسیو ممکن است در صفحه‌ی باریک و عریض شکل متفاوتی داشته باشد.
    • در رویکرد mobile-first، ابتدا صفحه‌ی باریک را می‌سازیم و بعد گسترش می‌دهیم.
    • برای بررسی صفحه، اندازه‌های گوناگون را امتحان و خوانایی و اسکرول افقی را کنترل کن.

    آماده‌ای؟

    با تمرین‌ها، چیدمان‌های مناسب صفحه‌های مختلف را بررسی کن.

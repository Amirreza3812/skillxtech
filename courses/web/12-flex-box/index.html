آشنایی با Flexbox

یاد می‌گیریم چطور با Flexbox فرزندان یک عنصر را در یک ردیف یا ستون بچینیم و فاصله و تراز آن‌ها را کنترل کنیم.

در این درس

    ۱. Flexbox چیست؟

    Flexbox روشی برای چیدن و مرتب کردن فرزندان یک عنصر است. برای فعال کردن آن، به عنصر والد مقدار display: flex می‌دهیم. فرزندان مستقیم آن والد، آیتم‌های Flexbox می‌شوند.

    خود والد را «ظرف» یا flex container می‌نامیم و فرزندان مستقیمش را «آیتم» یا flex items. ویژگی‌های اصلی Flexbox معمولاً روی ظرف نوشته می‌شوند.

    نکته

    اگر فرزند یک آیتم خودش فرزند دیگری داشته باشد، آن فرزندِ داخلی به صورت خودکار آیتم Flexbox والدِ بزرگ‌تر نمی‌شود. فقط فرزندان مستقیم ظرف Flexbox، آیتم‌های آن هستند.

    ۲. فعال کردن Flexbox

    در حالت عادی، چند بخش بلوکی معمولاً زیر هم قرار می‌گیرند. با display: flex روی والد، فرزندانش در یک ردیف قرار می‌گیرند. مقدار پیش‌فرض جهت در Flexbox برابر row است. 

    .items {
  display: flex;
}

    ۳. انتخاب جهت با flex-direction

    ویژگی flex-direction جهت قرار گرفتن آیتم‌ها را مشخص می‌کند. مقدار row آیتم‌ها را در راستای ردیف می‌چیند و مقدار column آن‌ها را در راستای ستون قرار می‌دهد.

    چون صفحهٔ این درس راست‌به‌چپ است، جهت دیداری ردیف با جهت نوشتار فارسی هماهنگ است. مقدارهای row-reverse و column-reverse ترتیب دیداری را برعکس می‌کنند.

    مقدار نتیجه
    row آیتم‌ها در یک ردیف قرار می‌گیرند.
    column آیتم‌ها در یک ستون قرار می‌گیرند.
    row-reverse آیتم‌ها در ردیف، با ترتیب دیداری برعکس قرار می‌گیرند.
    column-reverse آیتم‌ها در ستون، با ترتیب دیداری برعکس قرار می‌گیرند. 
    .items {
  display: flex;
  flex-direction: column;
}

    ۴. فاصله‌گذاری با gap

    ویژگی gap فاصلهٔ بین آیتم‌ها را مشخص می‌کند. این ویژگی روی ظرف Flexbox قرار می‌گیرد و لازم نیست برای هر آیتم جداگانه margin تعیین کنیم. 

    .items {
  display: flex;
  gap: 16px;
}

    اگر جهت آیتم‌ها column باشد، فاصلهٔ آیتم‌ها در امتداد ستون دیده می‌شود. اگر جهت row باشد، فاصله میان آیتم‌های ردیف قرار می‌گیرد.

    ۵. مرتب کردن آیتم‌ها با justify-content

    ویژگی justify-content آیتم‌ها را در امتداد محور اصلی مرتب می‌کند؛ محور اصلی همان جهتی است که با flex-direction تعیین کرده‌ایم.

    مقدار رفتار کلی
    flex-start آیتم‌ها در ابتدای محور اصلی قرار می‌گیرند.
    center آیتم‌ها در مرکز محور اصلی قرار می‌گیرند.
    flex-end آیتم‌ها در انتهای محور اصلی قرار می‌گیرند.
    space-between فاصلهٔ خالی میان آیتم‌ها تقسیم می‌شود.
    space-around فضایی پیرامون آیتم‌ها قرار می‌گیرد. 
    .items {
  display: flex;
  justify-content: center;
}

    ۶. تراز کردن آیتم‌ها با align-items

    ویژگی align-items آیتم‌ها را در امتداد محور متقاطع تراز می‌کند؛ یعنی محوری که بر محور اصلی عمود است. برای دیدن نتیجه، معمولاً به ظرف ارتفاع یا اندازهٔ مشخصی می‌دهیم.

    مقدار رفتار کلی
    stretch آیتم‌ها در محور متقاطع کشیده می‌شوند.
    flex-start آیتم‌ها در ابتدای محور متقاطع قرار می‌گیرند.
    center آیتم‌ها در مرکز محور متقاطع قرار می‌گیرند.
    flex-end آیتم‌ها در انتهای محور متقاطع قرار می‌گیرند. 
    .items {
  display: flex;
  align-items: center;
  height: 180px;
}

    دو محور را به خاطر بسپار

    justify-content در امتداد محور اصلی عمل می‌کند و align-items در امتداد محور متقاطع. با تغییر flex-direction، جهت این دو محور هم عوض می‌شود.

    ۷. رفتن آیتم‌ها به ردیف بعد با flex-wrap

    به‌طور پیش‌فرض، آیتم‌ها تلاش می‌کنند در یک خط جا بگیرند. با flex-wrap: wrap اجازه می‌دهیم اگر فضای کافی نبود، آیتم‌ها به خط بعدی بروند. 

    .items {
  display: flex;
  flex-wrap: wrap;
  gap: 10px;
}

    ۸. ساخت چینش‌های تو در تو

    همان‌طور که در درس قبل دیدیم، صفحه را می‌توان به بخش‌های بزرگ و کوچک تقسیم کرد. حالا هر والد می‌تواند Flexbox جداگانهٔ خودش را داشته باشد. در مثال زیر، بخش اصلی صفحه آیتم‌ها را در یک ردیف قرار می‌دهد و منوی کناری لینک‌ها را در یک ستون مرتب می‌کند. 

    <div class="page">
  <header>سربرگ</header>

  <div class="page-bodyادامهٔ `index.html` از همان‌جایی که کد قبلی قطع شد:

```html
<div class="page-body">
  <aside class="sidebar">
    <nav class="menu">
      <a href="#">خانه</a>
      <a href="#">دوره‌ها</a>
      <a href="#">دربارهٔ ما</a>
    </nav>
  </aside>

  <main class="content">
    <article>محتوای اصلی</article>
  </main>
</div>
</div>
    .page {
  display: flex;
  flex-direction: column;
  gap: 12px;
}

.page-body {
  display: flex;
  gap: 12px;
}

.menu {
  display: flex;
  flex-direction: column;
  gap: 8px;
}

    جمع‌بندی

    برای فعال کردن Flexbox به والد display: flex می‌دهیم. جهت چیدمان را flex-direction، فاصلهٔ بین آیتم‌ها را gap، مرتب‌سازی روی محور اصلی را justify-content و تراز روی محور متقاطع را align-items کنترل می‌کند. با flex-wrap: wrap هم اجازه می‌دهیم آیتم‌ها در صورت کمبود فضا به خط بعد بروند. می‌توانیم این تنظیم‌ها را در والدهای مختلف ترکیب کنیم و چینش‌های تو در تو بسازیم.

    آماده‌ای؟

    حالا با جهت، فاصله و تراز آیتم‌ها تمرین کن.

بولین‌ها و شرط‌ها در JavaScript

با مقدارهای بولین و عملگرهای مقایسه آشنا می‌شویم و یاد می‌گیریم با دستورهای if و else بر اساس شرط‌ها تصمیم بگیریم.

در این درس

    مقدارهای بولین

    نوع دادهٔ بولین (Boolean) فقط دو مقدار دارد: true و false. این مقدارها برای نشان دادن درست یا نادرست بودن یک وضعیت استفاده می‌شوند. 

    const isLoggedIn = true;
const hasFinishedLesson = false;

console.log(isLoggedIn);
console.log(hasFinishedLesson);

    نکته

    true و false مقدارهای بولین هستند؛ آن‌ها را داخل کوتیشن ننویس. مقدار "true" یک رشته است، نه بولین.

    مقایسهٔ مقدارها

    عملگرهای مقایسه دو مقدار را بررسی می‌کنند و نتیجه‌ای بولین، یعنی true یا false، برمی‌گردانند.

    عملگر معنی نمونه
    > بزرگ‌تر از 8 > 5 نتیجهٔ true دارد.
    < کوچک‌تر از 3 < 2 نتیجهٔ false دارد.
    >= بزرگ‌تر یا مساوی 5 >= 5 نتیجهٔ true دارد.
    <= کوچک‌تر یا مساوی 4 <= 3 نتیجهٔ false دارد.
    === مساوی از نظر مقدار و نوع 5 === 5 نتیجهٔ true دارد.
    !== نامساوی از نظر مقدار یا نوع 5 !== 3 نتیجهٔ true دارد. 
    const age = 18;

console.log(age >= 18); // true
console.log(age < 18);  // false

    از === استفاده کن

    برای بررسی برابری معمولاً از === استفاده کن. این عملگر هم مقدار و هم نوع داده را مقایسه می‌کند. عملگر == ممکن است پیش از مقایسه نوع داده‌ها را تبدیل کند و نتیجهٔ غیرمنتظره بدهد.

    دستور if

    با if می‌توانیم بگوییم اگر یک شرط درست بود، کد مشخصی اجرا شود. شرط داخل پرانتز می‌آید و کدی که باید اجرا شود داخل آکولاد قرار می‌گیرد. 

    const age = 20;

if (age >= 18) {
  console.log("اجازهٔ ورود داری.");
}

    اگر شرط نتیجهٔ true بدهد، کد داخل آکولاد اجرا می‌شود. اگر نتیجه false باشد، آن بخش اجرا نمی‌شود.

    دستور if و else

    با else می‌توانیم مشخص کنیم اگر شرط درست نبود، چه کدی اجرا شود. 

    const age = 16;

if (age >= 18) {
  console.log("اجازهٔ ورود داری.");
} else {
  console.log("برای ورود هنوز کم‌سن هستی.");
}

    بررسی چند حالت با else if

    وقتی چند حالت داریم، می‌توانیم از else if استفاده کنیم. JavaScript شرط‌ها را از بالا به پایین بررسی می‌کند و اولین شرط درست را اجرا می‌کند. 

    const score = 82;

if (score >= 90) {
  console.log("عالی");
} else if (score >= 70) {
  console.log("خوب");
} else if (score >= 50) {
  console.log("قابل قبول");
} else {
  console.log("نیاز به تمرین بیشتر");
}

    ترتیب شرط‌ها مهم است

    شرط‌های خاص‌تر یا بزرگ‌تر را معمولاً بالاتر قرار بده. وقتی یک شرط درست پیدا شود، بقیهٔ شاخه‌های همان ساختار بررسی نمی‌شوند.

    ترکیب شرط‌ها

    گاهی برای تصمیم‌گیری باید بیش از یک شرط را بررسی کنیم. این سه عملگر منطقی کاربرد زیادی دارند:

    • && (و): هر دو شرط باید درست باشند.
    • || (یا): درست بودن دست‌کم یکی از شرط‌ها کافی است.
    • ! (نقیض): نتیجهٔ بولین را برعکس می‌کند.
    const age = 22;
const hasTicket = true;

if (age >= 18 && hasTicket) {
  console.log("می‌توانی وارد شوی.");
}

const isWeekend = false;
console.log(!isWeekend); // true

    امتحان کن

    مقدار سن را تغییر بده و نتیجهٔ بررسی شرط را در صفحه ببین.

    خلاصه

    • نوع بولین دو مقدار true و false دارد.
    • عملگرهای مقایسه نتیجهٔ بولین تولید می‌کنند.
    • if کد را فقط وقتی اجرا می‌کند که شرط درست باشد.
    • از else برای حالت جایگزین و از else if برای بررسی حالت‌های بیشتر استفاده می‌کنیم.
    • &&، || و ! برای ترکیب یا برعکس‌کردن شرط‌ها هستند.

    آماده‌ای؟

    حالا چند تمرین دربارهٔ بولین‌ها و شرط‌ها انجام بده.

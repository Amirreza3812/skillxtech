طراحی وب

تمرین: بولین‌ها و شرط‌ها

شرط‌ها را تغییر بده، حالت‌های مختلف را امتحان کن و نتیجه را ببین.

  1. بررسی مثبت یا منفی بودن عدد

    مقدار number را تغییر بده. اگر عدد بزرگ‌تر از صفر بود پیام «مثبت»، اگر کوچک‌تر از صفر بود پیام «منفی» و در غیر این صورت پیام «صفر» نمایش بده.

    راهنمایی

    برای حالت سوم، بعد از if و else if از else استفاده کن.

  2. بررسی قبولی

    اگر نمره برابر یا بیشتر از ۱۰ بود، پیام «قبول شدی» و در غیر این صورت پیام «نیاز به تلاش بیشتر» نمایش بده.

    راهنمایی

    برای بررسی «بزرگ‌تر یا مساوی» از عملگر >= استفاده کن.

  3. رده‌بندی امتیاز

    با استفاده از if، else if و else، امتیاز را در یکی از این گروه‌ها قرار بده: ۹۰ به بالا «عالی»، ۷۰ به بالا «خوب»، ۵۰ به بالا «قابل قبول» و کمتر از آن «نیاز به تمرین».

    راهنمایی

    شرط‌ها را از امتیازهای بالاتر به پایین‌تر بررسی کن. مقدار score را برای دیدن نتیجه‌های مختلف تغییر بده.

  4. ترکیب دو شرط

    فقط وقتی پیام «اجازهٔ ورود داری» نمایش بده که سن حداقل ۱۸ باشد و متغیر hasTicket هم درست باشد.

    راهنمایی

    برای درست بودن هم‌زمان هر دو شرط از عملگر && استفاده کن. سن یا وضعیت بلیت را تغییر بده و حالت‌های مختلف را بررسی کن.
